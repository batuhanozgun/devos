# D-011

**What is asked.** The plan has the builder read the research library (`agentic-os-search`, private, read-only for DevOS) directly until C04 moves it into Supabase. This session cannot attach it: the platform asks a person to approve the attach tool, and a session in Accept edits (D-008) cannot answer that prompt. Batu decides whether this session may run in Auto for one call to attach the library, or the library waits until C04, or this session runs in Auto from now on.

**Options** (Appendix E section 3):

| | Purpose | Benefit | Cost | Alternative it replaces |
|---|---|---|---|---|
| (a) one Auto window, recommended | attach the library once, read access only | C00 step 4 and the C00–C04 library reading go as planned; D-008 holds for all other work | Batu: two clicks and one short message, once; while the window is open, Claude Code's classifier also judges steps and may refuse one with a label only; if he forgets to switch back, the session stays in Auto (the guard still decides every call) | (b), (c) |
| (b) Accept edits, library after C04 | keep D-008 whole | no action from Batu | the independent plan review (C00 step 4) loses its Foundation and candidate-study scan, or waits for C04; every C00–C04 use of the library waits; C00 cannot close as planned before C04, which is a change of plan order and of review quality | (a) |
| (c) Auto from now on, this session only | no waiting on platform-gated calls | session starts in C01, C03 and the exams would not wait for him either | D-008 reversed for this session; the classifier's label-only refusals, which D-008 removed, come back for all work | (a) |

**Recommendation and reason.** (a). It meets the plan's need with the smallest change to his decision: one call, read access only, under the guard. (b) would cut a step the plan requires; (c) is broader than this need. The session starts that C01 needs will come to him as their own narrow question when C01 starts, with their number known.

**What he needs to know.** Attaching gives this session read access only; the guard allows only the library and only read access (rule S5), and DevOS never writes to the library (plan 0.5). The library's own control files are not loaded as instructions (the session does not register it as a root). Nothing else changes.

**If he does not answer.** Work that does not need the library goes on: the translation of the plan (C00 step 0), the ECC comparison from ECC's public source (step 3), the counter-design (step 5) and the premise inventory (step 6). The library part of the independent review (step 4) waits, so C00 cannot close. Silence is not approval; no default applies.

**Steps for (a)** (in Turkish to him; Appendix E section 7): 1. in this session, in the mode menu next to the message box, choose "Auto"; 2. write "auto" to this session; 3. when the session writes that the library is attached, choose "Accept edits" in the same menu. The session checks the mode in the guard's log before and after.
