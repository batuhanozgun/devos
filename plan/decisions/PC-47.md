### 1. Appendix B 3.15, the rules, their last sentence (line 286). Labelled: no (Appendix B is a [Proposal], its line 3).

New: "Exam tasks are opened in the working environment as ordinary `Work`. The fact that a task is an exam is kept only in `EvalRun`'s link (above), never in a field of the `Work` record; the exam records stay hidden, and no function answers the working environment differently for an exam task than for ordinary work (`evidence/C02/EV-C02-002_data_model_choices.md` DM-24 and DM-35; `evidence/C02/EV-C02-008_design_addendum_roles_and_samples.md` section 5.1)."
Reason: EV-C02-008 sections 5.1 and 5.3 place 1. The old sentence's "field" has disagreed with B:284 ("the link lives only here, so only `devos_sinav` can read it") since PC-42, and with EV-C02-002 DM-24 (no exam field on Work). Under section 5.1 the exam fact is kept only in the exam records, which stay refused to every class but `devos_sinav` (B:35 to B:38; line 286's earlier sentences), and the Work an exam task was opened as is ordinary for every class; the new text says so, and states property P where B states the exam's rules.
