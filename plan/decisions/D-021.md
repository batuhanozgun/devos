# D-021

**What is asked (one sentence, Appendix E section 3).** Will you press Run now once on the routine's page so that its second run (R1b) starts today rather than tomorrow at 11:07: (a) press it today (recommended), or (b) do not press, and it runs by itself tomorrow at 11:07?

**Why it is Batu's.** The press is an action on his account, on the routine he created; the builder cannot take it, and does not start runs of his routine.

**Options.**
- **(a) Press Run now once today, with no text (recommended).** Purpose: rows 1 and 4 of C01, and everything that waits on row 1, a day earlier. Benefit: about 23 hours saved on C01's critical path, at the same quality: the run does exactly what the scheduled run would do, from the same control file, and records how it was started. Cost: one press; the run draws the same usage as tomorrow's would, but today, in the current five-hour window (it resets at 14:30 his time); two runs fall on 2026-10-11; tomorrow's scheduled run then has nothing to do and makes a short idle run (its rules are being adjusted, note N-143). Risk: that a session started with Run now behaves like a scheduled one is documented by the platform, not observed; if it did not, R1b would stay open and tomorrow's run would take it, which is option (b)'s timeline.
- **(b) Do not press.** Purpose: change nothing. Benefit: no action from him. Cost: rows 1 and 4, and the C01 items that wait on row 1, come a day later.

**Recommendation: (a)**, because it saves about a day on the critical path with one press, changes nothing in what the run does, and its worst case is (b).

**What you need to know.** Press once and write no text: text given with Run now reaches the run only as untrusted data, and the run needs none. If nothing appears after the press, do not press again; say so on issue #6. The offer stands until 2026-10-12 at 10:50 his time (07:50Z); after that, do not press, because the scheduled run is near and two runs at once would collide. A press needs no reply: the run's own record shows it.

**If you do not answer.** Nothing is lost: R1b runs by itself on 2026-10-12 at 11:07 his time, and no other work waits on this decision.

**How to answer.** Press Run now (no reply needed), or write `D-021: b` on issue #6 or in the working session.
