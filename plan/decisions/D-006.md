# D-006

**Why it is Batu's.** Every session in the builder's chain is created by the one before it, and the chain has reached the platform's lineage limit (depth 8 of 8). This run cannot create its successor, a reviewer or a reminder. Only a session outside the chain can start the next run. **What he does:** tell his conversation session "devos için yeni bir kurulum koşusu başlat" (it knows the run goal), or start a session on `devos` himself. **Default by silence:** none; the work waits (C00 is on hold until W-C00-12 is accepted, and nothing is lost: tranche 1c is on draft PR #86).
