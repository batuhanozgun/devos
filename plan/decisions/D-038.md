# D-038

**Soru (Türkçe, #6 için).** T-W03-08'in kırma denemesi için GitHub'da sahte bir ortam açıp, denemeden sonra onu ve üç test dalını siler misin?
- (a) Evet: aşağıdaki adımları yaparsın; ilk üç adımdan sonra "açtım" yazarsın, ben denemeyi yapıp sana silme adımlarını yazarım (önerim).
- (b) Hayır: kırma denemesi "kontrol edilemedi" olarak kalır, dallar da durur.

Cevap: `D-038: a` ya da `D-038: b`.

**Adımlar (a için).**
1. GitHub'da `batuhanozgun/devos` deposunu aç, üstteki **Settings** sekmesine, soldaki menüde **Environments**'a tıkla, sonra **New environment**'a bas. Ad olarak `w03-fixture-unprotected` yaz ve **Configure environment**'a bas. Görmen gereken: bu adla bir ortam sayfası.
2. Aynı sayfada **Deployment branches and tags** bölümünde **No restriction** seçili kalsın; başka bir kural ekleme. Görmen gereken: dal kuralı yok.
3. **Environment secrets** bölümünde **Add environment secret**'a bas. Name: `SUPABASE_DB_PASSWORD`, Value: `w03-fixture-not-a-credential` (bu gerçek bir şifre değil, uydurma bir değer). **Add secret**'a bas. Görmen gereken: listede bu adla bir secret. Sonra bu oturuma "açtım" yaz.
4. (Ben denemeyi yaptıktan sonra) aynı **Environments** sayfasında `w03-fixture-unprotected`'ı aç, **Delete environment**'a bas ve onayla.
5. Deponun **Branches** sayfasında (kod sekmesinde dal sayısına tıklayarak) şu üç dalın yanındaki çöp kutusu simgesine bas: `claude/w03-branch-probe`, `claude/w03-search-breaks` ve sana yazacağım kırma dalı.

**What is asked (one sentence).** Should Batu create, for one run, a synthetic GitHub environment with no branch rule and a non-secret value, so that T-W03-08's break can be shown, and then delete it with three fixture branches (a, recommended), or skip all of it (b)?

**Why it is his.** Only the repository's owner can configure environments on a personal-account repository, and the builder cannot delete branches; both are changes to his account's repository.

**What you need to know.** The real environments (migrate-devos-test, migrate-devos) and their passwords are not touched. The synthetic environment holds a made-up value and exists only for one run. The test already shows that GitHub refused the branch every way it was tried; the break shows that the test would notice if GitHub did not refuse.

**If you do not answer.** Nothing waits; the break is recorded "could not check", and the branches stay.
