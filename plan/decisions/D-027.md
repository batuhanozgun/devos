# D-027

**What is asked (one sentence, Appendix E section 3).** Will you press Run now on the routine's page so that its next run (P2, row 13) starts today rather than tomorrow at 11:07, and once more for P3 when I say on issue #6 that it is ready: (a) yes (recommended), or (b) no, and they run by themselves tomorrow and the day after at 11:07?

**Why it is Batu's.** The press is an action on his account, on the routine he created; the builder does not start runs of his routine.

**Options.**
- **(a) Press Run now once now for P2, and once more for P3 when the executor says so on issue #6 (recommended).** Purpose: row 13 (P2 and P3), and the steps after it (the combined scenario and the routine's removal), two days earlier. Benefit: about 18 hours saved by the first press and a day more by the second, at the same quality: each run does exactly what the scheduled run would do, from the same control file on `main`. Cost: two presses, a few minutes apart or more (P1 took about 7 minutes); the runs draw the same usage as the scheduled ones would, but today. Risk: as with D-021 and D-022, if a run behaved differently when started by hand, its step would stay open and the next scheduled run would take it, which is option (b)'s timeline.
- **(b) Do not press.** Purpose: change nothing. Benefit: no action from him. Cost: row 13 and the steps after it two days later.

**Recommendation: (a)**, for the same reason as D-021 and D-022: each press saves about a day on the critical path and changes nothing in what the run does; its worst case is (b).

**What you need to know.** Press once for P2 and write no text. Do not press for P3 until the executor writes on issue #6 that P3 is ready: P3 must start only after P2 has closed and its closing has been counted. If nothing appears after a press, do not press again; say so on issue #6. The offer for P2 stands until 2026-10-12 at 10:50 his time (07:50Z). A press needs no reply: the run's own record shows it.

**If you do not answer.** Nothing is lost: P2 runs by itself on 2026-10-12 at 11:07 his time, P3 on 2026-10-13.

**How to answer.** Press Run now (no reply needed), or write `D-027: b` on issue #6 or in the working session.
