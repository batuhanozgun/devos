# D-022

**What is asked (one sentence, Appendix E section 3).** Will you press Run now once more on the routine's page so that its next run (P1, row 7) starts today rather than tomorrow at 11:07: (a) press it today (recommended), or (b) do not press, and it runs by itself tomorrow at 11:07?

**Why it is Batu's.** The press is an action on his account, on the routine he created; the builder does not start runs of his routine.

**Options.**
- **(a) Press Run now once today, with no text (recommended).** Purpose: row 7's session part, and the steps after it (rows 13 and the combined scenario), a day earlier. Benefit: about 19 hours saved on C01's critical path, at the same quality: the run does exactly what the scheduled run would do, from the same control file on `main`. Cost: one press; the run draws the same usage as tomorrow's would, but today, in the current five-hour window; it downloads and installs an embedding runtime (about 200 MB) in the routine's own session. Risk: as with D-021, if the run behaved differently when started by hand, the step would stay open and tomorrow's run would take it, which is option (b)'s timeline.
- **(b) Do not press.** Purpose: change nothing. Benefit: no action from him. Cost: row 7, and the steps that come after it, a day later.

**Recommendation: (a)**, for the same reason as D-021: one press saves about a day on the critical path and changes nothing in what the run does; its worst case is (b).

**What you need to know.** Press once and write no text. If nothing appears after the press, do not press again; say so on issue #6. The offer stands until 2026-10-12 at 10:50 his time (07:50Z). A press needs no reply: the run's own record shows it. This press is for P1 only; the next step (P2) needs a small checked change first, and comes to him separately if it is worth a press.

**If you do not answer.** Nothing is lost: P1 runs by itself on 2026-10-12 at 11:07 his time.

**How to answer.** Press Run now (no reply needed), or write `D-022: b` on issue #6 or in the working session.
