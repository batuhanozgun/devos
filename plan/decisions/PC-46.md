# PC-46

**Authority.** EV-C02-008 (`evidence/C02/EV-C02-008_design_addendum_roles_and_samples.md`) section 2 decides how EV-C02-002 DM-41's trigger and the database's own `sample` Reviews coexist, and its section 3.2 names the plan text the decision makes untrue, for a change through plan Section 14. Every Old text below is quoted from `main` `11feac5d1db15475bf2b773fd1b90742ded86e0e` (11feac5, PR #296), with that commit's line numbers. `plan/Ek_B_Veri_Modeli.md`, `plan/Ek_C_Testler.md` and this record are class normal; `plan/work/W-C02-10.md`'s acceptance block, which changes with this record (below, "Notes"), is class high. A fresh-context checker judges this change at the head that adds it, before its merge. No text labelled [Batu kararı] / [Batu's decision] changes.

### 1. Appendix B 3.11, the rules, the bullet "The verifier does not repair in the same action" (line 246). Labelled: no (Appendix B is a [Proposal], its line 3).
Old: "- The verifier does not repair in the same action: a new revision of the target product cannot be written in the same transaction as a `Review` record."
New: "- The verifier does not repair in the same action: a new revision of a review's target cannot be written in the same transaction as a `Review` record of it or a `Verdict` on such a review. The `sample` Review the database itself opens (next rule) for the record revision whose accepted write draws it, with no reviewer and no verdict, is not such a record; the transaction that takes it or writes its verdict falls under this rule in full (`evidence/C02/EV-C02-002_data_model_choices.md` DM-41; `evidence/C02/EV-C02-008_design_addendum_roles_and_samples.md` section 2)."
Reason: EV-C02-008 sections 2.1 to 2.3 and 3.2 place 1. Read literally, "the target product" (an Artifact, B 3.10) would stay true under the decision, since no sample stream targets an Artifact; but DM-41, accepted, applies the rule to every target and to Verdicts, and under that reading the old sentence would say that the database's own sample of a Need, Decision, EffortPolicy, Finding or routine work item refuses the write that draws it, which the design does not do. The new text states DM-41's reading (it is wider than the old words: every target, and the Verdict) and the one exception, bounded by the writer (the database itself), the revision (the one whose accepted write draws it) and the absence of any reviewer or verdict; the taking ends the exception. Stages: C02 (W-C02-09, W-C02-10, W-C02-13, W-C02-14); C03 (the audit environment takes the samples).

### 2. Appendix C, C2, N28 (line 145). Labelled: no (Appendix C is a [Proposal], its line 3).
Old: "| N28 | The verifier does not repair | A new revision of the target in the same transaction as the review record is rejected | The repair is opened as a separate work item | C02 |"
New: "| N28 | The verifier does not repair | A new revision of the target in the same transaction as the review record is rejected, and so is one in the transaction that takes a `sample` Review or writes its verdict; the `sample` Review the database itself opens for the record revision that draws it is not a review record here (Appendix B 3.11) | The repair is opened as a separate work item; a record whose accepted write draws a `sample` Review is accepted with it in the same transaction | C02 |"
Reason: EV-C02-008 sections 2.1, 2.3 and 3.2 place 2. Under the old plain words N28's negative and N01's (C:118: the "filled but meaningless" need "reaches the audit environment's queue as a `Review` of kind `sample`", which B:266 makes within the drawing call) cannot both pass. The new negative keeps every old case in which a verifier acts and adds one (the taking, and the sample's verdict); it excludes only the row no verifier wrote. The new positive states what the exclusion admits, so that a build that refuses its own samples fails N28 instead of passing it. Why this loosens nothing is argued in EV-C02-008 section 3.3, which this change's checker judges. Stages: C02 (W-C02-07: T-W07-N28's clause table quotes this row and gains its new clauses and EV-C02-008 section 2.5's cases before any result; W-C02-10 point 7; W-C02-13's breaks).
