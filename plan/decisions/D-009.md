# D-009

**What is asked.** Under D-008 every session the builder opens runs in Accept edits. The platform refuses a session in Accept edits when it tries to start another session ("MCP tool call requires approval"), and its documentation says no hook or permission rule can give that approval. As D-008 stands, no builder session can start a successor run or an independent review session. Batu decides whether one builder session, whose only job is starting sessions, may run in auto mode as an exception.

**What it does not decide.** How the starter is built, where it runs and which checks it carries are the builder's technical work, reviewed before merge (section 5). No option asks Batu to approve a refused call; option (a) is a scope for his own decision D-008, and the starter still runs under the guard.

**If he does not answer.** Nothing is lost. The run that found this finishes the work that needs no new session and stops. New runs and review sessions wait until a session that can start them is active (today only his conversation session, while it is in auto mode). Silence is not approval; no default applies.
