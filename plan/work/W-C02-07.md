The test designer (W-C02-02) writes C02's tests under `tests/` before the build they judge, in Appendix C's form C0 (every field filled; at least two examples of the failure class; a negative and a positive control; a break attempt; a format gate's "filled but meaningless" example), on real PostgreSQL: the Appendix C tests whose stage is C02 (R2 section 1: F01, F04, F05, F06, F07's C02 part, F08, Concurrency, N01, N02, N03, N04's C02 part, N09's C02 part, N17, N25's C02 part, N28, N29's C02 part, K05); a test for each Acceptance line that no Appendix C test covers (R2 section 5 (b): no direct writes to the tables by any role; each environment's real token against another environment's authority in every direction; a claim-bearing operation with a fake session ID; the format gates' "filled but meaningless" examples, N02 and N03 included; Finding's gate if W-C02-04 keeps it; the migration lines, which W-C02-03 shows); the inputs plan Section 8 item 14 names for the checks this item's tests exercise (missing, unreadable and partial input, with "could not check" a result of its own); and N-074 T-31's strengthened conditions (F12 (c): planted filled-but-meaningless records caught at a rate written in advance).
