# W-C00-15 · No-mechanism baseline before C02

Added on 2026-10-05 (L-146) as work found by W-C00-10 (topic T-24, from CHK-C00-023 C3). The plan's mechanisms are built in C02–C06 and first tested on real work in C07; without a baseline, plan 6.12 item 4's removal test ("does the result get worse when the mechanism is removed?") has nothing to compare against. It depends on W-C00-14 because, if the library is attached for it, its records are public writes drawn on the library.

## Acceptance

<!-- acceptance -->
Before C02 starts, a controlled discovery task in the form of Appendix C K01/K02 is run as a baseline without DevOS's planned mechanisms: one task with a hidden material gap and one no-gap control, written by a subagent that does not run them, with the success criteria for both written and merged before either runs; a fresh-context subagent that does not know the answer reads the task texts first and finds no hint to the gap (or the texts are rewritten and checked again); each task is run by fresh subagents of the installation session that see neither the criteria nor the gap, with direct read-only access to the library if D-011 allows it, otherwise with that stated; the results are recorded as evidence on U-1 and as the baseline for 6.12 item 4's removal test in C07 and C10, and are not counted as C07's result; a fresh-context checker verdict judges that the run followed its pre-registration.
