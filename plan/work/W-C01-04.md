# W-C01-04 · Probe-only guard rule

Plan C01, "Platform and guard apart": where a row asks what the platform itself allows, the probe makes exactly the named attempt, only on the named probe target, "under a probe-only guard rule (a checked guard change, removed when C01 ends); the guard's own answer is recorded separately". The installation guard (`.claude/hooks/tool_allowlist.py`) denies these attempts today, so without the rule a probe would see only the guard's answer. Rows 2, 3, 8, 12 and 17 and N-109 use it (row 8 for its push outside `claude/` and its auto-merge attempt, which the guard's rules B3 and M4 deny today); row 9's fault injection uses it if making the guard fail in a probe session needs a guard change. Its removal is W-C01-29.
