# W-C02-27 · M3b: guard rule T6 for SendMessage, the roles' tools lines and the working order's text (SB-COR 3.6b)

**What it is.** SB-COR step 3.6b (`plan/SB-COR_Correction_Plan.md`) with 3.6's "Messages are not records": the roles may message each other inside this session, and nothing else. One class-high pull request adds guard rule T6 to `.claude/hooks/tool_allowlist.py` (`SendMessage` allowed only to an agent ID held in this session's registry, by the caller rules of the approach), adds `SendMessage` to the `tools:` lines of the five role files with one changed body line each, and changes the working order's section 4 step 4, section 9's `Teammates:` and section 10 through a PC-53 addendum. It depends on W-C02-25, whose registry (`<LOG_DIR>/<session_key>.agents`) and `session_key` T6 reads, and whose pull request removes the settings deny of `SendMessage` (M3a, joined there; W-C02-26 is not created, EV-C02-030 part 9). The approach was agreed in one team round (EV-C02-030 parts 2 to 9; version 1 in part 9.2, pasted below). Its acceptance condition and its test file `tools/test_send_message.py` were written by its test designer before any product.
