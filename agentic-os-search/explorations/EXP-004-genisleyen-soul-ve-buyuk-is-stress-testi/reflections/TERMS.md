# EXP-004 — Geçici terim kullanımları

Bunlar bu exploration'daki çalışma anlamlarıdır; Concepts programının kabul edilmiş ortak sözlüğü veya sektör standardı değildir.

| Terim | Bu konuşmadaki geçici kullanım |
|---|---|
| **SOUL / Base SOUL** | İş gelmeden önce var olduğu varsayılan system-forming capability bütünü; tek agent olmak zorunda değil. |
| **Expanded SOUL / Working System** | Mission/Work'e göre Actors, Information, Environment, bindings, controls, verification/recovery vb. ile genişlemiş yaşayan çalışma organizması. |
| **Mission** | Target/purpose/scope/constraints/success/authority gibi unsurları taşıyan amaç-odaklı qualified system state adayı; beşinci Foundation ground olarak kabul edilmedi. |
| **Need / Required Condition** | Hedefin gerçekleşmesi için dünyada/doğru durumda bulunması gereken koşul; otomatik Work değildir. |
| **Work** | Purpose/outcome doğrultusunda organize edilen pursuit; discovery, verification, recovery ve meta-work de Work olabilir. |
| **Work discovery** | Hangi Work/condition'ın gerekli olduğunu ortaya çıkarma faaliyeti. |
| **Work admission** | Keşfedilmiş/proposed Work'ün çalışma sisteminin gerçek active/candidate Work alanına alınması. |
| **Actionable frontier** | Mevcut standing ve constraints altında şimdi başlanabilecek Work kümesi; tek next task değil. |
| **Role** | Responsibility/capability/competence/authority/output/interface beklentilerinin paketi; Actor değildir. |
| **Actor** | Rol/participation/authority ilişkisi taşıyabilen insan, LLM agent, collective, service veya başka bearer/party. |
| **Context** | Belirli Actor + Work + situation için model/consumer-visible seçilmiş Information view; canonical store değildir. |
| **Memory** | Bu konuşmada tek store değil; persistence/history/retrieval/revision/learned knowledge gibi Information lifecycle mekanizmaları için umbrella kullanım. |
| **Run / Execution Attempt** | Bir Work'ün belirli Actor/context/environment koşullarında gerçek yürütme denemesi; candidate runtime object. |
| **Realized effect** | Action/tool call kaydından ayrı, Environment'da gerçekten oluşmuş değişim standing'i. |
| **Qualification Case** | Belirli object/revision ve claim için criterion, evidence, method/oracle, verifier, result/currentness'i bağlayan candidate work/runtime object. |
| **Acceptance / progression** | Yetkili Actor/regime'in evidence ve constraints altında bir sonraki etkiye/evreye izin veren governance kararı; truth ile aynı değil. |
| **Re-entry context** | Canonical current state + relevant history + actual environment reconciliation'dan Actor/Work için türetilen devam görünümü. |
| **Meta-work** | Object target yerine working system'in kurulması, değiştirilmesi, repair/recovery/verification yöntemi veya organization'ı üzerinde yapılan Work. |
| **Continuity** | Yalnız persistence değil; currentness, recovery, reconcile, invalidation, standing recomputation ve redispatch ile sürdürülebilir devam. |
| **Invalidation** | Daha önce current/valid sayılan representation/standing'in dependency/change etkisi nedeniyle artık doğrudan kullanılamaz veya yeniden qualification gerektirir hale gelmesi. |

Bu terimlerin isimleri Concepts çalışması veya sonraki design sırasında değişebilir.
