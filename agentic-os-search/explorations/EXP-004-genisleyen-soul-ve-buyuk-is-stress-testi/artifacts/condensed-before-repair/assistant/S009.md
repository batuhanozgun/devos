# Test 3 — Work → Capability → Role → Actor

İlk actionable frontier:

```text
W01 Curriculum source acquisition
W03 Pedagogical requirements investigation
W04 Comparable-system investigation
W06 Production-capacity assessment
W07 Publication-environment investigation
W08 Maintenance/feedback investigation
```

Yanlış yaklaşım: 6 Work → 6 agent.

Önce Work'ün gerektirdiği capability'ler çıkar.

W01 örneği:
- source discovery,
- authoritative-source discrimination,
- jurisdiction/version matching,
- retrieval,
- provenance preservation,
- ambiguity detection.

Information: target education system/grade/period/institutions.  
Environment: web/document access.  
Control: source önerebilir ama final authority ilan edemez.  
Output: candidate source + origin/version/scope/match/ambiguity.

Buradan geçici `Curriculum Source Researcher` role'u doğar.

Role'un özü isim değil:

```text
Responsibility
Capabilities
Required competence
Allowed authority
Expected outputs

Interfaces
```

Role ≠ Actor. Role'u LLM agent, human researcher, domain specialist, hybrid veya service gerçekleştirebilir.

# Capability ≠ Competence ≠ Authority

PDF okuyabilmek capability; pedagojik nüansı güvenilir değerlendirebilmek competence; official curriculum'u kabul etmeye yetkili olmak authority.

Responsibility de ayrı.

Örnek Actor:
- capable yes,
- competent provisionally yes,
- assigned W01,
- authority candidate source propose,
- responsibility research package,
- acceptance authority no.

Verifier Actor ayrı olabilir.

# Organization problemi

Altı ready Work için altı role şart değil. W01/W03/W04 bazı capabilities'i paylaşabilir; W06/W07/W08 başka küme.

Specialized structure:
Curriculum Researcher / Pedagogy / Market / Operations / Publishing / Maintenance.

Broader structure:
Domain Research Actor (W01/W03/W04) + Operations/System Actor (W06/W07/W08).

Bu Actor topology bir optimization/meta-work problemi: specialization, coordination, context transfer, independence.

Organization yeni ground değil; Actors + Bindings + Authority/Responsibility + Work assignment ile collective configuration olarak temsil edilebilir.

# Coordinator kim?

1. SOUL koordinasyonu sürdürür.
2. ayrı Coordinator Actor.
3. Coordination büyük ölçüde Work/Control substrate.

Açık soru; system steward konusuna dönecek.

# Verifier başka agent demek değil

Ayrı Actor etiketi epistemik independence sağlamaz. Same model/context/source/prompt ortak hata üretebilir. Verifier role'un oracle, source access, independence strategy, error sensitivity ve acceptance scope ihtiyacı vardır.

Actionable standing güçlenir:

```text
ACTIONABLE =
Work prerequisites satisfied
AND adequate Information available
AND qualified Actor available
AND Environment supports effect
AND Control permits effect
```

SOUL yine object work yapmadı; Work discovery/admission, capability analysis, role formation, Actor-system design/selection, authority design yaptı.

Bu, SOUL'un ana işinin object work'ten çok object work'ü yapabilecek sistemi oluşturmak/reconfigure etmek olabileceğine güçlü işaret.

Gap register: agent ≠ Actor; role ≠ Actor; capability ≠ competence ≠ authority; assignment ≠ claim; organization new ground değil; Coordinator açık; work başına Actor gerekmez; verifier başka agent değildir; SOUL tek agent olmak zorunda değil; new primitive yok.
