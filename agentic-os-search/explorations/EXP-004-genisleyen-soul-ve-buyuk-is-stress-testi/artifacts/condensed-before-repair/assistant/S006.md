# S006 — U006'ya verilen substantive cevap

---

## Test 1 — Ham talep → çalıştırılabilir Mission

Ham talep:

> Bir eğitim yılı boyunca kullanılacak kapsamlı bir 4. sınıf matematik soru bankasını üret, yayımla ve sürdürülebilir biçimde işlet.

SOUL henüz agent yaratmadı, plan yapmadı, araç seçmedi.

### İlk hata ihtimali

Normal agent hemen:

```text
1. Müfredatı araştır
2. Konuları çıkar
3. Soruları üret
4. Kontrol et
5. Yayınla
```

diyebilir. Ama neyin başarılması gerektiğini yeterince bilmiyoruz: hangi eğitim sistemi, hedef kitle, kapsam, çözümler, kullanıcı, medium, update, acceptance, pedagogy, legal/privacy?

Bunları uydurup plana geçersek çok düzenli biçimde yanlış işi yapabiliriz.

# İlk Mission taslağı

SOUL'un ilk ürettiği şey tamamlanmış Mission değil, **provisional Mission** olur:

```text
TARGET CONDITION

Bir eğitim yılı boyunca hedef 4. sınıf öğrenci/öğretmen kitlesinin
matematik öğrenme ve değerlendirme ihtiyaçlarını karşılayabilecek,
tanımlanmış müfredat/kapsamı yeterli biçimde örten,
doğrulanmış ve yayımlanmış bir soru bankasının
üretilebilmesi, kullanılabilmesi ve gerektiğinde sürdürülebilmesi.
```

Ama:

```text
MISSION STANDING = NOT YET QUALIFIED
```

çünkü target parametreleri eksik.

# Mission bile tek primitive olmayabilir

Mission için dört alan gerekiyor:

### Work
Question-bank creation / publication / operation / maintenance.

### Actors
Principal/requester, acceptance authority, domain authorities, affected parties.

### Information
Raw request, requirements, constraints, success criteria, assumptions, open questions.

### Environment
Education system, curriculum, legal, publishing, resources, time/budget/technology.

Composition:
hangi Actor hangi kararı verebilir, requirement hangi target'a bağlı, constraint hangi Work'ü sınırlar, hangi criterion hangi sonucu kabul eder?

## Bulgu 1

Mission bağımsız beşinci ground olmaktan çok:

```text
purpose/outcome-oriented Work
+
Principal / authority Actors
+
intent / requirement Information
+
situated Environment constraints
+
bindings / standing / control
```

üzerinden oluşan özel composite state olabilir.

# SOUL şimdi ne yapabilir?

Mission tam belirli değil; tüm production'a başlayamaz. Ama hiçbir şey yapamaz değil.

Work admission:

```text
W-000
Mission Qualification
```

Altında target population, curriculum authority, product/use form, acceptance regime, operating horizon ve material constraints çözme ihtiyacı olabilir. Bunların bazıları araştırma, user decision, outside authority veya ileride keşif ister; hemen klasik task list'e dönmeyebilir.

# Composition

Binding:
Principal → authorizes → SOUL to form working system; raw request → source-for → provisional Mission; open questions → block → full Mission qualification.

Standing:
Mission PROVISIONAL; W-000 ACTIONABLE; production NOT READY; curriculum info INSUFFICIENT; acceptance regime UNKNOWN.

Control:
SOUL investigate/frame/propose/structure edebilir; fakat education system seçemez, acceptance authority uyduramaz, normative pedagogical trade-off'u principal yerine kararlaştıramaz.

Transition:

```text
RAW REQUEST
→ interpreted / bounded
→ PROVISIONAL MISSION
→ decision-critical gaps identified
→ MISSION-QUALIFICATION WORK ADMITTED
```

Mission qualified'a geçmedik.

# Test sonucu

Önemli state temsil ediliyor; request received ≠ Mission understood ≠ sufficiently qualified ≠ production ready ayrımı korunuyor. Şimdi yapılabilir Work: question production değil Mission Qualification. Authority ve durable state temsil edilebilir.

Gap register:
- Mission ayrı fifth ground? **Model ambiguity; composite state adayı.**
- uncertainty/open questions new primitive? **Represented.**
- stakeholder new ground? **Hayır; Actors taşıyor.**
- decision new ground? **Şimdilik hayır.**
- Mission gate? **Mechanism need.**
- yeni fundamental primitive? **Henüz hayır.**

İlk stress sonucu: model kırılmadı ama Mission'ın bağımsız üst module yerine four grounds + Composition ile oluşan özel composite state olabileceği görüldü.

Sıradaki soru: SOUL, işin tamamını henüz bilmiyorken “ne yapılması gerektiğini” nasıl çıkarır; decomposition, prerequisite discovery, unknown work, plan, dependency, readiness ve priority nasıl ayrılır?
