## Result and native-system contribution

Consult is a useful deterministic catalog recommender: token normalization, aliases/preferences, target filtering, ranked components/profiles, reasons and next-command text. It does not investigate the project's code/needs or translate a negated requirement into an exclusion. Its score is matching, not confidence, installability or accepted capability. Profiles are not target-filtered like components, and synthetic skill-directory entries do not establish host compliance.

The actual downstream resolver adds ID/dependency/cycle/exclusion/adapter checks that the direct-module catalog filter lacks. A concrete fixed-pin contrast is framework:nextjs→framework-language: its direct targets include Codex, but its required rules-core does not. The resolver consequently skips the framework module while other baseline material can remain. The fully read Codex adapter has no custom supportsModule, so a different adapter rejection does not preempt this dependency explanation. This is source deduction, not an executed install or measured failure frequency.

Separate component names can select the same broad module; React exclusion can remove Next.js's shared module. The proposed command consumers merge project ecc-install.json selections even though consult did not read that config. A separate destination counterpart follows the actual parameters: standalone plan defaults projectRoot to ECC's source root, while install passes the current project directory. The Cursor adapter therefore exposes different R/.cursor versus P/.cursor destinations when source and caller roots differ.

These findings do not erase useful downstream controls. Standalone plan discloses its scaffold-level scope; the install dry-run elaborates actual operations and current ownership/migration/settings checks. Apply performs an explicit hook-consent assertion before mutation, then guarded operations and state/digest recording. A related profile recommendation is not consent, and a refused unapproved hook installation is not a safety failure. No universal guard/rollback/host guarantee is inferred from the inspected application call sites.

Finally, consult's schema/query/target/time is not a frozen catalog/source/destination/approval identity. Its unversioned npx command can be resolved in a different package environment. Installed source files, resolved materialization and useful host behavior remain separate objects.
