## What the inquiry established

The adapter's claimed host version was resolved to a canonical tag and independently checked package declaration. Actual host event types agree with the selected local names. Selected manifest/resource/loader/runner/session sources then connect declaration, filtering, callback registration, hook invocation and returned prompt consumption. This replaces an adapter-only field interpretation with a version-bound consumer account; it does not certify an installed binary or all application modes.

The decisive distinctions are input lifetimes and error representation. The adapter's repeated module-cached rules, one-shot factory-local context and the host's separate restored messages are different state. The first ordinary prompt receives the pending context; a later ordinary prompt starts from the base and receives rules without that original pending contribution. Internal tools/retries/queued continuation are not necessarily another before-agent-start boundary. Model/auth preflight occurs before the callback, so an initial missing-model/key failure is not a valid consumed-context-loss example.

The host's ordered callback aggregation also permits a later extension to replace the prompt after ECC clears pendingContext. The cache-backed loader can reuse a module factory while creating new extension objects, preserving the module-level rules under stated same-cwd conditions. Actual resource reload clears that cache; new process and cwd invalidation are positive alternatives. No live /new/cache/error incident was observed.

The common runner can log a missing selected hook to stderr yet return original input/exit0. The adapter does not retain that stderr and sees no additionalContext, without entering its warning branch. Missing common runner and nonzero child failures are different and do warn. The result therefore rejects both universal warning and universal silence claims.

Start/end effects were traced separately: START can create/prune files and write observer leases even with context injection off; END cleans observer leases and may signal an observer, but is not the transcript-summary writer. The host separately restores messages. No-shell invocation and warning degradation are useful process/input controls, not a sandbox or durable accepted-work protocol.
