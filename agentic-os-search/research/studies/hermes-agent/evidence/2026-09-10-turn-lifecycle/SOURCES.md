Default-branch searches returned `77e55b4d1f1d3cf2df1e8143ccacf7527b5f7cf0` for cache, keep_prompt, persistence and API helper navigation. Load-bearing observations C01–C18 were reopened at the primary pin. `tests/test_compaction_prompt_rebuild.py`, `docs/session-lifecycle.md`, `evals/gateway/session_time_persistence_controls.py` and `agent/chat_completion_helpers.py` were discovery pointers only in this slice, NOT full-read or run evidence. Failed keyword search is not absence.

Official web agent-loop documentation was searched as unpinned navigation. Divergent cached descriptions/defaults were not used as evidence for the pinned implementation. No release/version promotion.

A local attempt to materialize an already readable public source through raw download failed DNS resolution. GitHub connector reads worked; this is not source absence. Stored-response retrieval occasionally returned inconsistent/unrelated navigation content; critical C13 claims were checked with direct path/ref/line reads. No infrastructure root cause is asserted. Earlier 429 observations are historical, not assumed permanent.

## Evidence strength

This slice is **SOURCE INSPECTED + CROSS-MODULE INFERENCE**, with no new HERMES execution. It creates neither a new product PASS nor an independent replication of M4/N/A/SA/AP. Python checks used to package/check research links or hashes are publication checks, not HERMES behavior tests. The source call chain can explain a normal transition while actual event-loop, network, database, transport and concurrent faults remain unmeasured.
