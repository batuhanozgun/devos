## Reproduce without installing Hermes

Use a fresh process in a disposable copy of this folder with CPython 3.13 (recorded runtime 3.13.5/Linux). No third-party packages are required. The daemon pool imports private CPython executor internals; another interpreter/version may need adaptation and is not automatically a Hermes failure.

```sh
python harness.py --output NEW-RESULT.json > new-stdout.txt 2> new-stderr.txt
python validation_probe.py > new-validation-stdout.txt 2> new-validation-stderr.txt
python identity_check.py
```

The second and third commands overwrite their report names: **use a copy of the folder** to preserve original evidence. Runs create only in-memory fixtures, transient worker threads and temporary identity-test files. No network/model/provider/credentials/real user profile/real terminal tool is used. The marker handler only records a benign event in memory.

`upstream/` contains three complete source modules and the original MIT license. `excerpts/` holds manually selected large-module definitions with added import scaffolding; its hashes are NOT full-module upstream hashes. The complete actual modules were read through connector blob responses but not automatically materialized locally.

Optional [verify_excerpts.py](verify_excerpts.py) accepts a local complete pinned upstream tree and checks original blob identities plus selected-definition AST equality. This optional check was **not run against complete originals in this turn**; only syntax was checked. It requires no network. It is not a whole-module execution test.
