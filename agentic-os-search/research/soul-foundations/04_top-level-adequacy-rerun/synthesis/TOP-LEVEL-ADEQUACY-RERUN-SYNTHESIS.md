# Top-Level Adequacy Rerun — Integrated Synthesis

**Status:** bounded synthesis / awaiting user evaluation  
**Date:** 2026-09-05

## Executive conclusion

After all four grounds were individually deepened and evaluated, the post-deepening adequacy rerun retains the same top-level count:

```text
Environment / Operating Reality
Information / Representation
Work
Actors / Agency–Participation–Authority

+ typed relations / control / transitions
```

The result is materially stronger than the original 2026-09-02 working hypothesis because the two previously under-researched broad grounds — Environment and Information — have now been independently deepened, while Work and Actors have each survived four-ground boundary/gap audits and contemporary agentic holdouts.

No missing fifth ground, wrong-level placement, required merge/split or stronger rival survived Q0–Q5.

The strongest new conclusion is not another ground:

> **systematic typed relation/control/transition composition is now the next major Foundation research problem, if separately authorized after user evaluation.**

---

## 1. Why the rerun was necessary

The earlier adequacy result was explicitly a working hypothesis and left major research debt:

- Environment parent semantics and hierarchy required deeper validation;
- Information above Records required independent first-principles research;
- Work and Actors had not yet been re-tested under the completed four-ground boundaries;
- relation/control was recognized as necessary fabric but not yet pressure-tested against deep ground results.

All of those conditions changed during `03_ground-deepening/`.

Therefore simply inheriting the old adequacy result would have violated its own reopen conditions.

---

## 2. Current ground anchors

### Environment / Operating Reality

Protected question:

> What actual realized domain and Work-condition reality obtains, independently of how it is represented, pursued or attributed?

Accepted internal structure distinguishes Domain Reality from Work Conditions, with deeper State/Structure/Condition/Dynamics regions and Technical Work Environment as a deep support profile.

### Information / Representation

Protected question:

> What mediated informational state exists, what does it represent, and how is it formed, derived, changed or exposed independently of the represented reality?

Accepted internal structure distinguishes Informational State from Informational Dynamics and retains Records as a persistence specialization/profile.

### Work

Protected question:

> Which pursuits toward outcomes are selected, structured, admitted, enacted, coordinated, evaluated, adapted, concluded or recovered over time?

Work remains a rich multidimensional ground without a universal immediate-child hierarchy.

### Actors / Agency–Participation–Authority

Protected question:

> Which bearers/positions/parties are implicated and how are identity, standing, participation, authority/obligation, representation/delegation and attribution/responsibility distributed across them?

Actors remains a relational/multi-anchor ground without a universal immediate-child hierarchy.

## 3. Exhaustiveness result

Potential fifth grounds were re-tested after deepening:

- Goal / Outcome / Value / Criteria;
- Governance / Norms / Policy / Control;
- Relations / Interaction / Composition;
- Capability / Actionability;
- Parties / Stakeholders;
- Time / Continuity / Evolution;
- Verification / Assurance;
- generic State / Process / Causation;
- Learning / Knowledge.

None remained a stable first-order peer.

The recurring reason is not that these concerns are unimportant. It is that each decomposes into semantically distinct facts anchored in the four grounds plus typed cross-ground relations.

Example — verification/acceptance:

```text
verification activity         → Work
evidence / result             → Information
actual target condition       → Environment
verifier / acceptance authority → Actors
supports / verifies / accepts → relation/control fabric
```

---

## 4. Level-alignment result

Each ground survived attempts to reduce it into the other three.

### Environment is not reducible

Reality can change while Work, Actors and representations remain fixed.

### Information is not reducible

False, stale, conflicting, hypothetical and selectively exposed representations have identity and transition semantics not recoverable from their referents.

### Work is not reducible

With the same Actors, Environment and Information, a pursuit can be selected/rejected, admitted/not admitted, decomposed differently, paused, recovered or terminated differently.

### Actors is not reducible

With the same Work, Environment and informational artifacts, authority, obligation, role occupancy, delegation and accountability can change.

No pairwise merge preserves these distinctions.

---

## 5. Boundary-interaction result

The strongest interactions reinforce rather than dissolve the ground boundaries.

Key anti-collapse rules:

```text
actual reality != representation
Work state != representation of Work
Actor standing != representation of standing
Actor capability != Environment actionability
Work admission != Actor obligation / authority
Work completion != Environment outcome
technical effect power != legitimate authority
verification evidence != authorized acceptance
```

These cases reveal a major next-phase need: derived standings and transitions that depend on several grounds simultaneously.

Examples:

- actionability;
- effective/transitive authority;
- goal/outcome directedness;
- verification/validation/acceptance;
- causal attribution/accountability;
- feedback/learning/evolution.

They do not currently require a fifth anchor.

---

## 6. Materially different domain holdouts

Targeted cross-domain holdouts were used to avoid software/agentic overfit.

### Metrology / scientific measurement

BIPM/JCGM VIM independently distinguishes measurement procedure/process, measurement result and measurand/conditions. This fits the Work–Information–Environment separation; operator/role semantics can remain Actors when material.

### Emergency management

FEMA/NIMS distinguishes actual incident/resource conditions, situational awareness, objective-directed planning/execution and command/delegation structures. Goal and governance pressures remain cross-ground rather than new peers.

### Healthcare / patient safety

WHO distinguishes actual patient/system harm, incident-report information, care/improvement activity and health-worker/patient/family/leadership involvement. Learning and stakeholder pressure do not force new grounds.

### AI risk governance

NIST AI RMF distinguishes governance roles/policies, mapping/measurement/management activity, documentation/evidence and actual deployed context/performance. `Govern` is explicitly cross-cutting in that framework, which is compatible with governance as composition/control pressure rather than proof of a peer ground.

These sources do not validate the project's exact synthesis, but they provided materially different failure opportunities and did not break it.

## 7. Rival decompositions

Tested rivals included:

```text
State / Process / Agent / Representation
World / Intent / Action / Knowledge / Agency
Environment / Information / Activity / Parties / Norms
Resources / Work / Actors / Artifacts / Governance
four grounds + Relations/Control peer
four grounds + Goal/Value peer
relation/event-only network
Domain / Representation / Pursuit / Agency
```

The main rival failures were:

- formal State/Process axes mix different semantic loci;
- Action/Activity weakens the deliberate-pursuit semantics of Work;
- Intent/Norm/Governance reify cross-ground relations into residual buckets;
- Resources/Artifacts are too narrow for general-purpose Environment/Information;
- relation-only views lose protected anchors;
- near-isomorphic renamings do not improve structure enough to justify churn.

## 8. Naming result

Current labels remain serviceable with explicit semantic warnings:

### Environment / Operating Reality

Not `everything outside` and not generic Context.

### Information / Representation

Does not imply truth, knowledge or persistence.

### Work

Not task-only or simple execution lifecycle.

### Actors / Agency–Participation–Authority

Not active-doers-only and not one universal Actor primitive.

A later composition phase may create evidence for naming refinement — especially around `Standing` versus `Authority` in the Actors label — but no rename is currently structurally required.

## 9. The new Foundation frontier

The rerun changes the project’s uncertainty profile.

Before deepening:

> Are these really the right top-level grounds?

After deepening and rerun:

> The grounds are boundedly stable; how must they be composed so their local distinctions survive real system reasoning?

Likely composition research regions include:

1. **directedness / goal / outcome / criteria**;
2. **Work–Actor participation / obligation / authority**;
3. **capability / access / actionability / effective power**;
4. **observation / representation / referent binding**;
5. **dependency / coordination / resource support**;
6. **evidence / verification / validation / acceptance**;
7. **provenance / attribution / accountability**;
8. **target / effect / causation**;
9. **delegation / access / enforcement / transitive authority**;
10. **feedback / learning / evolution / control adaptation**.

This is an orientation list, **not** an authorized taxonomy or composition architecture.

## 10. Epistemic status

### Boundedly supported

- four top-level ground anchors remain distinct and useful;
- no fifth peer is currently forced;
- no current ground is safely reducible or mergeable;
- no tested rival is stronger;
- materially different external holdouts preserve the distinctions;
- systematic relation/control/transition research is a distinct next problem rather than another ground.

### Still unresolved

- final typed relation/control taxonomy;
- composition semantics and derived standings;
- whether later composition exposes a ground-level falsifier;
- final naming refinements;
- formal representation/ontology;
- architecture and implementation.

### Verification limit

The integrated rerun is same-researcher synthesis. It is source-backed and adversarially challenged but has **not** received independent second-researcher/model replication. No external source validates the exact four-ground frame.

## Final bounded answer

> **Environment / Operating Reality, Information / Representation, Work, and Actors / Agency–Participation–Authority remain the strongest current top-level Foundation research grounds after recursive deepening and a fresh adequacy rerun.**
>
> **The next unresolved Foundation problem is how these grounds compose through typed relations, controls and transitions. That later phase must be separately planned and authorized.**
