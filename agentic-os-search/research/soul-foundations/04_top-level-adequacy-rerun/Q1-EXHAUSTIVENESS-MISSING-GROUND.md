# Top-Level Adequacy Rerun — Q1 Exhaustiveness / Missing-Ground Test

**Status:** COMPLETE  
**Date:** 2026-09-05

## 1. Question

After deepening all four accepted grounds, is there a recurring first-order problem that can only be handled by stretching the current frame and therefore deserves a fifth peer ground?

Decision rule: a candidate becomes a peer only if it is simultaneously:

- first-order and load-bearing;
- semantically coherent enough to have a protected question of its own;
- not reducible to one current ground plus typed cross-ground relations;
- stable across materially different domains;
- not merely a criterion, mechanism, relation family, lifecycle qualifier or architecture/control implementation.

## 2. Candidate A — Goal / Outcome / Value / Criteria

### Why it looks like a missing ground

Work without direction is under-specified. Selection, priority, completion and validation all appear to depend on goals, desired outcomes, value or criteria.

The Work audit itself retained purpose/outcome as load-bearing and explicitly deferred its cross-ground placement.

### Attempted protected question

> What is wanted, preferred, valuable or counted as success independently of actual reality, representation, Work pursuit and Actor standing?

### Failure of peer-ground interpretation

The candidate does not remain one stable semantic kind across cases.

Different aspects resolve to different existing grounds:

- **Work:** pursuit direction, candidate selection, priority, stopping and outcome-oriented organization;
- **Environment:** the actual realized target condition and criterion-relative standing of reality;
- **Information:** desired-state specifications, acceptance criteria, forecasts, estimates and evidence about attainment;
- **Actors:** preference, value judgment, obligation, mandate and authority to define/accept outcomes.

A goal can be represented in Information without the Work being committed. An Environment condition can satisfy a criterion without any Actor valuing it. An Actor can prefer an outcome without Work existing yet. Work can be directed to an outcome whose current realization is unknown.

### Result

**NOT a fifth ground.**

`Goal / Outcome / Value / Criteria` is a high-priority cross-ground direction/evaluation family. Its semantic plurality is evidence against treating it as one peer bucket.

Reopen if later composition cannot preserve a coherent directed-Work relation without introducing an irreducible fifth locus.

## 3. Candidate B — Norms / Policy / Governance / Control

### Why it looks like a missing ground

SOUL / Development OS depend heavily on permissions, policies, gates, verification rules, deterministic controls, human authority and enforcement.

### Attempted protected question

> What governs or constrains what may/must happen and how compliance/control is established?

### Decomposition under the accepted grounds

- **Actors:** authority, permission, obligation, mandate, accountability and delegation;
- **Information:** policy/rule text, control configuration, evidence, decision/approval representation;
- **Work:** governance/review/verification/approval/control activities and required transition gates;
- **Environment:** realized enforcement mechanisms, access/resource constraints, runtime controls and actual institutional/operating conditions;
- **relations/control composition:** which Actor/Work/Environment/Information combinations authorize, block, require, verify or admit a transition.

A written policy can exist without being authoritative. Authority can exist without a particular document. A runtime can mechanically block an action without defining the normative reason. A Work gate can be required while the Environment enforcement is absent.

### Result

**NOT a fifth ground.**

`Governance/Control` remains indispensable composition fabric, but one peer ground would mix normative standing, informational rules, Work control activities and realized enforcement.

The newer Actors result makes this especially clear:

```text
legitimate authority != reachable effect power != runtime enforcement outcome
```

## 4. Candidate C — Relations / Interaction / Composition

### Why it looks like a missing ground

Every ground produced a rich deferred-relation ledger. Authority, provenance, dependency, observation, target/effect, verification, delegation and feedback are load-bearing.

### Attempted protected question

> How are foundational things related and how do their combinations generate system-level meaning?

### Failure of peer-ground interpretation

This is a **composition question about the ground set**, not another ground at the same analytical level.

The relation families are heterogeneous:

- Work dependency is not the same semantic family as Actor authority;
- Information provenance is not the same as Environment causation;
- observation is not the same as delegation;
- access is not the same as verification;
- temporal transition is not the same as accountability.

A generic `Relations` peer would therefore become a meta-container for typed edges whose semantics still derive from the things connected.

### Result

**NOT a fifth ground.**

Relations/control/transitions are now strongly justified as the **next research phase** if adequacy closes, not as a fifth peer ground.

## 5. Candidate D — Capability / Actionability / Resources

### Why it looks like a missing ground

Effective action depends on more than Actor competence and more than Environment availability. Modern agentic cases expose multi-hop effect paths, credentials, tools, delegation and runtime constraints.

### Attempted protected question

> What can actually be done here and now?

### Decomposition

Situated actionability is relationally derived from at least:

- Actor capability/competence;
- Actor permission/authority where relevant;
- Environment resource/interface/access/current-condition availability;
- Work method/requirements and current pursuit state;
- Information about the target, permissions and current conditions;
- control/path topology for indirect effects.

Critical counterexample:

```text
Actor capable
+ Environment blocks access
→ not actionable

Actor lacks legitimate authority
+ reachable privileged agent/tool path
→ technically effective but not legitimately authorized
```

### Result

**NOT a fifth ground.**

Actionability/effective power is a derived cross-ground standing, not an independent peer problem region.

## 6. Candidate E — Parties / Stakeholders / Affected Subjects

### Why it looks like a missing ground

The `Actors` label can misleadingly suggest only active doers, while beneficiaries, rights holders, recipients, principals, affected parties and accountability forums can matter without performing action.

### Current Actors correction

The accepted Actors formulation already widened the region to persistent bearers/positions/parties and typed standing/participation/authority/attribution relations. It explicitly rejects `Actor = active performer`.

`Stakeholder`, `beneficiary`, `affected party` and `rights holder` are typically **relations/positions of a bearer relative to Work, outcome, domain state or normative regime**, not a separate substance.

### Result

**NOT a fifth ground.**

There is a naming pressure on `Actors`, but no current evidence for `Actors + Parties` as separate peers.

Potential future rename such as `Agency / Participation / Standing` remains a Q5/Q6 naming question, not a structural fifth-ground finding.

## 7. Candidate F — Time / Continuity / History / Evolution

### Why it looks like a missing ground

Every ground contains time-sensitive semantics:

- Environment State/Dynamics, path dependence and boundary change;
- Information freshness, version, revision, persistence and Records;
- Work lifecycle, recurrence, continuation and recovery;
- Actor identity/role/delegation/authority continuity.

SOUL also aims to evolve from feedback and failure.

### Attempted protected question

> What persists or changes through time and how does the system evolve?

### Failure of peer-ground interpretation

`Time` is a qualifier/reference dimension across the four grounds, not a stable domain of one semantic type.

`Continuity` means different things by ground:

- identity continuity;
- Work continuation;
- persistence/history of Information;
- state/dynamic continuity of Environment.

Likewise `Evolution` is composite:

```text
Environment change / incident
→ Information formation / evidence
→ Work generation / adaptation
→ Actor decision / authority
→ new Environment / Information / Work / Actor standing
```

### Result

**NOT a fifth ground.**

Evolution is a high-value later transition/composition pattern, not a peer ground under current evidence.

## 8. Additional recurring candidates checked

### Verification / Evidence / Assurance

Not a peer ground.

- verification/validation activity → Work;
- evidence/results/claims → Information;
- target condition → Environment where applicable;
- authority/acceptance/accountability → Actors;
- exact binding and transition semantics → composition/control.

### Identity / Standing

Already first-order Actors semantics, with represented identity/standing separated into Information.

### State / Change / Causation

Actual realized state/change is strongly Environment-side when about reality; represented state/change is Information; Work has pursuit state; Actors have standing state. Generic `State` as a peer would collapse these different meanings.

### Learning / Knowledge

Informational change, model/representation formation and retained Records are Information-side; deliberate learning/training is Work; changed capability can be Actor- or Environment-side depending referent; governance/admission is composition.

No stable fifth peer emerges.

## 9. Q1 adversarial summary

The strongest apparent omissions are **not trivial**. Goal/value, governance/control and relations are necessary to later SOUL reasoning.

But necessity is not sufficient for peer-ground status.

Across materially different cases, each candidate either:

1. decomposes into semantically distinct facts already protected by the four grounds;
2. is a typed relation/derived standing across them;
3. is a qualifier such as time/risk/value;
4. is a later control/composition problem;
5. or is a naming pressure rather than a missing problem region.

## 10. Q1 verdict

> **No fifth top-level ground is currently forced by the post-deepening omission set.**

This is a bounded result, not universal exhaustiveness proof.

The four-ground frame survives Q1's exhaustiveness test.

Remaining pressure moves to Q2:

- perhaps one of the four current grounds is at the wrong level;
- perhaps two should merge;
- perhaps one should split;
- perhaps a stronger rival decomposition preserves the same phenomena with less boundary complexity.
