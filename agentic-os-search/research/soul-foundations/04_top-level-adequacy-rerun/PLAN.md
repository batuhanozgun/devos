# Top-Level Adequacy Rerun — Plan

**Status:** active plan  
**Date:** 2026-09-05

## Objective

Re-test the accepted four-ground Foundation hypothesis **after** Environment, Information, Work and Actors have each been individually deepened/evaluated.

Current accepted grounds entering the rerun:

```text
Environment / Operating Reality
Information / Representation
Work
Actors / Agency–Participation–Authority
```

The question is not whether these labels are convenient. The question is whether, at the current Foundation purpose and depth, they still form the strongest bounded top-level problem-ground frame without hiding a missing peer ground, forcing a wrong level alignment, or depending on boundary theft.

## Non-goals / guardrails

This rerun does **not** yet perform systematic typed relation/control/composition research.

Relations may be used only as falsifiers and boundary pressure, e.g.:
- if `Actor ↔ Work` cannot be described without inventing a fifth problem ground, adequacy may be broken;
- if the relation is expressible as composition among accepted grounds, record it for later and do not solve the composition now.

Do not infer architecture, ontology/data model or implementation from this pass.

## Q0 — Canonical evidence recovery

Recover:
- original `02_adequacy/` accepted working hypothesis and its falsifiers;
- final accepted Environment current surfaces;
- final accepted Information current surfaces;
- final accepted Work current surfaces;
- final accepted Actors current surfaces;
- ground-local deferred relations / reopen triggers;
- candidate studies only where they provide materially different holdouts.

Output:
- exact evidence inventory;
- differences between the original adequacy hypothesis and the now-deepened grounds;
- live rerun hypotheses.

## Q1 — Exhaustiveness / missing-ground test

Ask whether any recurring first-order problem now fits only by stretching one of the four grounds.

Pressure candidates include, but are not limited to:
- goal/value/criteria;
- policy/norms/governance/control;
- relations/interactions/composition;
- capability/actionability;
- state/change/causation;
- stakeholders/affected parties;
- verification/evidence;
- time/continuity;
- identity/standing;
- learning/adaptation/evolution.

A candidate becomes a fifth ground only if it is:
- first-order and load-bearing;
- not reducible to one existing ground plus typed cross-ground relations;
- stable across materially different domains;
- not merely a mechanism, role, criterion, relation family or architecture concern.

## Q2 — Level-alignment / reduction test

For each accepted ground, try to show it is at the wrong top level.

### Environment
Can it be reduced to state/capability relations owned elsewhere, or is actual operating reality irreducible?

### Information
Can it be reduced to descriptions of the other grounds, or does mediated representation remain irreducible?

### Work
Can it be reduced to Actors acting in Environment over Information, or does pursuit organization/evolution remain irreducible?

### Actors
Can it be reduced to Work participation + Environment capability + Information identity, or do bearer/standing/authority/attribution relations remain irreducible?

Also test whether any two grounds should merge or whether one should split at top level.

## Q3 — Boundary-interaction pressure without composition

Use the strongest deferred relation cases as adversarial tests, not as a relation taxonomy project.

Priority cases:
- Actor ↔ Work: participation, assignment, obligation, authority, acceptance;
- Actor ↔ Environment: capability, access, actionability, effective power;
- Actor ↔ Information: identity/standing evidence, delegation, epistemic authority;
- Work ↔ Environment: target/effect, readiness, actual outcome;
- Work ↔ Information: plan/status/evidence vs actual Work;
- Information ↔ Environment: representation vs referent, observation/acquisition;
- multi-ground: verification/acceptance, effective/transitive authority, feedback/evolution.

Decision rule:
- if a relation exposes a missing ground, reopen adequacy;
- if it only needs typed composition, defer it to the later relation/control phase.

## Q4 — Materially different holdouts

Use a small set of materially different cases to test the frame, rather than accumulating examples.

Candidate case families:
- software/agentic systems;
- organizational/institutional work;
- scientific/investigative work;
- continuing operational/service work;
- non-human / multi-agent participation;
- high-impact governed action.

Candidate studies can be reused selectively as holdouts, never as taxonomy authority.

## Q5 — Rival top-level decompositions

Attack the four-ground frame with serious alternatives, for example:
- State / Process / Agent / Representation;
- World / Intent / Action / Knowledge / Agency;
- Environment / Information / Activity / Parties / Norms;
- Resources / Work / Actors / Artifacts / Governance;
- relations/control as a fifth peer ground;
- goal/value as a fifth peer ground.

Do not reject rivals merely because they use different words. Compare explanatory loss, boundary stability, level alignment and reuse across domains.

## Q6 — Bounded closure

Possible outcomes:

### Outcome A — four-ground frame survives

Return a refreshed bounded adequacy judgment and explicitly authorize only user evaluation.

### Outcome B — refinement without new ground

Rename/re-scope/re-parent one or more grounds while preserving the four-ground count, then return for evaluation.

### Outcome C — material adequacy falsifier

Open only the minimum additional Foundation research needed to resolve the falsifier. Do not proceed to relation/control composition.

## Stage exit

Only after user evaluation of the rerun may the project decide whether systematic typed relation/control/composition research should begin.
