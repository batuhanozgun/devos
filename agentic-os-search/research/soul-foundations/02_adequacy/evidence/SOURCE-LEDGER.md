# E. External / cross-lineage holdouts

## E1 — W3C PROV Data Model

Source:
`https://www.w3.org/TR/prov-dm/`  
Grade: **P2 — W3C specification**

Direct support:
- provenance core distinguishes Entity, Activity and Agent plus typed relations;
- Entity can be physical, digital, conceptual or other;
- Activity uses/produces entities;
- agents bear responsibility.

Use in inquiry:
- independent convergence with Work/Actors/representation-like separation;
- shows persistent Record is narrower than all possible entities/things;
- supports relation centrality.

Does not prove:
- SOUL should implement PROV;
- Entity/Activity/Agent is a complete ontology for SOUL.

## E2 — Work System Theory (Steven Alter)

Sources:
- `https://repository.usfca.edu/at/36/`
- `https://aisel.aisnet.org/cais/vol9/iss1/6/`

Grade: **P3 — established IS/work-system research**

Direct support:
- work-system framework includes processes/activities, participants, information, technology, products/services, customers, environment, infrastructure and strategies;
- processes/activities, participants, information and technology recur as central/internal system elements in the broader WST tradition.

Use:
- cross-lineage convergence with current problem grounds;
- challenge that `information` is broader than persistent Records;
- evidence that environment/infrastructure/context can matter without being reducible to activities/participants/information.

## E3 — Cognitive Work Analysis / Work Domain Analysis

Sources:
- Defence Science and Technology Organisation, Naikar, `Cognitive Work Analysis: Foundations, Extensions, and Challenges`: `https://www.dst.defence.gov.au/sites/default/files/publications/documents/DSTO-GD-0680%20PR.pdf`
- Oxford Handbook overview: `https://academic.oup.com/edited-volume/34402/chapter-abstract/296618307`
- University of Southampton CWA example: `https://eprints.soton.ac.uk/367346/`

Grade: **P2/P3 — defence research report + academic/peer-reviewed tradition**

Direct support:
- CWA distinguishes work-domain constraints, control tasks, strategies, social organization/cooperation and worker competencies;
- WDA analyzes physical/social/cultural environment/purposes/resources separately from subsequent task/strategy/actor analyses.

Use:
- strong independent support for Work Domain / Operating World as a first-order analysis region not reducible to Work or Actors.

## E4 — STAMP / STPA

Source:
STAMP Institute, `https://home.stamp-institute.com/about-stamp/`

Grade: **P2/P3 institutional summary of established system-safety framework**

Direct support:
- controller, controlled process, control action, process model and feedback are separated;
- controller decisions can be unsafe when process model/feedback does not match true process/environment state;
- safety is an emergent property of interactions/control structure rather than one component property.

Use:
- world/process state ≠ feedback ≠ internal model;
- relation/control fabric is load-bearing;
- `Control` need not be a peer substance.

## E5 — NASA Systems Engineering Handbook

Source:
`https://www.nasa.gov/reference/2-0-fundamentals-of-systems-engineering/`

Grade: **P2 — NASA institutional guidance**

Direct support:
- system value arises materially from relationships/interconnections among parts;
- systems engineering must meet requirements in intended use environment;
- verification and validation have different objectives, with validation tied to intended purpose/environment.

Use:
- supports relation-centric composition, intended-use environment and verification/validation distinction.

## E6 — BDI agent programming

Use:
