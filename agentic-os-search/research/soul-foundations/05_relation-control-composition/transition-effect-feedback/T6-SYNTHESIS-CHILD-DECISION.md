## 1. Executive synthesis


These are **diagnostic research problem regions**, not mutually exclusive event classes.

## 2. Parent protected question

> How do actual changes/effects propagate across accepted Foundation grounds over time; which causal contributions explain realized effects; and when do observations/results return to alter subsequent system behavior, possibly persistently?

The parent is cross-ground only. It is not the universal home of all dynamics, causation or feedback.

## 3. Critical routing boundary

Environment already owns `Domain Dynamics`; Information owns `Informational Dynamics`; Work owns pursuit/execution evolution; Actors owns participation/authority/delegation semantics.

Therefore:

```text
ground-local dynamics
!= Cross-Ground Transition / Effect / Feedback by identity
```

Use a semantic-removal test similar to Composite Standing:

> If all other-ground anchors/relations were removed while preserving the local bearer/process, would the protected temporal/effect question retain the same meaning?

If yes, keep it ground-local. If no, cross-ground composition is load-bearing.

## 4. Child A — Cross-Ground Transition / Propagation

### Protected question

> What actually changed/unfolded across ground boundaries, at what anchors/scopes/times, and how fully did the change propagate or fail to propagate?

### Stable semantic core

```text
Cross-Ground Transition / Propagation
├─ exact changed/affected focus + Binding instances
├─ transition/change identity and semantic resolution
├─ relevant prior/baseline and realized after/trajectory semantics
├─ occurrence/effective/reference time where material
├─ propagation path/scope/dependencies where material
├─ partiality / delay / convergence / rollback / compensation possibilities
└─ observation/evidence kept separate from occurrence
```

### Distinct failure family

- command/change recorded but not realized;
- realized locally but not propagated;
- partial/stale distributed state;
- wrong target/version/scope;
- occurrence versus observation time collapsed;
- transient effect mistaken for persistent effect;
- standing/control dependency changed without correct invalidation/re-evaluation routing.

### Strong non-collapse

```text
change requested != change committed != change effective everywhere
recorded event != actual occurrence
Work executed != realized Environment effect
intended effect != realized effect
```

## 5. Child B — Cross-Ground Causal Effect / Contribution

### Protected question

> Which actions/events/conditions/controls/Work/Actor contributions caused, enabled, amplified, prevented, or failed to prevent/detect a realized cross-ground effect, with what evidential confidence and causal depth?

### Stable semantic core

```text
Cross-Ground Causal Effect / Contribution
├─ exact effect being explained
├─ candidate causal contributors + typed roles
├─ temporal/structural eligibility
├─ mechanism/intervention/counterfactual/association evidence as available
├─ contributing/enabling/prevention/detection/systemic layers where material
├─ competing causal explanations
└─ calibrated causal confidence / unresolved alternatives
```

Foundation does not require every domain to use the same causal inference method.

### Distinct failure family

- sequence mistaken for causation;
- trigger mistaken for root/systemic cause;
- correlation/association mistaken for effect;
- enabling condition omitted;
- prevention/detection failure omitted;
- one `root cause` forced where several contributors matter;
- control-effectiveness claim inferred from presence rather than causal impact.

### Strong non-collapse

```text
A before B != A caused B
trigger != sufficient cause
proximate cause != complete causal explanation
one cause identified != complete causal model
control present/complied-with != control causally effective
```

## 6. Child C — Cross-Ground Feedback / Adaptation

### Protected question

> Did observations/results/effects return across ground boundaries to alter later Work, Control, Actor behavior, Information selection/configuration or Environment interaction; and did they only influence one response or persistently change the response-generating system?

### Stable semantic core

```text
Cross-Ground Feedback / Adaptation
├─ source effect/observation/result
├─ return path into decision/work/control/behavior
├─ consumption/evaluation of returned information
├─ resulting later action/control/configuration change
├─ evidence that future behavior actually differs
└─ persistence/adaptation scope where claimed
```

### Distinct failure family

- telemetry/report mistaken for feedback;
- report exists but no consumer/action path;
- one-off response called learning;
- lesson documented but system unchanged;
- control/configuration changed but not deployed/effective;
- adaptation present but not beneficial;
- repeated incidents despite claimed learning.

### Strong non-collapse

```text
observation != feedback
feedback signal != feedback consumed
feedback loop != learning
one response != persistent adaptation
lesson recorded != learned system
adaptation occurred != adaptation improved outcome
```

## 7. Why these are immediate children rather than profiles

The promotion threshold is met because each child has:
- a distinct protected question;
- distinct falsifiers;
- distinct evidence requirements;
- distinct corrective/recovery Work when uncertain or failed;
- cross-domain recurrence;
- irreducibility to one accepted ground or sibling.

The children can co-occur in one episode. The hierarchy is diagnostic, not a partition of events.

## 8. Why no fourth child is promoted

### Temporal Alignment
Cross-cutting dimension across all three.

### Observation / Monitoring
Information formation/exposure + Binding; feedback asks whether the return path affects future behavior.

### Recovery / Compensation
Work owns the recovery activity; Transition owns realized propagated changes.

### Evolution
Persistent adaptation is the deep end of Feedback/Adaptation; not every feedback loop evolves.

### Provenance
Primarily Information/Binding evidence of transition/attribution.

### Intended / Realized / Observed
Mandatory dimensions/non-collapse, not stable protected regions.

### Control Effectiveness
A high-value Causal Effect/Contribution + Standing profile, not a separate child.

## 9. Cross-cutting semantic dimensions
