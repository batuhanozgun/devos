# Cross-Ground Transition / Propagation — P4 Rival Internal Decompositions

**Status:** COMPLETE  
**Date:** 2026-09-06

## 1. Objective

Attack the emerging bounded-leaf hypothesis by testing materially different internal decompositions. A split is promoted only if its branches have stable protected questions, distinct failure families/evidence needs, cross-domain recurrence and minimal duplication of accepted grounds/siblings.

## 2. Rival A — Realization / Propagation / Convergence

```text
Transition / Propagation
├─ Realization
├─ Propagation
└─ Convergence
```

### Strength

Intuitive in distributed/configuration-change systems.

### Failure

- Realization is the semantic core of any transition claim; without it there is no child object.
- Propagation is the defining cross-ground shape rather than a separable sibling population.
- Convergence is not universal and usually depends on a scope/criterion, making `converged/fully propagated` a Standing over transition facts.
- Some correct systems intentionally remain heterogeneous.

**Verdict:** reject as immediate-child hierarchy.

## 3. Rival B — Transition Identity / Propagation Scope / Recovery

```text
Transition / Propagation
├─ Change Identity
├─ Scope / Propagation
└─ Recovery / Reversal
```

### Strength

Highlights exact-target and rollback problems.

### Failure

- change identity and scope are mandatory/conditional signature dimensions, not independent problem populations;
- recovery is primarily Work plus further realized transitions;
- restored/acceptable result is Standing;
- one episode can simultaneously have all three.

**Verdict:** reject.

## 4. Rival C — Requested / Realized / Observed

```text
Transition / Propagation
├─ Requested / Intended
├─ Realized
└─ Observed / Recorded
```

### Strength

Directly prevents representation/action/result collapse.

### Failure

This is not a same-level child structure:
- request/intention can be Information/Actors/Work;
- realization is Transition;
- observation/record is Information Dynamics/State.

The distinctions are mandatory non-collapse relations across accepted regions, not Transition children.

**Verdict:** reject strongly.

## 5. Rival D — Atomic / Partial / Compensated

```text
Transition / Propagation
├─ Atomic
├─ Partial
└─ Compensated
```

### Strength

Captures operationally important failure/recovery modes.

### Failure

- categories are not exhaustive or mutually exclusive;
- `atomic` is often an implementation/transaction property;
- partiality is multi-dimensional;
- compensation is a later Work + transition episode, not a peer transition species;
- continuous changes do not fit cleanly.

**Verdict:** retain as profiles/dimensions only.

## 6. Rival E — Forward Change / Reconciliation

```text
Transition / Propagation
├─ Forward Propagation
└─ Reconciliation / Recovery
```

### Strength

Useful operational lifecycle in eventually consistent systems.

### Failure

- reconciliation is Work, not realized change by identity;
- successful repair creates further transitions;
- `forward` versus `recovery` depends on intent/reference frame;
- compensation may intentionally move to a new acceptable state rather than return backward.

**Verdict:** reject.

## 7. Rival F — Local / Cross-Ground / Systemic

```text
Transition
├─ Local
├─ Cross-Ground
└─ Systemic
```

### Failure

Local dynamics are already owned by accepted grounds. The active child is deliberately cross-ground only. `Systemic` is a scale/coverage judgment rather than a stable peer.

**Verdict:** reject; would reopen already-settled boundary theft.

## 8. Rival G — Source Change / Dependency Propagation / Target Effect

### Strength

Models a causal-looking propagation chain.

### Failure

- not every transition has a unique source;
- dependency edges have heterogeneous meanings;
- target effect can itself trigger further propagation;
- source/target role can reverse by question;
- quickly leaks into sibling Causal Effect/Contribution.

**Verdict:** retain as one possible episode profile, not hierarchy.

## 9. Rival H — Transition / Invalidation

### Strength

Stale Standing/Control is operationally high value.

### Failure

Invalidation is not one uniform realized transition:
- a dependency change may stale an assessment;
- change object-level standing;
- alter criterion applicability;
- require re-evaluation without changing truth;
- have no material consequence.

Transition owns dependency change; Standing/Control own the resulting current qualification/applicability.

**Verdict:** reject.

## 10. Rival I — Materialized / Derived propagation

### Strength

Distinguishes copied state from recomputation.

### Failure

This is architecture/representation strategy leakage. Foundation cannot assume standings/controls are materialized, cached, recomputed or event-driven.

**Verdict:** reject strongly.

## 11. Rival J — State Jump / Continuous Trajectory

### Strength

Prevents discrete-event bias.

### Failure

Hybrid and scale-dependent systems can exhibit both; the distinction is a temporal/dynamic representation dimension already familiar from Domain Dynamics.

**Verdict:** retain as dimension, not child.

## 12. Cross-rival comparison

A child split would need to explain more than the current shared grammar:

```text
exact changed focus
+ transition identity
+ reference/trajectory
+ realized scope
+ time/order where material
+ typed propagation/dependency
+ partiality/persistence/reversibility where material
+ observation separation
```

No rival produces stable sibling populations without either:
- treating the core as a child;
- importing another ground's semantics;
- turning a Standing into Transition;
- promoting Work/recovery operations;
- or leaking architecture vocabulary.

## 13. P4 provisional judgment

```text
Cross-Ground Transition / Propagation
    ← strongest current hypothesis: BOUNDED LEAF
    ← no immediate child currently justified
```

P5 must now attack this result using authoritative, materially different external holdouts and selected candidate studies. A single strong counterexample can reopen the split.
