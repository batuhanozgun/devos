4. **Multi-origin episodes:** how should concurrent/mutually dependent changes be grouped without implying one authoritative source?
5. **Supersession:** when does a later change supersede an earlier transition versus create a new independent scoped state?
6. **Observation gaps:** what evidence is sufficient to distinguish `not changed` from `not observed` across materially different domains?
7. **Unknown realization:** when evidence is incomplete, which transition facts can remain unknown rather than forcing a lifecycle status?

10. **Institutional effectiveness:** how should effective-date, implementation and compliance timing interact when governing effect and actual behavior diverge?

14. **Independent replication:** would an independent researcher/model retain bounded-leaf status and the same routing boundaries?

- materially different domains require a universal distinction not expressible by the shared transition/propagation grammar;

## Non-reopen conditions

Do not reopen merely because:
- one implementation uses eventual consistency;
- one domain needs many rollout states;
- one system stores materialized propagation status;
- a rollback/compensation workflow is complex;
- one transition uses continuous rather than discrete time;
- multiple timestamps are needed;
- target scope is large;
- architecture later chooses sagas, event sourcing, transactions, message buses, reconciliation loops or policy distribution systems.
