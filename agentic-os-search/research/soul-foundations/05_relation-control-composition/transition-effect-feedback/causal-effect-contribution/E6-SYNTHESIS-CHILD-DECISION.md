> For an exact realized cross-ground effect or defined outcome transition, what causal claims are justified about contributors to the observed episode and about how changing candidate causes/controls/actions would alter outcomes under relevant alternatives?

## 3. Shared causal grammar

Both children inherit:

```text
Causal claim
├─ exact effect / outcome / explanandum
├─ candidate cause / contributor / action / exposure
├─ relevant context / scope / time
├─ causal contrast / reference semantics where material
├─ typed causal role/depth where decision-critical
├─ domain-appropriate evidence
├─ competing explanations/confounding where material
├─ calibrated confidence / unresolved alternatives
└─ stopping depth tied to decision/intervention value
```

Shared non-collapse:

```text
sequence / association != causation
trigger != complete causal explanation
one cause identified != complete causal model
causal contribution != responsibility/accountability
control presence/compliance != causal effectiveness
```

## 4. Child A — Actual Causal Contribution / Episode Causation

### Protected question

> In this exact realized cross-ground episode/effect, which actual events, conditions, omissions, controls, actions or interactions were causal contributors to what occurred, and at what causal depth is the explanation sufficient for the current intervention/recurrence decision?

### Stable semantic core

```text
Actual Causal Contribution / Episode Causation
├─ exact realized episode/effect
├─ actual candidate contributors that occurred/were absent
├─ actual causal path/set/interaction where material
├─ episode-specific context and boundary conditions
├─ causal roles/depths where decision-critical
│  ├─ proximate/direct
│  ├─ enabling/contributing
│  ├─ prevention failure
│  ├─ detection/containment failure
│  └─ systemic/framing
├─ actual-cause contrast / mechanism / reconstruction evidence
├─ competing episode explanations
└─ calibrated causal confidence / unresolved contributors
```

The role labels are profiles/checklist items, not immediate children.

### Distinct failure family

- chronology mistaken for actual cause;
- first trigger treated as complete explanation;
- hindsight narrative;
- one `root cause` forced despite joint/redundant causes;
- causal set/interaction omitted;
- prevention/detection failure omitted;
- individual action overemphasized while system conditions disappear;
- causal contribution confused with responsibility/blame;
- exact episode effect not fixed before analysis.

### Typical evidence/research Work

- incident/mishap reconstruction;
- event-condition and barrier analysis;
- mechanism inspection;
- fault reproduction/injection;
- actual-cause counterfactual analysis where useful;
- physical/digital traces;
- alternative-mechanism elimination;
- deeper causal investigation until intervention/recurrence value saturates.

## 5. Child B — General / Interventional Causal Effect

### Protected question

> For a defined action/exposure/control/intervention X and outcome Y, across a specified unit/population/context and relevant alternative, how would changing X alter Y or its distribution/probability/severity?

`General` here means a causal effect beyond merely explaining one fixed realized episode. It can still be unit-specific in some causal formalisms; the load-bearing distinction is the forward **effect-of-changing-X** question.

### Stable semantic core

```text
General / Interventional Causal Effect
├─ exact candidate intervention/exposure/action/control
├─ exact outcome / effect measure or comparison target
├─ alternative / baseline causal contrast
├─ unit / population / context / scope
├─ treatment/intervention realization and fidelity where material
├─ confounding / selection / interference assumptions where material
├─ effect magnitude/distribution/heterogeneity where material
├─ mechanism / transportability support where material
├─ evidence design
└─ calibrated confidence / validity limits
```

### Distinct failure family

- association/correlation mistaken for causal effect;
- before/after difference treated as intervention proof;
- confounding/selection/information bias;
- wrong baseline/contrast;
- intended intervention differs from realized intervention;
- average effect applied to wrong individual/context;
- effect heterogeneity ignored;
- interference/spillover ignored;
- transportability/generalization overreach;
- control presence/compliance treated as risk-reduction effectiveness.

### Typical evidence/research Work

- randomized experiment where feasible;
- controlled fault injection/evaluation;
- natural/quasi experiment;
- observational causal inference;
- confounding/selection analysis;
- comparison/contrast specification;
- intervention-fidelity checks;
- effect heterogeneity/context analysis;
- repeated cross-context evaluation.

## 6. Why these are immediate children rather than mere profiles

The promotion threshold is met because each has:
- a distinct protected question;
- different characteristic false-positive causal conclusions;
- different evidence designs;
- different uncertainty/research Work;
- different semantic anchors;
- cross-domain recurrence;
- no safe reduction into the other.

### Removal test

Remove the episode-specific actual-effect question from Child A:
- the question becomes a forward intervention/effect problem and changes meaning.

Remove the intervention/alternative/outcome-distribution question from Child B:
- repeated episode narratives remain but general effect is not identified.

Thus the distinction is not merely stylistic.

## 7. Relationship between the two children

They can inform each other but do not collapse.

### General effect → actual causation

A strong general effect can raise or lower the plausibility/probability that X caused one episode, but does not uniquely establish actual cause.

### Actual causation → general effect

Many well-investigated incidents can generate hypotheses and mechanism knowledge, but do not automatically estimate a general causal effect due to selection/confounding/context differences.

### Shared mechanism

A causal mechanism can support both:
- explaining this episode;
- predicting effect under intervention.

Mechanism is therefore cross-cutting, not a third child.

## 8. Control-effectiveness routing

Accepted Control asks:

> How is behavior/effect governed?

Causal Effect asks:

> Did the control actually change the outcome/risk?

Then Standing can ask:

> Is the evidence sufficient to treat the control as effective under criterion C?

Two causal forms exist:

```text
Actual:
Did control C prevent/mitigate this exact incident effect?

General:
Does control C reduce incident probability/severity across the governed context?
```

Therefore `Control Effectiveness` is not a third child; it is a high-value profile crossing both promoted children + Standing.

## 9. Responsibility/accountability routing

Actual causal analysis may identify:

```text
Actor action A causally contributed to effect E
```

Actors separately asks:
- was A authorized?
- did A have a duty?
- was the Actor negligent?
- who is accountable to which forum?

Thus:

```text
causal contribution
!= responsibility
!= accountability
```

No responsibility child is promoted here.

## 10. Why causal-depth roles remain profiles

The recurring role set:

```text
proximate/direct
enabling/contributing
prevention failure
detection/containment failure
systemic/framing
```

remains highly useful but fails child criteria because:
- roles overlap;
- they are explanandum-relative;
- they vary by system boundary;
- necessary/sufficient/contributing properties cut across them;
- some general causal-effect questions have no incident-style prevention/detection decomposition.
