## E2 — Causal role / depth discrimination

Recurring causal-depth roles survived as **profiles**, not children:
- trigger;
- proximate/direct;
- enabling/contributing;
- prevention failure;
- detection/containment failure;
- systemic/framing.

Key reason: roles overlap and change with explanandum/boundary/depth.

Also established:
- necessary != sufficient;
- contributing != necessary;
- but-for necessity is not a universal causal criterion;
- omissions/failure-to-prevent need causal relevance beyond mere absence;
- causal analysis stops when deeper levels no longer change intervention/recurrence/control/decision.

File: `E2-CAUSAL-ROLE-DEPTH-DISCRIMINATION.md`

## E3 — Evidence / counterfactual / alternatives

Established:
- temporal precedence usually constrains candidates but is not causal proof;
- association/statistical significance does not establish causation;
- mechanism can be strong but does not prove actual operation by itself;
- intervention/experiment directly pressures causal effect but has scope/transport limits;
- causal contrast is conceptually load-bearing without one mandatory counterfactual syntax;
- but-for reasoning fails under overdetermination;
- confounding/selection can produce spurious causal narratives;
- investigative elimination is legitimate actual-cause evidence;
- no universal evidence ladder survives.

File: `E3-EVIDENCE-COUNTERFACTUAL-ALTERNATIVES.md`
