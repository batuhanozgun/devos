## 2. Protected question

> For a defined target, how would outcome/effect Y differ under exact regime/state/action/exposure X versus comparator X', under the relevant context/time/version, and with what limits on causal identification and generalization?

This remains distinct from accepted Actual Causation:

```text
Did X cause this observed Y?
!=
How would Y differ under X versus X'?
```

## 3. Stable semantic core

```text
Contrastive / Interventional Causal Effect
├─ exact causal question / outcome Y
│  ├─ outcome semantics
│  └─ time horizon where material
├─ exact target bearer/scope
│  └─ unit / subgroup / population / system
├─ focal regime X
├─ comparator regime X'
├─ intervention/exposure/regime identity
│  ├─ version / intensity / timing / duration where material
│  ├─ static / dynamic / policy regime where material
│  └─ multiple-version distinction where material
├─ target applicability frame
│  └─ Environment / population / version / time / context
├─ realized intervention/exposure semantics where material
│  └─ assignment / delivery / traversal / adherence / fidelity boundaries
├─ interference / exposure-configuration semantics where material
├─ effect aggregation / scale where magnitude is claimed
├─ heterogeneity / conditioning semantics where material
├─ object-level causal-effect claim
├─ identification assumptions/threats kept explicit when load-bearing
├─ evidence / estimate / uncertainty kept separate from causal truth
└─ source→target generalization boundary kept explicit when material
```

Not every branch is mandatory in every domain. A branch is required when collapsing it can change the causal question or decision.

## 4. Strongest non-collapse set


## 5. Intervention identity/fidelity result

A causal intervention is not merely a name.

Where material, preserve:
- policy/rule;
- version;
- intensity/dose;
- timing/duration;
- application/eligibility;
- actual realization/traversal;
- override/fallback;
- co-interventions.

But this does not become a child because it specifies **which causal contrast is being asked** and interfaces with Binding/Transition/Environment realization.

## 6. Comparator result

Comparator is constitutive of effect identity.

```text
C vs no control
!= C vs weaker control
!= C vs alternative D
```

A vague baseline can invalidate the causal question just as much as a vague treatment.

## 7. Confounding/selection/support result

These are causal-identification threats, not new causal-effect objects.

Preserve when material:
- common-cause/confounding alternatives;
- selection mechanisms;
- measurement error;
- support/positivity/overlap gaps;
- missingness;
- model assumptions.

Critical boundary:

```text
causal target defined
!= current evidence identifies it
```

## 8. Heterogeneity result

Effect variation across target members/context/version is genuine causal structure.

But:

```text
heterogeneous effect
```

still answers the same contrastive question at different conditioning/aggregation scopes.

No `Heterogeneity` child.

## 9. Interference/spillover result

Interference can make one unit's outcome depend on other units' interventions.

Foundation must therefore allow:
- assignment vectors;
- neighborhood exposure;
- saturation/coverage;
- shared-resource/system regimes.

But this changes the intervention/target specification rather than creating a distinct protected question.

No `Interference` child.

## 10. Transportability/generalization result

Strongest challenged candidate.

Current reduction:

```text
target causal question:
Effect of X vs X' on Y in target T

source-to-target question:
Can evidence from S identify/support that target-T effect?
```

The first remains the object-level Contrastive Causal Effect.
The second is a causal evidence/invariance/generalization bridge.

No `Transportability` child is promoted at current depth.

Because fresh dedicated external transportability literature could not be recovered in this pass, this remains the strongest reopen trigger.

## 11. Direct/indirect/mediated/system effects result

These are more specific causal contrasts/path restrictions or target scopes.

They may require distinct methods/assumptions but do not form universal sibling populations.

No child promotion.

## 12. Efficacy/effectiveness/fidelity result

These are effects under different:
- contexts;
- intervention realizations;
- adherence conditions;
- operational constraints.

They remain profiles of the same causal-contrast grammar.

## 13. Control causal-effectiveness interface

Accepted composition remains sufficient:

```text
Control
→ what should govern behavior/effect

Contrastive Causal Effect
→ how outcome/risk changes under Control regime C vs comparator C'

Composite Standing
→ whether that causal effect meets an effectiveness/risk/acceptance criterion
```

Thus:

```text
Control present
!= Control enforced
!= Control complied with
!= Control causally effective
!= effectiveness sufficient for target criterion
```

No new `Control Effectiveness` region.

## 14. Agentic-software interpretation

Example claim:

```text
"permanent eval E reduced recurrence"
```

requires enough specificity to answer:
- outcome: which failure class / rate / severity?
- target: which tasks/agents/environments/versions?
- focal regime: E at what version and enforcement semantics?
- comparator: no E / old E / alternative guardrail?
- realized fidelity: did E actually run and gate relevant paths?
- co-interventions: model/prompt/routing changes?
- interference: shared policies/agents/resources?
- time horizon: immediate vs sustained?
- source→target: eval suite vs production?

Only after those are bound can evidence support a causal-effect claim.
