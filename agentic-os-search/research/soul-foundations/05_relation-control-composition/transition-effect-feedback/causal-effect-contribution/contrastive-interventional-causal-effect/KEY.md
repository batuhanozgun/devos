Canonical question:

> For a defined target, how would outcome/effect Y differ under exact regime/state/action/exposure X versus comparator X', under the relevant context/time/version, and with what limits on causal identification and generalization?

## Stable semantic core

```text
Contrastive causal-effect claim
├─ exact outcome Y + relevant horizon
├─ exact target bearer/scope
├─ focal regime X
├─ comparator regime X'
├─ exact intervention/exposure/regime identity
│  └─ version/intensity/timing/rule where material
├─ applicability frame
│  └─ population/Environment/version/time/context
├─ realized exposure/fidelity semantics where material
├─ interference/exposure-configuration semantics where material
├─ effect aggregation/scale where magnitude is claimed
├─ heterogeneity/conditioning semantics where material
├─ object-level causal-effect claim
├─ identification assumptions/threats visible when load-bearing
├─ evidence/estimate kept separate from causal truth
└─ source→target generalization boundary where material
```

## Strongest rules

```text
causal effect identity
= outcome + target + X vs X' + applicability frame
  (+ exact regime/configuration semantics where material)

intended / assigned intervention
!= materialized / received / traversed intervention
!= sustained intervention with required fidelity

causal target defined
!= identifiable from current evidence
!= estimated
!= estimate correct/precise
!= evidence sufficient for target decision

source/local causal effect
!= target causal effect by identity

no observed spillover
!= no interference
```
