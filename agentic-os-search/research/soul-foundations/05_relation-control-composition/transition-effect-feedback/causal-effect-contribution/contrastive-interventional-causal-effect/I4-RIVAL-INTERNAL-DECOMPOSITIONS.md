# Contrastive / Interventional Causal Effect — I4 Rival Internal Decompositions

**Status:** COMPLETE / BOUNDED-LEAF HYPOTHESIS STRENGTHENED  
**Date:** 2026-09-06

## 1. Objective

Attack the one-child/leaf hypothesis by testing whether recurring causal-effect problems form stable immediate children.

Promotion criteria:
1. distinct protected question;
2. distinct characteristic failure family;
3. cross-domain recurrence;
4. cannot be safely represented as target/contrast/context/evidence dimension;
5. materially different research/recovery route;
6. does not steal an accepted sibling/ground responsibility.

## 2. Rival A — Intervention Definition / Identification / Generalization

Candidate:

```text
Contrastive Causal Effect
├─ Intervention / Estimand Definition
├─ Causal Identification
└─ Generalization / Transportability
```

### Strength

This resembles real methodological workflows:
- define question;
- identify from data;
- transport to target.

### Failure

The three are not sibling causal-effect populations.

`Intervention/estimand definition` specifies the object-level causal question.

`Identification` asks whether available evidence/assumptions can recover that object.

`Generalization/transport` asks whether source evidence can support the same kind of target-specific causal object in a new scope.

They are semantic/evidence layers rather than three kinds of causal effect.

Verdict: **reject as child hierarchy**.

## 3. Rival B — Individual / Population / System Effects

Candidate:

```text
Individual Effect
Population Effect
System/Policy Effect
```

### Strength

They differ in aggregation, observability and evidence methods.

### Failure

All answer:

> How would the target outcome differ under X versus X'?

The target bearer changes:
- individual;
- subgroup/population;
- connected system.

System effects can also include interference and policy assignment.

This is a target/aggregation dimension, not a new protected question.

Verdict: **retain as profiles**.

## 4. Rival C — Direct / Indirect / Mediated / Spillover Effects

Candidate:

```text
Direct Effect
Indirect/Mediated Effect
Spillover/Interference Effect
```

### Strength

These may require different assumptions and causal structures.

### Failure

They are defined by more specific contrasts/path restrictions inside the same causal question.

One domain may need none; another may need several simultaneously.

A total effect can include direct + indirect paths, while spillover can be part of a system-level regime effect.

Verdict: **causal-path/profile distinctions, not children**.

## 5. Rival D — Manipulable Intervention / Non-Manipulable Exposure

Candidate:

```text
Interventional Effects
Exposure/State Effects
```

### Strength

Literal interventions often yield clearer alternative-regime semantics.

### Failure

Manipulability is not the protected-question boundary.

A non-atomic exposure can still support a meaningful causal contrast if alternative regimes/states are sufficiently defined.

Conversely, a technically manipulable label can be causally ill-defined if it bundles multiple versions.

Verdict: **reject split; retain well-defined-contrast requirement**.

## 6. Rival E — Efficacy / Effectiveness / Implementation Effect

Candidate:

```text
Efficacy under controlled/ideal conditions
Effectiveness in operational reality
Implementation/fidelity effect
```

### Strength

These are highly useful applied distinctions.

### Failure

They are effects in different:
- target contexts;
- intervention realizations;
- adherence regimes;
- operational conditions.

Implementation strategy can itself be the intervention, but that remains a causal contrast.

Verdict: **profiles, not universal children**.

## 7. Rival F — Local Effect / Transported Effect

Candidate:

```text
Source/Local Causal Effect
Transported/Generalized Causal Effect
```

### Strength — strongest rival

Source-to-target reuse has distinct failure modes:
- effect-modifier shift;
- intervention-version drift;
- support gaps;
- selection differences;
- context/mechanism changes;
- measurement differences.

It often requires a dedicated analysis.

### Adversarial reduction test

Target question:

```text
What is effect of X vs X' on Y in target T?
```

This is already a standard contrastive causal-effect claim.

If evidence comes directly from T, no transport problem exists.

If evidence comes from source S, the extra question is:

```text
Does evidence from S identify/support the target-T effect?
```

That is a source→target evidence/invariance bridge.

The object-level causal effect remains the same kind of thing.

### Boundary consequence

A separate child would risk mixing:
- causal target truth;
- evidence provenance/selection;
- applicability/invariance Standing.

Verdict: **do not promote at current depth**. Preserve Transportability/Generalization as a major profile/reopen trigger.

## 8. Rival G — Confounded / Randomized / Quasi-Experimental / Mechanistic Effects

Candidate split by evidence method.

Rejected because methods do not define causal-effect types.

The same causal target may be studied by:
- randomized experiment;
- natural experiment;
- observational adjustment;
- mechanistic/fault-injection evidence;
- simulation plus validation;
- mixed evidence.

Verdict: **method taxonomy, not Foundation children**.

## 9. Rival H — Control Effectiveness as a dedicated causal child

Candidate:

```text
General Causal Effect
Control Effectiveness
```

### Strength

Control effectiveness is operationally critical and has distinct metrics.

### Failure

The protected question is still:

> Compared with control regime C', how does Control C change target risk/outcome Y in context T?

Control supplies the governing object/intervention semantics; Causal Effect supplies the contrastive consequence; Standing can decide whether the magnitude satisfies an effectiveness criterion.

Therefore:

```text
Control semantics
+ Contrastive Causal Effect
+ effectiveness criterion/Standing
```

is sufficient at current depth.

Verdict: **do not promote**.

## 10. Rival I — Benefit / Harm / Trade-off Effects

Candidate:

```text
Beneficial Effect
Harmful Effect
Trade-off Effect
```

Rejected because polarity/value depends on outcome/criterion and Actor goals.

A causal effect can be positive on one outcome and negative on another.

Value judgment is not a causal child.

## 11. Rival J — Static / Dynamic / Adaptive Intervention Effects

Candidate:

```text
Static Treatment Effect
Dynamic Policy Effect
Adaptive/Sequential Regime Effect
```

These require different intervention definitions/evidence methods but answer the same protected question with different regime structures.

Verdict: **intervention-regime profile, not child**.

## 12. Rival K — Identified / Partially Identified / Unidentified Effects

These are epistemic/identification standings, not causal-effect populations.

Preserve:

```text
causal effect target exists/defined
!= current evidence point-identifies it
```

Verdict: **Standing/evidence-facing profile**.

## 13. Strongest current structure

No rival split survives immediate-child promotion.

Provisional structure:

```text
Contrastive / Interventional Causal Effect
    ← one target-specific causal-contrast grammar
    ← intervention/comparator/fidelity dimensions
    ← identification/evidence assumptions
    ← heterogeneity/interference profiles
    ← transport/generalization profile
    ← no immediate child yet
```

## 14. Why overlap does not make the leaf vague

The leaf has one protected question:

> For a defined target, how would outcome Y differ under regime X versus X'?

The recurring distinctions tell us **how that question can be specified or invalidly answered**.

They are not arbitrary leftovers because each routes to one of a small set of failure classes:
- effect target under-specified;
- intervention/comparator under-specified;
- realized exposure mismatched;
- causal identification invalid;
- target heterogeneity hidden;
- interference hidden;
- source→target generalization unsupported;
- effect evidence confused with decision Standing.

## 15. I4 conclusion

The bounded-leaf hypothesis is now strong but remains provisional until external/candidate holdouts.

The strongest possible reopen is:

> **Transportability / Generalization might still deserve a child if independent traditions repeatedly treat source→target causal validity as a separate first-order causal object rather than an evidence bridge to a target-specific causal contrast.**

I5 must attack exactly that point, plus interference, estimand/intervention fidelity and Control causal-effectiveness using independent traditions where tool access permits.
