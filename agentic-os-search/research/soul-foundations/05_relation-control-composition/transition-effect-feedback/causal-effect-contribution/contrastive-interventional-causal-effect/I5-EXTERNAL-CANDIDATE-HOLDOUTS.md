## 3. Dawid/Musio parent holdout — effects of causes vs causes of effects

Accepted parent E5 recovered scholarly pressure distinguishing:
- **effects of causes** — how outcomes change under causes/interventions;
- **causes of effects** — whether a cause produced one observed outcome.

This directly supports the active child's protected question as distinct from accepted Actual Causation.

It does not force an internal split inside contrastive effects.

## 4. CDC parent holdout — association is not causal effect

Accepted parent E5/E3 recovered CDC pressure that measures of association are not causal by identity and can be distorted by:
- chance;
- selection bias;
- information/measurement bias;
- confounding;
- analysis error.

This independently supports I0/I3:

```text
observed association
!= contrastive causal effect
```

It also supports preserving assumptions/evidence threats without turning them into causal-effect children.

## 5. NIST parent holdout — Control effectiveness requires outcome/risk contribution

Accepted parent E5 recovered NIST pressure that control effectiveness concerns whether controls contribute to reducing security/privacy risk, not merely whether controls exist or are implemented.

This supports the composition:

```text
Control semantics
+ contrastive causal-effect question
+ effectiveness criterion / Standing
```

rather than a dedicated `Control Effectiveness` child.

A control can be:
- correctly specified;
- implemented;
- complied with;
- yet causally ineffective for the target outcome.

## 7. Anthropic candidate study — configuration intervention identity

The Anthropic candidate study is especially useful because it treats:
- `CLAUDE.md`;
- Skills;
- Hooks;
- prompts/models;
- permissions/sandbox/control configuration
as changeable configuration surfaces and recommends regression evaluation when such surfaces change.

It also describes production incidents being converted into permanent eval/control changes.

Causal-effect pressure:

```text
configuration changed
+ later outcomes improved
!= configuration change causally produced improvement automatically
```

The study's own known confounders/validity risks include:
- model/provider changes;
- task mix;
- monitoring/reporting changes;
- policy/control drift;
- runtime/environment differences;
- alternate authority/effect paths.

This strongly supports target/version/context specificity and intervention-fidelity discipline.

It does not supply independent efficacy evidence for the causal effect of the playbook mechanisms.

## 9. Candidate pressure — benchmark/eval to production

Both agentic candidate studies expose a recurring pattern:

```text
mechanism performs well on eval/benchmark/staging
→ assume production causal benefit
```

This can fail through:
- target-distribution shift;
- environment differences;
- model/version drift;
- interference with other agents/tools;
- fidelity differences;
- changed detection/reporting;
- optimization to the eval suite.

Foundation interpretation:

```text
causal effect in evaluation context E
!= causal effect in production target P by identity
```

The target-P effect remains a Contrastive Causal Effect; using E evidence for P is a transport/generalization evidence problem.

## 10. Does Transportability become a child under holdout pressure?

External fresh source breadth was not available, so the conclusion must remain bounded.

Current attack:

### Case A — source and target are identical

No transport question exists; contrastive causal effect remains well-formed.

### Case B — source differs from target

The object-level target question remains:

```text
What is effect of X vs X' on Y in target T?
```

Additional work asks whether evidence from `S` supports/identifies this target claim.

### Case C — context change changes intervention identity

Then the problem is not merely transport; the target causal contrast itself differs and must be redefined.

### Case D — context changes effect modifiers only

Then target-specific heterogeneity/generalization assumptions are needed.

Across cases, transportability behaves as a **source→target validity/reuse profile** attached to one target causal-effect object.

Current verdict:

> Do not promote Transportability/Generalization at current depth, but keep it as the strongest reopen trigger because dedicated independent literature was not freshly recovered in this child pass.

## 11. Does Interference become a child under candidate pressure?

Thus:

```text

```

No child promotion.
