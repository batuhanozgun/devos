# Actual Causal Contribution / Episode Causation — A4 Rival Internal Decompositions

**Status:** COMPLETE / BOUNDED-LEAF HYPOTHESIS STRENGTHENED  
**Date:** 2026-09-06

## 1. Objective

Test whether Actual Causal Contribution / Episode Causation needs stable immediate children rather than one shared episode-causal grammar.

## 2. Rival A — Direct / Enabling / Control-Failure / Systemic

Candidate:

```text
Actual Episode Causation
├─ Direct / Proximate
├─ Enabling / Contributing
├─ Control / Barrier Failure
└─ Systemic / Framing
```

### Why attractive

These roles recur in engineering, safety and incident analysis and often drive different corrective actions.

### Why it fails as child hierarchy

- the same factor can occupy several roles;
- role changes with exact explanandum;
- detection failure can be irrelevant to initial fault but causal to user harm;
- systemic is boundary/depth-relative;
- control/barrier failure can simultaneously be enabling/systemic;
- necessary/sufficient/joint properties cut across all roles.

Verdict: **retain as causal-depth/role profiles, not children.**

## 3. Rival B — Positive Causation / Omission or Failure-to-Prevent

Candidate:

```text
Actual Episode Causation
├─ Positive / Productive Cause
└─ Omission / Failure-to-Prevent
```

### Why attractive

Omissions require relevance constraints because infinitely many absences are imaginable.

### Why it fails as child hierarchy

- both answer the same protected episode-causal question;
- both require exact explanandum, actual episode fact/state, causal relevance, evidence and alternatives;
- omission adds contrast/relevance qualification but not a different failure population;
- one causal configuration can contain positive and omission contributors together;
- separating them would duplicate joint-cause and depth logic.

Verdict: **omission is a guarded causal profile, not child.**

## 4. Rival C — Mechanism / Barrier Failure / Organizational-Systemic

Candidate organizes by explanatory medium.

Rejected because:
- mechanism can span physical, software, organizational and institutional processes;
- barrier failure itself needs mechanism/path relevance;
- organizational/systemic factors can operate through mechanisms;
- the split imports domain/ground identity into causal taxonomy.

Verdict: **mechanism/path is cross-cutting evidence/explanation structure.**

## 5. Rival D — Necessary / Sufficient / Contributing

Candidate:

```text
Necessary Cause
Sufficient Cause
Contributing Cause
```

Rejected because these are logical/causal properties rather than disjoint episode populations.

One contributor may be:
- necessary but not sufficient;
- sufficient but not necessary under overdetermination;
- necessary within one sufficient set but not globally necessary;
- neither necessary nor sufficient alone yet causal in interaction.

Verdict: **retain as properties of causal claims/configurations.**

## 6. Rival E — Individual Cause / Joint or Causal-Set Cause

Candidate:

```text
Individual Actual Cause
Joint / Causal-Set Cause
```

### Why attractive

A1 found that independent edges can lose conjunctive/set semantics.

### Why it fails as child hierarchy

- individual causation is the arity-1 limiting case of configuration-sensitive causation;
- one episode can contain both individual and joint contributors;
- overdetermination creates alternative sets rather than a separate kind of inquiry;
- the same protected question/evidence problem remains.

Verdict: **causal arity/configuration is structural dimension, not child.**

## 7. Rival F — Occurrence / Progression-Severity / Recovery-Delay

Candidate splits by the kind of effect being explained.

Rejected because these are different explananda within the same episode grammar.

```text
cause of initial event
!= cause of propagation/severity
!= cause of prolonged duration/recovery delay
```

But changing the explanandum does not change the causal problem kind.

Verdict: **exact explanandum dimension, not child.**

## 8. Rival G — Local / Distributed / Systemic

Rejected because scope/topology is not a causal kind.

A distributed cross-ground episode can still use the same actual-cause grammar:
- exact effect;
- actual contributors;
- joint/path semantics;
- evidence;
- alternatives;
- depth.

`Systemic` is not synonymous with distributed.

Verdict: **scope/topology profile only.**

## 9. Rival H — Cause / Mitigation / Failure-to-Prevent

Candidate separates promoting and reducing causal influence.

Rejected because:
- preventing/mitigating this exact effect is the same episode-causal proposition with opposite/reducing contribution semantics;
- the same barrier can fail in one episode and mitigate another;
- exact effect and path determine role.

Verdict: **contribution polarity/profile, not child.**

## 10. Rival I — Causal Path / Causal Context / Causal Configuration

This is the strongest structural rival after A1–A3.

Potential split:

```text
Actual Episode Causation
├─ Causal Path / Mechanism
├─ Enabling Context / Conditions
└─ Causal Configuration / Set
```

Rejected as child hierarchy because:
- path, context and configuration are simultaneous facets of one causal claim;
- context can be a member of the causal configuration;
- mechanism can itself be conjunctive;
- some actual-cause claims need one facet but not all;
- they do not form disjoint protected-question populations.

Verdict: **shared causal-structure dimensions.**

## 11. Strongest surviving organization

```text
Actual Causal Contribution / Episode Causation
    ← one protected question
    ← effect-centered
    ← configuration-sensitive
    ← multiple overlapping causal roles/properties
    ← evidence/alternatives calibrated to exact claim
```

Profiles/dimensions retained:
- direct/proximate;
- enabling/contributing;
- prevention/detection/containment;
- systemic/framing;
- omission/failure-to-prevent;
- promoting/mitigating;
- necessary/sufficient/INUS-like;
- individual/joint/redundant/preempted;
- occurrence/progression/severity/duration;
- path/mechanism/context/configuration.

## 12. Provisional structural verdict

No tested decomposition produces:
- a different protected causal question;
- a distinct evidence family not already claim-relative;
- a stable cross-domain population;
- non-overlapping boundaries.

Current provisional result:

> **Actual Causal Contribution / Episode Causation is a bounded-leaf candidate, not a parent requiring immediate children.**

A5 must now pressure this result against authoritative/candidate holdouts, especially omission, systemic causation, multiple factors and blame-free systems investigation.
