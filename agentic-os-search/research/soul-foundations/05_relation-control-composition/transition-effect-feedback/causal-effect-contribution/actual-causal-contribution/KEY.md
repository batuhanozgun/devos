Canonical question:

> For one exact realized episode/effect, which actual events, conditions, omissions, controls, actions or interactions causally contributed to what occurred?

## Strongest structural discovery

```text
joint causal configuration
!= collection of independent cause edges
```

Some effects are caused by contributor configurations/sets or alternative sufficient routes. Flattening them can change the claim.

No graph/schema representation is prescribed.

## Strongest explanandum rule

```text
cause of initiating event
!= cause of progression
!= cause of severity
!= cause of prolonged duration/recovery delay
```

The causal role of the same factor depends on the exact effect being explained.

## Strongest omission/control rule

```text
Control/barrier defect
!= actual causal contribution by identity

omission causal relevance
!= duty / negligence / accountability
```

A missing/failed barrier must be shown relevant to the exact episode path/effect.

## Strongest epistemic rule

```text
causal story has supporting evidence
!= serious alternatives discriminated
!= causal explanation complete
```

Also:

```text
all observed/logged contributors analyzed
!= all materially relevant contributors observed
!= causal explanation complete
```

## Multiple-cause rules

```text
one cause identified != complete causal model
but-for necessity != universal causal criterion
could-have-caused != actually-caused
joint cause != independent sufficiency
```

Permit joint causes, multiple sufficient sets, overdetermination, preemption, enabling contributors and mitigating/preventive contributors.

## Boundary rules

```text
chronology / provenance != actual causation
actual causal contribution != responsibility/accountability
actual episode cause != contrastive/interventional causal effect
actual causal relation != evidence != evidence-sufficiency Standing
```
