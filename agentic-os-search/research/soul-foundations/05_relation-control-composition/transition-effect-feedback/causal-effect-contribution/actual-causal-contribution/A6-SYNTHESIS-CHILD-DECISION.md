## 2. Protected question survives

> For one exact realized episode/effect, which actual events, conditions, omissions, controls, actions or interactions causally contributed to what occurred, through what episode-specific causal structure, at what decision-relevant depth, and with what uncertainty or competing explanations?

This remains distinct from:
- Transition/Propagation — what changed;
- Contrastive/Interventional Causal Effect — what changing X would generally do to Y;
- Control — what should govern behavior;
- Actors — responsibility/accountability;
- Standing — whether evidence is sufficient for a criterion-relative conclusion.

## 3. Stable actual-cause grammar

```text
Actual episode-causal structure
├─ exact episode / inquiry boundary
├─ exact realized explanandum / effect
├─ actual contributor instance(s)
├─ causal contribution role/polarity where material
├─ joint / interaction / causal-set semantics where material
├─ path / mechanism / dependency semantics where material
├─ relevant context / scope / time
├─ causal contrast / contingency where material
├─ evidence kept separate from causal truth
├─ competing explanations / unresolved contributors
├─ calibrated confidence / completeness uncertainty
└─ causal depth stopped by intervention/recurrence/control/decision value
```

## 4. Strongest structural discovery — causal configuration

Actual causation is not safely reducible to independent pairwise edges.

```text
A AND B → E
```

may require a joint causal configuration.

Likewise:

```text
A OR B → E
```

with both sufficient routes present creates overdetermination/redundancy pressure.

Therefore:

```text
causal configuration / sufficient-set semantics
!= bag of independent `causedBy` edges
```

No architecture representation is prescribed.

## 5. Strongest depth discovery — explanandum-relative causation

Inside one incident:

```text
cause of initiating fault
!= cause of progression
!= cause of severity
!= cause of prolonged duration
```

A detection/containment failure can be irrelevant to the initiating event yet causal to broader harm.

This eliminates fixed universal depth labels.

## 6. Strongest omission/control discovery

```text
Control/barrier defect
!= causal contribution to exact effect by identity
```

A missing/failed barrier becomes episode-causally relevant only when evidence supports path/contrast relevance to the exact effect.

Also:

```text
omission causal relevance
!= duty / negligence / accountability
```

## 7. Strongest epistemic discovery — discrimination over support

A causal story can have supporting evidence while serious alternatives remain equally compatible.

Therefore:

```text
story has evidence
!= evidence discriminates alternatives
!= causal explanation complete
```

Actual-cause confidence should track discriminating power, not narrative coherence alone.

## 8. Causal frame-blindness

A new completeness guardrail survives:

```text
all observed/logged contributors analyzed
!= all materially relevant contributors observed
!= causal explanation complete
```

Unknown instrumentation/action paths/environment conditions can leave causal completeness unknown even when each identified contributor is well supported.

## 9. Multiple-cause result

Foundation must permit:
- joint causal sets;
- multiple sufficient sets;
- redundant/overdetermining routes;
- preemption;
- enabling contributors;
- severity/progression contributors;
- mitigating/preventive contributors;
- omissions/failure-to-prevent when causally qualified.

Never require:

```text
root_cause = exactly one value
```
