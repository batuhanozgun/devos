## Reopen triggers

Reopen this child if:
- a material domain repeatedly requires a distinct protected question for systemic versus proximate actual causation;
- omission/failure-to-prevent cannot use the shared grammar without importing normative duty;
- joint/overdetermined/preempted causation cannot be represented without a new first-order causal region;
- causal explanation completeness cannot be bounded without a separate epistemic region;
- responsibility/accountability cannot remain separated from actual causal contribution;
- contrastive-effect research shows actual episode causation is reducible after all;
- independent replication identifies a stronger split.

## Non-reopen conditions

Do not reopen merely because:
- one domain uses fault trees and another event trees/CAST/RCA;
- one cause is probabilistic;
- one episode has many contributors;
- one factor is both systemic and enabling;
- omission analysis needs additional evidence;
- causal paths are represented with a graph in a later architecture;
- the user wants more domain-specific cause labels.
