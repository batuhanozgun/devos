# Actual Causal Contribution / Episode Causation — Integrated Synthesis

## 1. Executive result

Dedicated A0→A7 research supports:

```text
Actual Causal Contribution / Episode Causation
    ← BOUNDED LEAF
    ← no immediate child promoted

```

This child answers one protected question:

> For one exact realized episode/effect, which actual events, conditions, omissions, controls, actions or interactions causally contributed to what occurred?

## 2. Exact effect first

Actual causation must be anchored to an exact realized explanandum from Transition / Propagation.

Inside one incident:

```text
initial fault
outage
user harm
outage duration
recovery delay
```

are distinct effects.

A factor can cause one without causing another.

Therefore:

```text
cause of occurrence
!= cause of progression
!= cause of severity
!= cause of duration
```

## 3. Episode-specific contributor identity

```text
X can cause failures
!= instance x caused/contributed in episode e
```

Actual-cause claims concern actual episode instances/states/actions/conditions/absences, not merely general causal capability.

## 4. Shared actual-cause grammar

```text
Actual episode-causal structure
├─ exact episode / inquiry boundary
├─ exact realized explanandum / effect
├─ actual contributor instance(s)
├─ causal role/polarity where material
├─ joint / interaction / causal-set semantics where material
├─ path / mechanism / dependency semantics where material
├─ relevant context / scope / time
├─ causal contrast / contingency where material
├─ evidence kept separate from causal truth
├─ competing explanations / unresolved contributors
├─ calibrated confidence / completeness uncertainty
└─ causal depth stopped by intervention/recurrence/control/decision value
```

## 5. Configuration-sensitive causation

A central result is that actual causation can be irreducibly joint/set-relative.

Example:

```text
A AND B → E
```

If neither A nor B alone is sufficient, flattening to two independent `caused E` claims changes the meaning.

Likewise:

```text
A OR B → E
```

with both sufficient routes present creates overdetermination/redundancy.

Foundation must therefore preserve joint/alternative causal configuration semantics where material.

This is a semantic requirement, not a graph/schema commitment.

## 6. Multiple causation / overdetermination

Actual episode analysis must permit:
- joint causation;
- multiple sufficient sets;
- redundant/overdetermining causes;
- preemption;
- enabling conditions;
- severity/progression contributors;
- mitigating/preventive contributors.

Therefore:

```text
one cause identified != complete causal model
but-for necessity != universal causal criterion
```

## 7. Causal chains are not simple transitive edges

```text
A → B → E
```

can support mediated causation, but simple causal-edge composition is not automatically safe under:
- preemption;
- blocking;
- changed explanandum;
- alternative sufficient routes;
- intervention context.

Thus causal reachability is not identical to a direct/equal-strength cause claim.

## 8. Omission / failure-to-prevent

Mere absence is not enough.

A useful omission/failure-to-prevent claim normally needs discriminating relevance through some combination of:
- exact absent/non-occurring state/action/barrier;
- relevant preventive/detective/containment function or causal contrast;
- feasible/relevant alternative;
- mechanism/path by which presence would change trajectory;
- evidence from design/intervention/reproduction/barrier analysis/domain constraints;
- exact scope/time alignment.

Keep separate:

```text
omission causally relevant
!= Actor duty
!= negligence
!= accountability
```

## 9. Control/barrier failures

```text
Control defect
!= actual causal contribution by identity
```

The defect must matter to the exact protected effect/path.

A defective barrier can be causally irrelevant if another barrier stops the path or the hazard never reaches it.

Control owns governing semantics; Actual Causation owns whether the control state actually changed the episode trajectory.

## 10. Systemic/framing contributors

Organizational, architectural, policy, incentive, capability or recurring-assumption conditions can be actual episode contributors.

But:

```text
systemic issue exists
!= systemic issue caused this episode
```

Systemic is depth/boundary-relative and overlaps with enabling/control-failure roles. It does not become a child.

## 11. Evidence result

Factual reconstruction, logs, provenance, physical traces, mechanism evidence, reproduction/fault injection, removal/intervention and investigative elimination can all be useful.

No universal evidence ladder survives.

Key distinction:

```text
high-confidence timeline
!= high-confidence causal explanation
```

and:

```text
mechanism can produce E
!= mechanism actually operated in episode e
```

## 12. Competing explanations

Evidence should be valued for its ability to discriminate among serious causal structures, not merely for supporting one coherent story.

```text
causal story supported by evidence
!= alternatives discriminated
!= causal explanation complete
```

Where several explanations fit the evidence, unresolved alternatives should remain explicit.

## 13. Causal frame-blindness

A major result:

```text
all observed/logged contributors analyzed
!= all materially relevant contributors observed
!= causal explanation complete
```

Instrumentation, selection, missing evidence and unobserved action/environment paths can systematically narrow the investigation frame.

This is Information-facing evidence visibility pressure, but causal explanation completeness remains a causal claim.

## 14. Causal confidence

Confidence can differ across:
- factual contributor presence;
- causal role;
- mechanism/path;
- completeness of causal model.

No universal numeric scale is required.

Actual causation should preserve unresolved alternatives rather than forcing one root cause for narrative closure.

## 15. Depth stopping rule

R06 remains the stop rule:

> Continue deeper only while another causal layer materially changes intervention choice, recurrence risk, control design, responsibility boundary or decision outcome.

This avoids both shallow proximate closure and infinite `why?` regress.
