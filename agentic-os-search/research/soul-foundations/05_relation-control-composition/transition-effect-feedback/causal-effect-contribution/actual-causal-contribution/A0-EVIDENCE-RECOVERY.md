## 1. Objective

## 2. Accepted prerequisites

### Transition / Propagation
Provides the exact realized effect/change identity, scope and timing.

```text
recorded/intended effect != realized effect
```

Actual causation cannot safely start from an ambiguous or merely represented outcome.

### Causal parent
Accepted distinction:

```text
Did X cause this observed Y?
!=
What would changing X generally do to Y?
```

This child owns only the first question.

### R06 causal-depth protocol
Preserves:
- symptom versus cause;
- proximate versus deeper/systemic cause;
- trigger versus enabling conditions;
- occurrence versus prevention/detection failure;
- one cause versus sufficient causal explanation;
- depth stopping by intervention/recurrence/control/decision value.

### Actors boundary

```text
causal contribution != responsibility != accountability
```

### Control boundary

```text
control defect / noncompliance != causal contribution to exact outcome by identity
control existence != causal effectiveness
```

### Standing boundary

```text
actual causal relation
!= evidence for causal relation
!= evidence sufficient to conclude causal relation
```

## 3. Parent evidence recovered

Parent E2/E3/E5 already established under authoritative/cross-domain pressure:
- chronology is not causation;
- trigger/proximate cause can be correct yet incomplete;
- enabling, prevention, detection and systemic factors can all be genuine contributors;
- necessary and sufficient are distinct properties;
- but-for necessity is not universal because of redundant/overdetermining causes;
- omission/failure-to-prevent needs causal qualification, not mere absence;
- multiple causal contributors are normal rather than exceptional;
- mechanism, intervention/removal, reconstruction and elimination can all supply causal evidence depending on the claim;
- no universal evidence ladder survives;
- actual episode causation is distinct from general/interventional effect estimation.

## 5. Frozen falsifiers

A child result fails if any of the following survive:

### F1 — one-root requirement
If one scalar/root cause can represent all decision-critical episode causation without loss, richer grammar is unnecessary.

### F2 — independent-edge sufficiency
If all actual causation can be represented as independent pairwise `X caused E` claims without losing joint/set/interaction semantics, causal-set structure is unnecessary.

### F3 — but-for universality
If `E would not occur without X` is necessary and sufficient across material domains, multiple-sufficient/overdetermination handling is unnecessary.

### F4 — omission collapse
If absence/failure-to-prevent either cannot be causal or can be treated as ordinary positive cause without additional relevance constraints, no omission-specific guardrails are needed.

### F5 — depth taxonomy
If proximate/enabling/prevention/detection/systemic roles form stable disjoint populations, immediate children may be required.

### F6 — responsibility identity
If actual causal contribution reliably establishes responsibility/accountability, Actors boundary fails.

### F7 — Control identity
If defective/absent Control is automatically a cause of every downstream adverse effect, causal qualification adds nothing.

### F8 — chronology/provenance reduction
If exact event/provenance reconstruction plus Binding is sufficient to establish actual causation, this child collapses.

### F9 — contrastive reduction
If actual episode causation can be safely reduced to general/interventional effect plus episode facts, parent split fails.

### F10 — confidence leakage
If preserving uncertainty/competing explanations requires turning this child into general epistemology, scope is unstable.

### F11 — systemic separate child
If systemic/organizational causation has an irreducible protected question not captured by episode causation grammar, a child split may be required.

### F12 — frame completeness
If reviewing all observed/logged contributors is sufficient to establish causal-model completeness, no causal frame-blindness guardrail is needed.
