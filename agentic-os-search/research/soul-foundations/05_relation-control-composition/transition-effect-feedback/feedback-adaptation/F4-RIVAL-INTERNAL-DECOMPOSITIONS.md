# Cross-Ground Feedback / Adaptation — F4 Rival Internal Decompositions

**Status:** COMPLETE  
**Date:** 2026-09-11

## Objective

Attack the provisional two-child split and test alternative decompositions.

## Provisional split under attack

```text
Cross-Ground Feedback / Adaptation
├─ Feedback / Returned Influence
└─ Persistent Adaptation / Future-Response Change
```

## Rival A — one bounded leaf

Claim:

> feedback and adaptation are simply stages of one loop and should remain internal dimensions.

### Failure

Fixed feedback can exist indefinitely with no persistent adaptation. Persistent adaptation can arise from a one-time historical feedback episode without a continuously recurring loop.

They therefore have different truth conditions, evidence requirements and failure/recovery families.

**Reject one-leaf model.**

## Rival B — Observation / Evaluation / Adaptation

Observation belongs primarily to Information formation/exposure; evaluation/qualification belongs Standing/Work; adaptation is temporal composition.

Promoting all three would steal accepted siblings/grounds.

**Reject.**

## Rival C — Reactive / Adaptive / Evolutionary

`Reactive` often maps to fixed feedback response. `Adaptive` maps to persistent response-function change. `Evolutionary` could mean:
- many adaptations over long time;
- population/selection dynamics;
- architectural self-change;
- organizational evolution.

No stable third protected question appears. Evolution remains a reopen trigger if later research exposes a distinct failure family.

**Reject three-level hierarchy at current depth.**

## Rival D — Parameter / Policy / Structural adaptation

These are loci/depths of persistent change:
- parameter tuning;
- policy/control change;
- workflow/process change;
- capability/tool change;
- structural/organizational change.

They can overlap and remain the same protected question: did prior feedback/history durably alter future response?

**Profiles, not children.**

## Rival E — Corrective / Preventive / Learning feedback

These classify intended purpose/effect and overlap with Work/Control profiles. The same feedback episode can be corrective now and preventive for the future.

**Reject.**

## Rival F — Human / Automated / Hybrid learning

Actor realization differs but semantic question does not.

A human team can durably change procedure; an automated controller can update parameters; a hybrid system can require approval. Actor type is orthogonal.

**Reject.**

## Rival G — Local / System / Organizational adaptation

These are scope/boundary levels. A local change can become systemic depending on propagation and scope; organizational adaptation can include human Work, Control and Information changes.

**Reject as universal children.**

## Rival H — Beneficial / Harmful / Neutral adaptation

These are evaluation/effectiveness outcomes. Adaptation occurrence remains independent of whether it helps.

```text
adaptation occurred
+ causal effect
+ criterion
→ beneficial / harmful / neutral standing
```

**Reject as children.**

## Rival I — Learning / Forgetting

Forgetting/reversion is a later transition affecting adaptation persistence/currentness. It does not create an independent protected problem family.

**Retain as persistence profile.**

## Rival J — Feedback / Learning / Self-Modification

Self-modification can target the ordinary response rule or the adaptation mechanism itself. Recursive depth changes risk/verification requirements, but the semantic claim remains durable future-response change attributable to prior feedback/history.

**No third child.**

## Strongest surviving split

### Child 1 — Cross-Ground Feedback / Returned Influence

Protected question:

> Did an observation/result from a prior/current realized state return across ground boundaries to a later consumer and causally influence a subsequent action, decision, control or transition?

Characteristic failures:
- no return path;
- stale/wrong signal;
- no consumption;
- consumption without influence;
- influence attributed when another cause changed behavior;
- unstable/misframed loop.

### Child 2 — Persistent Adaptation / Future-Response Change

Protected question:

> Did feedback/history produce a durable change in the system's future response to materially comparable situations, and where/how is that changed response realized and retained?

Characteristic failures:
- lesson stored but inert;
- one-off response only;
- change not materialized/propagated;
- change not retained;
- future behavior unchanged;
- persistent but harmful/misdirected change.

## F4 conclusion

The two-child split remains stronger than all tested alternatives. `Evolution`, recursive self-change and stability remain explicit reopen/pressure areas, not current children.
