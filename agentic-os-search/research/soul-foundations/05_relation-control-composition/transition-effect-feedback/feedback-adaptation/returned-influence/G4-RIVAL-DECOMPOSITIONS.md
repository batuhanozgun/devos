# Returned Influence — G4 Rival Decompositions

**Status:** COMPLETE / PROVISIONAL BOUNDED LEAF  
**Date:** 2026-09-11

## Promotion standard

An important distinction is not automatically a child. Compare whether the split protects a recurring additional problem that cannot be retained in the common grammar or routed to an accepted ground/sibling without material loss. Different implementations, evidence burdens, stages and truth/knowledge levels alone do not settle promotion.

Overlap alone is also not a rejection criterion: the accepted composition method permits one episode to instantiate several diagnostic questions. The test below addresses semantic and research value, not disjoint object buckets.

## Rival 1 — Return Channel / Consumer Uptake / Response

**Strong case:** delivery, uptake and response can fail separately and require different corrective work.

**Counter-test:** channel formation/exposure is already Information/Environment/Binding-facing; the chosen response pursuit belongs to Work/Actors/Control. The child-specific question is their operative return relation. Promoting each step would partly reproduce those grounds while leaving their composition to a residual category.

**Decision:** retain distinct failure locations in one signature, not three children. Do not hide delivery-versus-use uncertainty.

## Rival 2 — Structural Feedback / Operational Feedback / Episode Causation

**Strong case:** installed loops, active coupling and individual causal contributions have different truth conditions and evidence.

**Counter-test:** these distinguish a pattern's existence, activation and particular instance-level effect. They are claim levels of the same return relation, not three new feedback species. Episode causation already has an accepted sibling grammar. The crucial correction is to label the claim level, not to invent a competing causation branch.

**Decision:** explicit claim-level distinction; no child promotion.

## Rival 3 — Corrective / Confirmatory / Inhibitory Feedback

**Strong case:** changing, continuing and stopping an action have different operational consequences.

**Counter-test:** a single response rule can select any of these based on the same type of input. The output mode changes, not the returned-influence question. Treating hold as outside feedback produces a known counterexample; treating it as a separate child makes every response branch a taxonomy candidate.

**Decision:** response profiles; no child.

## Rival 4 — Negative / Positive / Stabilizing / Destabilizing

**Strong case:** reinforcing and counteracting couplings can require different dynamic analysis.

**Counter-test:** polarity and stability are not synonymous; both depend on the modeled relation and dynamics. Benefit and safety are additional target-relative qualifications. A model can include several coupled paths of different signs. Nothing requires a new returned-influence object.

**Decision:** polarity/dynamic-effect profiles; detailed control theory remains domain-specific.

## Rival 5 — Single / Distributed / Network Feedback

**Strong case:** distributed loops expose delays, competing consumers and shared resources absent from a simple two-node diagram.

**Counter-test:** exact return binding already permits many anchors and response loci. A network changes which paths and configurations must be preserved, but not the basic question. Failure arises if the grammar is prematurely binary, not because another child is necessarily missing.

**Decision:** cardinality/topology/scope dimension. Reopen if a future domain cannot preserve its operative return using that grammar.

## Rival 6 — Internal / External / Human / Automated Feedback

**Strong case:** source roles, trust and methods differ substantially.

**Counter-test:** internal/external depends on the chosen system boundary; human involvement does not establish authority or truth, and another agent does not automatically add independent evidence. These are important actor/provenance/realization properties, not protected feedback questions independent of return/use.

**Decision:** actor/source profiles; no hierarchy from provider identity.

## Rival 7 — Feedback Assurance / Evidence Validity

**Strong case:** uncertainty about whether an input really influenced behavior is decision-critical and may need dedicated investigations.

**Counter-test:** evidential sufficiency is not the object-level return relation. Promoting it as a peer risks turning every causal uncertainty into a new node and duplicates Standing/Information/Actual Causation. Nevertheless its diagnostic probes must stay explicit, rather than being dismissed as mere documentation.

**Decision:** retain G2 evidence discipline and G3 lineage/coverage; no immediate child.

## Rival 8 — Observation / Evaluation / Learning

**Strong case:** widely used organizational workflows distinguish these functions.

**Counter-test:** it mixes represented information, evaluation Work and persistent adaptation. It is not a decomposition of Returned Influence. It also permits 'evaluation complete' to obscure whether the signal reached an operative response.

**Decision:** reject for this child; the separate Persistent Adaptation sibling remains inactive.

## Rival 9 — Remove Returned Influence entirely

**Strong case:** Binding + Information + causal contribution could describe every example. Why retain a distinct research region?

**Counter-test:** those reusable ingredients alone do not ask whether condition/performance has returned into a relevant response path of a continuing system/pursuit. That question exposes recurring reporting-without-use, missing return, delayed correction and partial-loop failures. A derived composition region need not introduce a fifth ontological primitive to be diagnostically valuable.

**Decision:** preserve the region as a specialized cross-ground question. This is a project-method judgment, not proof that no other research organization is possible.

## Result and cost of the leaf choice

Provisional result:

```text
Cross-Ground Feedback / Returned Influence
    ← bounded leaf
    ← reference-relative operative-return grammar
    ← explicit claim levels, response modes and failure locations
    ← no immediate child promoted
```

The cost is that a reader must use the internal map rather than a child tree to find channel, causation or stability issues. `FINDINGS-MAP.md` must therefore preserve those routes. A leaf is not permission to erase depth.

The strongest remaining challenge is whether increasingly coupled or latent-response systems produce a new protected inquiry rather than a harder evidence problem. Current primary holdouts do not require that split. G5/G7 test this conclusion further.
