# Cross-Ground Feedback / Adaptation — F0 Evidence Recovery

**Status:** COMPLETE  
**Date:** 2026-09-11

## Objective

Recover current Foundation boundaries and independent pressure before deciding whether Feedback / Adaptation is one leaf or a parent.

## Accepted prerequisites

```text
Transition / Propagation
→ what exact change became real/effective and propagated?

Actual Causation
→ what actually contributed to this realized episode/effect?

Contrastive Causal Effect
→ how would target outcomes differ under X versus X'?

Control
→ what behavior/transition is governed under what basis?

Composite Standing
→ what qualification currently holds?
```

Feedback / Adaptation must not duplicate any of these.

## Frozen boundary falsifiers

Reject any result that implies:

```text
observation/report exists → feedback occurred
signal returned → signal was consumed
signal consumed → signal changed behavior
behavior changed once → system adapted
same fixed response repeated → adaptive system
lesson documented → learned system
permanent change → beneficial improvement
before/after improvement → adaptation caused improvement
```

## Parent residuals recovered

The accepted Transition parent left these live questions:
- threshold for feedback versus observation;
- signal availability versus consumption versus causal influence;
- one-off response versus persistent adaptation/evolution;
- adaptation occurrence versus benefit/effectiveness;
- delay/staleness/oscillation/overshoot/destabilization;
- when a permanent eval/test/control counts as system learning;
- whether Feedback / Adaptation splits into stable children.

## External pressure recovered 2026-09-11

### WHO patient-safety reporting and learning systems

WHO explicitly treats incident reporting as insufficient by itself. Reporting data can support learning, but achieving sustainable risk reduction and safety improvement requires downstream learning/use/change. This pressures:

```text
incident recorded != learning achieved
```

### FAA Safety Management System

FAA Safety Assurance evaluates continued effectiveness of controls, acquires information, analyzes it, assesses the system, and identifies improvement opportunities. SMS also emphasizes adaptation to change and continuous improvement. This pressures a loop:

```text
operation/outcome
→ information acquisition/analysis
→ system assessment
→ changed risk controls/process
```

without implying every assessment creates adaptation.

### NIST CSF 2.0 Improvement

The Improvement category identifies improvements from tests/exercises and from execution of operational processes. This pressures separation between:

```text
finding / lesson identified
!= improvement implemented
!= future outcome improved
```

### NASA adaptive-control tradition

NASA-hosted adaptive-control material distinguishes fixed feedback behavior from adaptive control that changes the control law/parameters based on measured changes. This is a direct falsifier for:

```text
feedback loop exists → adaptation exists
```

NASA learning/adaptive-control work also exposes stability/convergence as separate requirements; learning/adaptation can be unsafe or non-convergent.

### Google SRE operational learning

Google SRE material emphasizes postmortems, action items, ownership and follow-through. Written postmortems and lessons do not automatically change the system; action items must enter Work and be completed. This pressures:

```text
postmortem written != system learned
```

## Candidate-study pressure

### gstack

The study shows recurring:

```text
production/readback/failure
→ artifact/evidence
→ qualification/governance
→ source/runtime/control/test change
→ later execution
```

Its repository evolution also shows repeated failures becoming reusable helpers/tests/invariants. This is useful pressure for persistent adaptation, not taxonomy authority.

### Anthropic AI-native SDLC

The study includes incident→diagnosis→permanent eval/config/control change loops and explicitly treats agent configuration as an eval target. But the candidate itself warns that fewer later incidents do not prove causal effectiveness.

## Initial structural hypothesis

Two protected questions may be irreducible:

1. **Cross-Ground Feedback / Closed-Loop Influence**
   - Did an observation/result return to a later decision/control/work process and causally influence subsequent behavior?

2. **Persistent Adaptation / Learning**
   - Did feedback/history produce a durable change in the system's future-response function, policy, configuration, capability or decision behavior?

Do not promote yet. F1–F5 must attack the split.

## F0 conclusion

Feedback / Adaptation is coherent as a composition region, but the one-leaf hypothesis is already under serious pressure because fixed feedback and persistent adaptation can vary independently.
