## Child 1 — Cross-Ground Feedback / Returned Influence

### Protected question

> Did an observation/result from a prior/current realized state return across accepted-ground boundaries to a later consumer and causally influence a subsequent action, decision, control or transition?

### Stable semantic core

```text
Feedback / Returned Influence
├─ source realized outcome/state/event
├─ observation/signal/representation
├─ exact return binding/path
├─ later consumer/controller/decision/Work
├─ timing/currentness/applicability
├─ consumption/exposure
├─ causal influence on later behavior
└─ resulting later transition/effect
```

### Strong non-collapse

```text
observation != feedback
signal available != consumed
consumed != causally influential
feedback occurred != timely/current
feedback exists != stabilizing/safe
```

### Characteristic failure family

- signal never returned;
- wrong/stale signal;
- no exposure/consumption;
- consumed but ignored;
- later behavior attributed to feedback when another cause changed it;
- local feedback destabilizes or harms broader system;
- loop blind to material outcomes.

## Child 2 — Persistent Adaptation / Future-Response Change

### Protected question

> Did feedback/history produce a durable change in how the system will respond to future materially comparable situations, and where/how is that changed response realized and retained?

### Stable semantic core

```text
Persistent Adaptation
├─ prior feedback/history basis
├─ adaptation target/locus
│  └─ policy/model/config/control/workflow/capability/practice/etc.
├─ realized persistent change
├─ propagation/materialization into future decision/action path
├─ retention/currentness horizon
├─ future-response difference
├─ causal binding to prior feedback/history
└─ evidence/uncertainty kept separate from benefit/effectiveness
```

### Strong non-collapse

```text
one-off response != adaptation
repeated fixed response != adaptation
stored lesson != adaptation
adaptation Work completed != adaptation realized
adaptation persisted != adaptation beneficial/effective
```

### Characteristic failure family

- lesson stored but inert;
- one-off response only;
- permanent change proposed but not materialized;
- change outside future action path;
- change later overwritten/forgotten;
- future behavior unchanged;
- harmful or proxy-gaming adaptation;
- local adaptation worsens broader outcomes.

## Why this is a child split rather than stages

The two truth conditions can vary independently:

```text
feedback = true, adaptation = false
```

Example: fixed closed-loop controller.

```text
feedback episode occurred once, persistent adaptation = true
```

Example: one incident triggers a durable future control/test/policy change.

The second need not be a continuously recurring loop.

## Parent/sibling boundaries

### Information
Information owns signal/representation existence, source, formation and exposure.
Feedback owns returned influence on later behavior.

### Work
Work owns investigation, review, corrective tasks and implementation pursuits.
Adaptation owns whether history produced a persistent future-response change.

### Control
Control owns governing semantics of the new rule/regime.
Adaptation owns the historical feedback→persistent-regime-change claim.

### Transition / Propagation
Transition owns each realized change and propagation.
Adaptation is a higher-order temporal pattern: prior outcomes/history causally produce persistent future-response change.

### Causal Effect
Contrastive Effect owns whether the adaptation improves/worsens target outcomes.
Adaptation owns occurrence/persistence, not benefit.

### Standing
Standing owns currentness, stability, adequacy, beneficial/harmful/effective-enough qualifications.

## Cross-cutting profiles — not children

- delayed/stale feedback;
- negative/positive feedback;
- stability/oscillation/overshoot;
- proxy/local-vs-global objective;
- human/automated/hybrid realization;
- parameter/policy/structural adaptation;
- local/system/organizational scope;
- forgetting/reversion;
- recursive/meta-adaptation;
- beneficial/harmful/neutral outcome.
