## Protected question

> Which accepted-ground anchors are connected, in what semantic positions and under what applicability conditions, such that replacing the connection with a generic link would lose decision-critical meaning?

## Main discovery — binding has a semantic signature

A decision-usable binding is not universally captured by:

```text
relation-type + endpoint A + endpoint B
```

The strongest current semantic signature is:

```text
Binding semantic instance
├─ relation meaning / protected semantic question
│   └─ permitted/forbidden inference where decision-critical
├─ exact anchors
│   └─ each occupying typed semantic positions
├─ applicability structure
│   ├─ scope/reference frame
│   ├─ effective/reference time when material
│   └─ operation/method/stage/state/version/role qualifiers when material
├─ relation-instance individuation
└─ qualified/n-ary structure when binary decomposition loses association
```

This is not a data model. The same semantics may later be represented in many ways.

## Exact anchors and positions

Binding errors frequently occur even when the relation word is correct:
- correct evidence, wrong target/version;
- correct Actor, wrong Work role;
- correct resource, wrong method/stage dependency;
- correct Information item, wrong referent/time;
- correct delegation parties, wrong operation/scope/principal.

Typed semantic positions are therefore more fundamental than one generic arrow direction.

## Applicability is relation-semantic when changing it changes the claim

The same anchors can bear different valid relations under different:
- focal Work;
- scope;
- analytical/reference frame;
- operation;
- method/stage;
- target version/state;
- use/purpose;
- time interval.

A binding is incomplete when changing an omitted frame would change whether it meaningfully holds.

## Qualified / n-ary binding

Naive binary decomposition can lose which qualifiers belong to which relation occurrence.

Example:

```text
Actor A performs Work W at t1
Actor A verifies Work W at t2
```

must not be reduced to an ambiguous bag containing both roles and both times.

The semantic requirement is relation-instance individuation and preservation of all relevant positions/qualifiers.

No particular reification/graph/object pattern is mandated.

## Relation type inference

Graph topology is not semantics.

Do not infer by default:
- transitivity;
- symmetry;
- legitimate delegation closure;
- direct dependency from indirect support;
- authority from technical reachability.

A relation type's permitted/forbidden inference behavior is part of its meaning when decision-critical.

## Relation-family profiles

B2 found recurring profiles:

### Reference / Representation / Targeting

- representation ↔ referent;
- Work ↔ target;
- specification/evidence ↔ exact target/version.

### Participation / Position

- performer;
- requester;
- verifier;
- source;
- holder;
- recipient;
- beneficiary;
- accountable party.

### Dependency / Support

- Work/resource dependency;
- Information required for Work;
- Environment support/interface/path;
- Actor access/situation.

### Provenance / Attribution

- source;
- generation/derivation lineage;
- association/contribution;
- attribution.

Additional useful profiles:
- Situation / Access / Interface;
- Specification / Evidence / Traceability.

## Why profiles are not children

No profile achieves clean universal promotion because:
- they overlap;
- their deep semantics often already belong to accepted grounds;
- they leave residual valid bindings outside a clean partition;
- qualification/arity grammar recurs across every profile.

Examples:

```text
Actor source of Information
= participation + provenance

evidence about target produced by Work
= reference + provenance + Work binding

required reviewer
= participation + dependency + later Control
```

The stable Binding-local failure family is stronger than the family taxonomy.

## Binding-local failures

- wrong anchor;
- wrong semantic position/role;
- wrong relation meaning;
- lost scope/reference frame;
- wrong/stale temporal applicability;
- qualifier cross-combination;
- invalid relation inference from topology;
- generic-link semantic loss;
- represented relation mistaken for actual relation.

## External holdouts

### W3C PROV-O

Qualified Usage/Association/Delegation and role/time semantics pressure generic relation models and support the signature grammar.

### W3C n-ary relations note

Supports relation-instance arguments/qualification and semantic loss from naive binary decomposition while remaining representation-pattern guidance rather than Foundation taxonomy authority.

### W3C Web Annotation

SpecificResource, Selector, State, Purpose and Scope provide a strong counterexample to treating a resource identifier alone as the exact relational target.

### NIST ABAC

Subject/object/requested-operation/environment-condition structure shows why precise binding is prerequisite to later authorization/control evaluation.

### Candidate studies

Anthropic AI-native SDLC, multi-agent patterns and context/memory/harness material reinforced exact artifact/version, role, delegation, source/context and environment-path binding pressure.

None forced a Binding child split.
