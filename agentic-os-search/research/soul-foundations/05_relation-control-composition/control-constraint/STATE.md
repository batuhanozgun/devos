## Strongest discovery

```text
governed-effect / control-objective scope
!= enforcement-point / monitored-path scope
```

Therefore:

```text
one path blocked
!= protected effect controlled
```

A local mechanism can behave correctly while an indirect Actor/tool/service/physical route defeats the protected control objective.
