## 4. Boundary correction required before S1

The parent label `Composite Standing / Qualification` must **not** be interpreted as a universal home for every criterion-relative standing.

Current stronger distinction:

### Ground-local standing

Remain inside an accepted ground when the protected truth question can be answered without composing several ground semantics.

Examples:
- realized Environment condition is over-temperature relative to an applicable threshold;
- an Environment constituent is degraded/nonconforming under a criterion;
- Actor has an authority/obligation standing that is Actors-local once the constitutive regime is treated as part of that standing semantics;
- Work is in a Work-local lifecycle/admission state;
- an informational state carries a local epistemic/freshness qualification.

The existence of an Information representation of the criterion does not by itself make the standing cross-ground.

### Composite / cross-ground standing

This child applies when the **truth/evaluation conditions of the standing require semantics from multiple accepted grounds or their exact bindings**, and projecting the result onto one ground would hide decision-critical prerequisites.

Examples:

```text
Actor capability
+ Environment access/affordance
+ specific Work action/path
(+ authority/control facts)
→ actionable-now?
```

```text
exact target/version
+ criterion/requirement
+ verification Work/method
+ evidence/result
(+ verifier/authority/independence where material)
→ verified?
```

```text
intended use
+ actual/use Environment
+ target performance/evidence
+ stakeholder/user criterion
→ validated / fit for intended use?
```

```text
sought condition/criterion
+ actual Environment condition
+ evidence of that condition
(+ authority for acceptance where the question is acceptance rather than attainment)
→ outcome attained / accepted?
```

This boundary is a live hypothesis to attack in S1–S7.

## 5. Other accepted ground pressures

### Information

Accepted correction:

```text
evidence is target-relative, not an intrinsic Information subtype
actual condition
!= informational representation
!= source authority
!= factual truth
!= evidential role

```

This creates standing pressure for `evidence sufficient for claim/use/decision` without moving the standing into Information by identity.

### Work

Accepted non-collapse:

```text
Work completion
!= actual target condition achieved
!= evidence says achieved
!= authorized acceptance occurred
```

Work already distinguishes completion, verification, validation and acceptance as overlapping analytical dimensions; Composite Standing must not reclassify all of these as Work-local status labels.

### Actors

Accepted non-collapse:

```text
Actor capability
!= Environment access/availability
!= situated actionability

Actor authority
!= technical effect power
!= runtime enforcement outcome

Work acceptance state
!= authority to accept
```

This is strong evidence for cross-ground actionability/authorization/acceptance standings while preserving Actors-local authority semantics.

## 8. Live falsifiers entering S1

### F1 — Environment duplication
Composite Standing is redundant with accepted Environment Criterion-Relative Standing.

### F2 — Binding-predicate collapse
Every candidate standing is merely a predicate over correct Binding anchors and needs no distinct research region.

### F3 — ground-localization
`verified`, `ready`, `authorized`, `accepted`, `sufficient` can always be stored/recovered safely inside one ground.

### F4 — Control theft
Authorization/eligibility/compliance standings are really Control questions; Standing lacks a stable boundary.

### F5 — Transition theft
Freshness/invalidation/currentness are entirely Transition semantics; Standing need not carry reference-time validity.

### F6 — result-domain triviality
Boolean/graded/uncertain/unknown differences are implementation details rather than Foundation semantics.

### F7 — true-vs-evaluated collapse
There is no useful distinction among true standing, evaluated standing, decision outcome and recorded/asserted status.

### F8 — family split
Readiness/actionability, assurance/acceptance, epistemic sufficiency, outcome attainment or eligibility form stable immediate children.

### F9 — missing Binding distinction
Standing analysis requires a Binding distinction absent from the accepted Binding leaf.

### F10 — upstream adequacy failure
A recurring standing family reveals a fifth ground or composition region rather than a child-local issue.
