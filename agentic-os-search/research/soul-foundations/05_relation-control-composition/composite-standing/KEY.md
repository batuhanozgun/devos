Canonical gloss:

> **A Composite Standing is a qualification whose constitutive/defining semantics irreducibly depend on multiple accepted Foundation grounds or their exact bindings. Cross-ground evidence, reporting or assessment access alone does not make a ground-local standing Composite.**

## Critical boundary

Environment already owns accepted `Criterion-Relative Standing` for true current Domain Condition standing under an applicable criterion/regime.

Therefore:

```text
ground-local criterion standing
!= cross-ground Composite Standing
```

Use the counterfactual semantic-removal test:

> If another-ground anchor were removed from the standing's definition while preserving our ability to observe/know the local bearer, would the standing's meaning change?

If no, the standing is likely ground-local and the cross-ground material is only evidence/access. If yes, Composite Standing is likely the correct composition region.

## Stable semantic core

```text
Composite Standing core
├─ standing meaning / protected qualification question
├─ exact qualified focus + accepted Binding instances
├─ qualification frame
│  ├─ criterion / requirement / threshold / norm / intended use
│  ├─ scope / operation / population / jurisdiction / reference frame
│  └─ time/version/state where material
├─ constitutive cross-ground basis
├─ object-level result semantics
└─ validity dependencies/currentness
```

Optional but non-collapsed layers:

```text
epistemic assessment
├─ evidence / measurement / observation
├─ method/model/decision rule
├─ evaluator/verifier/adjudicator
└─ uncertainty/confidence/coverage

recognition / decision [when present]
├─ authorized Actor/forum/regime
└─ accept/reject/approve/certify/recognize outcome
```

## Strongest non-collapse rules

```text
cross-ground evidence/access != proof standing is composite

standing holds
!= assessment supports it
!= decision recognizes it
!= record says it holds

criterion != decision rule

false
!= unknown/indeterminate
!= not evaluated
!= not applicable
!= stale

verified != validated != accepted
capable != actionable != authorized != technically reachable
standing currentness != transition/history
```
