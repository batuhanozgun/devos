# Composite Standing / Qualification — Integrated Synthesis

**Status:** bounded synthesis / awaiting user evaluation  
**Date:** 2026-09-05

## Executive conclusion

Composite Standing / Qualification was researched as the second child of accepted Cross-Ground Composition, after Relational Binding had closed as an accepted bounded leaf.

Strongest current result:

```text
Composite Standing / Qualification
    ← BOUNDED LEAF
    ← cross-ground qualification only
    ← no immediate child promoted
    ← shared semantic core + optional assessment/recognition layers
    ← overlapping standing profiles
```

The decisive boundary correction is:

> **Composite Standing is not the universal home of all standing/status. It applies only where several accepted-ground semantics are part of what the qualification means or what constitutes it. Cross-ground evidence, assessment Work, reporting or access alone does not make a ground-local standing Composite.**

## Existing Environment standing boundary

Environment already contains accepted:

```text
Domain Condition
├─ Realized Characteristics
└─ Criterion-Relative Standing
```

Environment Criterion-Relative Standing asks what true current standing obtains for a Domain bearer under the applicable criterion/regime.

That node remains intact.

Use the counterfactual semantic-removal test:

> If another-ground anchor were removed from the standing's definition while preserving our ability to know/observe the local bearer, would the standing's meaning change?

If not, the standing is likely ground-local and the other-ground material is epistemic access. If yes, cross-ground composition is likely constitutive.

## Main discovery — one cross-ground qualification grammar

```text
Composite Standing core
├─ standing meaning / protected qualification question
├─ exact qualified focus + accepted Binding instances
├─ qualification frame
│  ├─ criterion / requirement / threshold / norm / intended use
│  ├─ scope / operation / population / jurisdiction / reference frame
│  └─ time/version/state where material
├─ constitutive cross-ground basis
├─ object-level result semantics
└─ validity dependencies/currentness
```

The core says what standing is being claimed and what makes it hold.

## Two associated layers that must not collapse into the standing core

### Epistemic assessment

```text
evidence / measurement / observation
+ method/model/decision rule
+ evaluator/verifier/adjudicator
+ uncertainty/confidence/coverage
→ assessment of the standing
```

### Decision / recognition

```text
assessment/basis
+ decision rule/regime
+ authorized Actor/forum
→ accept / reject / approve / certify / recognize
```

These layers are optional and domain-dependent.

Some institutional decisions are constitutive of a standing; others merely recognize/report one. No universal identity is assumed.

## Strongest three-layer distinction

```text
object/constitutive standing
!= epistemic assessment
!= decision/recognition outcome
!= Information record/status field
```

JCGM 106 provides the strongest external pressure:

```text
actual conformity
!= conformance probability / state of knowledge
!= accept/reject decision under decision rule
```

Measurement uncertainty can create false acceptance or false rejection risk without changing the item's underlying conformity standing.

## Result semantics

No universal boolean model survives.

Composite standings may require:
- binary results;
- categories;
- ordinal levels;
- graded/severity results;
- scalar + threshold;
- probabilistic/uncertain assessment;
- intervals/bounds;
- partial/coverage semantics;
- epistemic indeterminacy.

Required non-collapse:

```text
false
!= unknown / indeterminate
!= not evaluated
!= not applicable
!= stale
```

These exact labels need not become one implementation enum. The distinctions matter whenever they drive different decisions or recovery Work.

## Applicability before evaluation

A criterion must not be treated as failed merely because it does not apply.

Examples:
- wrong jurisdiction;
- wrong operation;
- wrong target version;
- wrong mission phase;
- wrong population/use/reference frame.

Therefore:

```text
criterion exists
!= criterion applies to this exact focus
```

## Criterion versus decision rule

The criterion defines what qualification means or what condition is required.

A decision rule defines how uncertain/mediated evidence becomes an assessment or decision.

JCGM guard-band cases show the same specification/evidence can produce different accept/reject outcomes under different decision rules while object-level conformity need not change.

Thus:

```text
criterion != decision rule
```

## Currentness / validity dependencies

A present standing may depend on:
- exact target/version/state;
- criterion/requirement/policy version;
- scope/use/jurisdiction;
- evidence/source validity;
- Environment conditions;
- Actor authority/delegation;
- Work action/method/path;
- evaluation method/model;
- waiver/exception/credential validity.

But:

```text
dependency changed
→ standing may require re-evaluation
!= standing necessarily changed
```

Standing owns current applicability/validity dependency semantics. Transition owns the event/change/propagation history and recomputation mechanics.

## Standing profiles retained — not children

### Readiness / Actionability / Feasibility

Key distinctions:

```text
capable
!= technically possible now
!= actionable for this Work/path
!= institutionally authorized
!= safely permitted
!= reachable effect power
```

### Verification / Validation / Conformance / Acceptance

```text
verified against requirement
!= validated / fit for intended use
!= accepted
```

Pure Domain conformance may remain Environment-local. Verification/validation/acceptance can become cross-ground because their meaning includes exact target, criterion/use, Work/evidence and sometimes Actor authority.

### Epistemic / Evidential Sufficiency

```text
information exists
!= information is evidence for claim C
!= evidence is sufficient for decision/use D
!= source is authoritative for role/use U
```

### Eligibility / Applicability / Authorization

This is the strongest Standing/Control boundary profile.

```text
request satisfies current authorization criteria
!= policy/rule that governs it
!= authorization/enforcement mechanism
```

### Goal / Outcome Attainment

Pure actual Environment criterion satisfaction may remain Environment-local. Exact Work-objective, evidence, intended-use or recognized-attainment semantics can make the qualification cross-ground.

### Risk / Priority / Fitness

Context/value/tolerance-relative and highly overlapping with validation, evidence sufficiency and Control. Retained as conditional profile only.

## Why profiles are not immediate children

No profile survives universal promotion because:
- the same vocabulary can be ground-local or composite;
- profiles overlap in real operational questions;
- a single decision such as `deployable` can require readiness + validation + risk tolerance + authorization;
- family splits duplicate accepted ground semantics;
- all profiles use the shared qualification grammar.

## Why semantic layers are not children

`Constitutive Standing / Epistemic Assessment / Decision-Recognition` are mandatory distinctions but false siblings:
- many standings do not instantiate all layers;
- assessment is often Work/Information-mediated access;
- authorized decision can itself constitute institutional standing;
- decision/recognition overlaps Control;
- one episode can instantiate all three.

## External holdout result

### NASA verification / validation

Supports exact target, criterion, evidence, intended-use and Environment binding while showing verification and validation differ by qualification frame.

### JCGM 106 / VIM

Strongest support for separating underlying standing, uncertainty-bearing assessment and acceptance decision.

### NIST ABAC

Shows request-specific authorization depends on subject/object/operation/environment/policy context while preserving distinction between evaluated authorization standing and Control/enforcement.

### NASA TRL

Important negative holdout: `readiness` vocabulary can remain a ground-local criterion-relative Environment standing. Vocabulary alone cannot route to Composite Standing.

### NIST AI RMF

Supports deployment-context-relative validity/reliability/risk evaluation, uncertainty and measurement limitations without creating a Risk/Fitness child.

### Candidate studies

Anthropic AI-native SDLC, multi-agent patterns, context-memory-harness and AI knowledge-strategies reinforce:
- artifact/test/context existence != semantic sufficiency;
- role label != valid verifier/authority standing;
- persisted/selected context != sufficient/current context;
- retrieval success != adequate evidence universe.

No holdout forced a child or upstream reopen.
