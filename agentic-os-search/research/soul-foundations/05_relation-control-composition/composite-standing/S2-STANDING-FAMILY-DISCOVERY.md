# Composite Standing / Qualification — S2 Standing-Family Discovery

**Status:** COMPLETE  
**Date:** 2026-09-05

## 1. Purpose

Test whether recurring cross-ground qualifications form stable immediate children or remain overlapping standing profiles under one shared semantic signature.

## 2. Family A — Readiness / Support / Actionability / Feasibility

### Protected question

> Given the exact actor/work/action/path and current conditions, is the contemplated operation/pursuit currently feasible/actionable/supported in the relevant sense?

### Typical anchors

- Actor capability/competence;
- Environment access, interface, resource, credential/network availability;
- Work action/method/path/target;
- policy/authority facts when `legitimately actionable` rather than merely technically feasible is the question;
- Information about current conditions/configuration where evaluation depends on representations.

### Distinctions

```text
capable
!= technically possible now
!= currently actionable for Work W
!= institutionally authorized
!= safely permitted
!= indirectly reachable effect power
```

### Failure modes

- one prerequisite treated as sufficient;
- wrong Work/action/path;
- stale Environment condition;
- capability confused with access;
- technical reach confused with legitimate authority;
- represented configuration confused with realized access.

### Child pressure

Strong profile, but not yet a clean child:
- `ready` can be Work-local or Environment-local depending protected question;
- `actionable` often adds Control semantics when legitimacy matters;
- same shared standing grammar applies.

**Current verdict:** retain as profile, do not promote yet.

## 3. Family B — Verification / Validation / Conformance / Acceptance / Assurance

### Protected questions are not identical

```text
verified against requirement/criterion?
validated / fit for intended use?
conforming under specification?
accepted by authorized party/forum?
```

### Typical anchors

- exact target/version/state;
- requirement/criterion/specification/intended-use statement;
- verification/validation/review Work and method;
- evidence/results;
- actual/use Environment where reality-facing;
- verifier/customer/user/acceptance authority where material.

### Distinctions

```text
verified
!= validated
!= accepted
!= actual target condition necessarily achieved
```

A target can be verified against a specification that is itself insufficient for intended use. An authorized party can accept something that remains imperfect or nonconforming under another criterion.

### Failure modes

- exact target/version drift;
- criterion ambiguity or wrong requirement;
- evidence not tied to target;
- verification activity exists but result unsupported;
- validation performed in wrong use environment;
- acceptance authority missing or wrong;
- acceptance conflated with truth/conformance.

### Boundary with Environment Criterion-Relative Standing

Pure actual conformance of a Domain object to a criterion may remain Environment-local.

Composite Standing is needed when the standing being asked is specifically:
- `verified against C via evidence/method W`;
- `validated for intended use U in environment E`;
- `accepted by authorized Actor A/forum F`;
- or another qualification whose meaning includes cross-ground anchors.

### Child pressure

This family is highly salient but internally heterogeneous. The shared standing grammar explains the differences through qualification frame and constitutive/evaluation basis rather than needing a dedicated child.

**Current verdict:** strong profile, not a child yet.

## 4. Family C — Goal / Outcome / Satisfaction / Attainment

### S0/S2 correction

Do not automatically route every `goal attained?` question to Composite Standing.

If the protected question is simply:

```text
actual Environment condition
satisfies desired/required criterion?
```

then the result can be Environment `Criterion-Relative Standing`, even if the desired criterion is represented in Information or originated from Actor preference.

### Composite cases

Cross-ground composition becomes load-bearing when the standing's meaning includes additional anchors, for example:
- `the exact Work objective for W has been achieved` where Work-target binding identity matters;
- `outcome evidence is sufficient to establish attainment`;
- `attainment is accepted/recognized under an authority/contractual regime`;
- `objective is attained for intended use/population/reference frame` requiring multi-ground applicability.

### Failure modes

- Work completion treated as outcome attainment;
- desired condition confused with actual condition;
- evidence confused with realized outcome;
- wrong target/reference frame;
- acceptance confused with attainment.

### Child pressure

Once pure Environment criterion-standing is removed, remaining cross-ground cases share the generic Composite Standing signature and overlap heavily with assurance/acceptance.

**Current verdict:** profile/cross-cutting pattern, not a child.

## 5. Family D — Epistemic / Evidential Sufficiency / Authority-for-Use

### Protected question

> Is the available informational/evidential basis sufficient, reliable, current or authoritative enough for a specific claim, inference, decision or Work use?

### Typical anchors

- claim/question/decision target;
- evidence set / Information items;
- source/provenance bindings;
- uncertainty/conflict/currentness;
- Work purpose/decision threshold;
- Actor expertise/mandate where authority-for-use matters;
- source universe / missing-evidence pressure.

### Distinctions

```text
information exists
!= information is true
!= information is evidence for claim C
!= evidence is sufficient for decision D
!= source is authoritative for role/use U
```

### Failure modes

- retrieval miss treated as absence;
- selected context treated as complete evidence universe;
- source authority treated as truth;
- evidence relevance treated as sufficiency;
- stale or version-mismatched evidence;
- unknown uncertainty/coverage suppressed.

### Why this is not Information-local by default

Information owns content/provenance/currentness/epistemic standing of informational states, but `sufficient for Work decision D` or `authoritative for role/use U` is use-/Actor-/Work-relative and therefore cross-ground.

### Child pressure

Distinct epistemic vocabulary, but same signature:
- qualified focus;
- use/decision criterion;
- evidence/basis;
- result semantics;
- uncertainty/currentness.

It also overlaps verification/validation strongly.

**Current verdict:** retain as high-priority profile; no child promotion yet.

## 6. Family E — Eligibility / Applicability / Authorization Standing

### Protected question

> Under the applicable rules, scope and current facts, does this bearer/request/action fall within the set for which a permission, eligibility or applicability condition holds?

### Typical anchors

- Actor/bearer/requestor;
- object/target;
- operation/action/Work transition;
- current Environment conditions;
- policy/rule/criterion;
- authority/delegation standing;
- jurisdiction/scope/time.

### Distinctions

```text
eligible/applicable/authorized standing
!= policy text
!= control requirement
!= authorization decision process
!= technical enforcement
!= observed execution
```

### Failure modes

- wrong operation/scope/environment;
- expired/revoked attribute;
- policy version mismatch;
- represented role/credential mistaken for actual standing;
- permission confused with obligation;
- decision result confused with runtime enforcement.

### Standing versus Control boundary

This is the strongest overlap case.

Composite Standing asks:

> Given the governing criteria and current facts, what authorization/eligibility qualification holds for this exact request/operation/context?

Control asks:

> What rule/authority/decision/enforcement makes the transition permitted, required, blocked, gated or escalated, and how are bypass/alternate paths handled?

The standing can be an evaluated input/output of a control system without owning enforcement semantics.

### Child pressure

Strong but too coupled to Control to promote before Control research; promotion now would pre-empt the sibling.

**Current verdict:** retain as boundary profile; do not promote.

## 7. Family F — Risk / Priority / Fitness / Suitability

### Protected questions vary widely

- risk acceptable under tolerance?
- Work priority high relative to alternatives?
- system fit/suitable for use?
- candidate eligible/desirable given value/cost/uncertainty?

### Typical anchors

- Actor/stakeholder values/preferences/tolerance;
- Information estimates/uncertainty;
- Environment consequences/exposure;
- Work options/capacity/opportunity cost;
- intended use/decision context.

### Failure modes

- scalar score treated as intrinsic truth;
- risk tolerance omitted;
- context/population differences erased;
- uncertainty hidden;
- priority treated as timeless Work property;
- fitness collapsed into technical performance alone.

### Child pressure

This region is highly evaluation-specific and may later support domain profiles, but its semantic question is not stable enough as one universal family. It overlaps outcome/validation, epistemic sufficiency and decision/control.

**Current verdict:** do not promote.

## 8. Cross-family comparison

### 8.1 Shared grammar dominates

All families require some version of:

```text
exact qualified focus
+ qualification frame/criterion/use
+ constitutive multi-ground basis
+ result semantics
(+ evaluation/access basis where knowledge/decision is mediated)
+ validity/currentness dependencies
```

### 8.2 Family boundaries are porous

Examples:

```text
"ready for deployment"
= readiness
+ validation/fitness
+ risk tolerance
+ authorization/eligibility
```

```text
"evidence sufficient to accept"
= epistemic sufficiency
+ acceptance authority
+ assurance target/criterion
```

```text
"authorized and actionable"
= authorization standing
+ actionability/feasibility
+ later Control/enforcement
```

These are exactly the kinds of false disjointness that make family-first child promotion risky.

### 8.3 Some candidate standings are ground-local after clarification

Not every familiar `status` belongs here:
- pure Environment conformance/health/criterion standing → Environment;
- Work lifecycle/admission state → Work;
- Actor authority/obligation standing → Actors;
- Information local freshness/reliability/uncertainty → Information.

Composite Standing is only for the cross-ground qualification.

## 9. Candidate immediate-child verdict after S2

No family currently clears all promotion criteria:
- distinct protected question;
- distinct failure family;
- cross-domain stability;
- low overlap;
- no duplication of accepted ground semantics;
- clean boundary with Control/Transition.

Current strongest hypothesis:

```text
Composite Standing / Qualification
    ← likely bounded leaf
    ← one shared cross-ground standing signature
    ← multiple overlapping standing profiles
```

This remains provisional until S3–S7.

## 10. S2 residuals entering S3

S3 must test whether the leaf hypothesis survives:
- non-boolean result domains;
- false vs unknown vs not-evaluated vs not-applicable;
- partial/graded satisfaction;
- conflicting evidence;
- probabilistic conformity;
- threshold/decision-rule dependence;
- criterion/target/evidence/authority/environment drift;
- stale recorded/materialized standing;
- difference between current standing validity and transition/invalidation history.

## 11. S2 judgment

Standing profiles are real and load-bearing, but the current evidence favors **shared semantic grammar over family children**.

Proceed to S3.
