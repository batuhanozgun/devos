# Composite Standing / Qualification — S6 Synthesis / Immediate-Child Decision

**Status:** COMPLETE / PROVISIONAL BOUNDED-LEAF DECISION  
**Date:** 2026-09-05

## 1. Executive synthesis

Composite Standing survives as a coherent cross-ground composition problem, but only with a sharpened boundary:

> **Composite Standing / Qualification concerns a qualification whose constitutive or defining semantic basis irreducibly depends on multiple accepted Foundation grounds or their exact bindings.**

It is **not** the universal home of all criterion-relative standing, assessment, status labels, readiness, conformance, authorization or acceptance vocabulary.

Current strongest structural judgment:

```text
Composite Standing / Qualification
    ← BOUNDED LEAF at current Foundation depth
    ← no immediate child promoted
    ← one reusable cross-ground qualification grammar
    ← overlapping standing profiles
```

S7 must attack this conclusion.

## 2. Critical upstream boundary correction

Environment already owns an accepted node:

```text
Domain Condition
└─ Criterion-Relative Standing
```

That node asks what true current standing obtains for a selected Domain bearer under an applicable criterion/regime.

Composite Standing therefore uses a stricter routing test.

### Ground-local route

Keep a standing ground-local when:
- its protected truth question belongs to one accepted ground;
- other-ground Information/Work/Actors merely provide evidence, assessment, access or reporting;
- removing those access mechanisms would make the standing harder to know, but would not change what the standing means.

### Composite route

Use Composite Standing when:
- several ground-local semantics are part of the standing's definition/constitutive basis;
- projecting the result onto one ground would hide decision-critical prerequisites;
- the qualification frame itself binds several grounds.

Examples:

```text
Actor capability
+ Environment access
+ exact Work action/path
→ technically actionable now?
```

```text
exact product/version
+ specified requirement
+ verification Work/method/evidence
→ verified against that requirement?
```

```text
exact product
+ intended use / stakeholder expectation
+ intended Environment
+ validation evidence
→ validated / fit for intended use?
```

```text
Information evidence set
+ target claim
+ Work decision/use threshold
(+ Actor/source authority where material)
→ evidence sufficient for this use?
```

## 3. Final semantic grammar

The strongest current structure separates the **standing core** from optional access/recognition layers.

### 3.1 Standing core

```text
Composite Standing core
├─ standing meaning / protected qualification question
├─ qualified focus
│  ├─ exact target/subject/claim/action/Work/Actor/condition
│  └─ exact Relational Binding instances needed to identify it
├─ qualification frame
│  ├─ criterion / requirement / threshold / norm / intended use
│  ├─ scope / operation / population / jurisdiction / reference frame
│  └─ effective/reference time + exact version/state where material
├─ constitutive cross-ground basis
│  └─ facts/bindings/rules/authorized acts needed for the standing to hold
├─ object-level result semantics
└─ validity dependencies/currentness conditions
```

This is the standing truth/constitution core.

### 3.2 Epistemic/evaluation layer — optional

When the standing is not directly established by its constitutive facts, preserve separately:

```text
evidence / measurement / observation
+ method / model / decision rule
+ evaluator/verifier/adjudicator
+ uncertainty / confidence / coverage
→ assessment of standing
```

The assessment may be wrong or indeterminate.

### 3.3 Decision / recognition layer — optional

When a domain has explicit institutional recognition/decision:

```text
evaluation/basis
+ decision rule/regime
+ authorized Actor/forum
→ accept / reject / approve / certify / recognize
```

The decision may:
- merely recognize/report a pre-existing standing;
- create a distinct institutional standing;
- or serve as a Control input/output.

Do not assume one universal case.

## 5. Result-domain conclusion

No universal boolean standing model survives.

Foundation must be compatible with:
- binary;
- categorical;
- ordinal;
- graded/severity;
- scalar + threshold;
- probabilistic/uncertain assessment;
- interval/bounds;
- partial/coverage;
- epistemic indeterminacy.

However result-domain shape is a **dimension**, not a child taxonomy.

## 6. Validity / invalidation conclusion

Composite Standing needs to preserve which load-bearing dependencies make a present-tense result valid/applicable.

Potential dependency changes:
- target/version;
- criterion/policy/requirement;
- scope/use/jurisdiction;
- evidence/source;
- Environment conditions;
- Actor authority/delegation;
- Work action/method/path;
- evaluation method/model;
- waiver/exception/credential.

But Standing does not own the transition history or recomputation mechanism.

Strong rule:

```text
dependency changed
→ prior standing may require re-evaluation
!= standing necessarily flipped
```

## 7. Profile map retained — not children

### Readiness / Actionability / Feasibility
Cross-ground only where the standing meaning actually composes Actor/Environment/Work/etc.

### Verification / Validation / Conformance / Acceptance
Different qualification frames under a common grammar; pure Domain conformance may remain Environment-local.

### Epistemic / Evidential Sufficiency
Strong cross-ground profile when sufficiency is relative to claim/decision/Work use.

### Eligibility / Applicability / Authorization
Strong Standing/Control boundary profile; current qualification result remains separable from rule/enforcement semantics.

### Goal / Outcome Attainment
Pure actual criterion satisfaction may be Environment-local; exact Work-objective/evidence/recognition composition can be cross-ground.

### Risk / Priority / Fitness
Context/value/tolerance-relative profile; not stable enough for a universal child.

## 8. Why no immediate child is promoted

### Family splits fail
- high overlap;
- same label can be ground-local or composite;
- several profiles combine in one operational standing;
- families duplicate accepted ground semantics.

### Semantic-layer splits fail
`Constitutive Standing / Epistemic Assessment / Decision-Recognition` are mandatory distinctions, but not stable sibling populations.

### Descriptive/normative splits fail
High-value cases are hybrid.

### Result-type splits fail
They are representation/result dimensions.

### Criterion-source splits fail
One standing can involve technical, use, regulatory and value criteria simultaneously.

## 9. External holdout result

### NASA verification/validation
Supports exact target, criterion, use/environment and evidence semantics while showing verification and validation differ by qualification frame rather than requiring separate Foundation children.

### JCGM conformity assessment
Strongly supports:

```text
actual conformity
!= conformance probability/state of knowledge
!= accept/reject decision
```

### NIST ABAC
Supports operation/environment/context-relative authorization evaluation while preserving Standing versus Control/enforcement.

### NASA TRL
Provides a negative routing counterexample: `readiness` vocabulary can remain ground-local criterion standing.

### NIST AI RMF
Supports context-relative validity/reliability/risk qualifications and uncertainty/measurement limitations without requiring a Risk/Fitness child.

### Candidate studies
Reinforce:
- tests/artifacts/context availability do not prove sufficiency/correctness;
- role label does not establish valid verification/authority;
- retrieval success does not establish evidence-universe adequacy.

No holdout forces child promotion or upstream reopen.

## 10. Label decision

The accepted label remains usable if its gloss is made explicit:

> **Composite Standing / Qualification = cross-ground qualification whose constitutive/defining semantics cannot be localized to one accepted ground.**

Do not rename solely to reduce theoretical ambiguity at this stage; `Cross-Ground Qualification` remains a possible future label if later child work repeatedly misroutes cases.
