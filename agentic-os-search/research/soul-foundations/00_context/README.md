# Layer 0 — Context Dependency

## Role

Layer 0 is not re-run or copied into this package. The completed bounded context reconstruction remains in `research/soul-context/`.

Its role for SOUL Foundations Research is to provide a starting problem-space signal, not a final architecture or ontology.

## Current carry-forward

Prior repository research did not establish the final SOUL architecture. It did, however, surface a useful research hypothesis: persistent records/artifacts, work, and actors appear important enough to deserve separate first-principles investigation before their relationships or a larger architecture are synthesised.

This carry-forward is deliberately weak:

- it justifies opening the three current vertical research lines;
- it does **not** establish that they are exhaustive;
- it does **not** establish that they are irreducible primitives;
- it does **not** privilege predecessor mechanisms as SOUL architecture truth.

## Canonical source

For exact claims about prior repositories, use `research/soul-context/INDEX.md` and recover the relevant evidence and primary repository source through that package's retrieval chain.

## Transition condition

Layer 0 is sufficient for the current purpose because it provides enough bounded context to begin independent foundation research. Layer 1 evidence may later require reopening or reframing parts of the context, but no such need is assumed in advance.
