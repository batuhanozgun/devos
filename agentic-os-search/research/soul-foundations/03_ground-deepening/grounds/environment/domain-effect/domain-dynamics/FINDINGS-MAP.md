## Explicit Dynamics problem regions — not children

1. **Realized occurrence / interaction** — processes, flows, coupling, feedback, disturbances, initiation/continuation/cessation.
2. **Realized change / transition / trajectory** — State changes, ordering, evolution, gradual/abrupt transition, recovery, regime change.
3. **Temporal dependence / memory** — delay, lag, persistence, hysteresis, path dependence, hidden-state versus genuine memory.
4. **Dynamic pattern / regime** — equilibrium/non-equilibrium, oscillation, stability, attractor/basin, synchronization, tipping.
5. **Multi-scale / nested Dynamics** — scale/reference dependence of event/process/disturbance descriptions.

These remain explicit because omitting them can break reasoning. They are not promoted because their boundaries are not stable enough across domain, scale, formalism and reference to justify independent recursive branches.
