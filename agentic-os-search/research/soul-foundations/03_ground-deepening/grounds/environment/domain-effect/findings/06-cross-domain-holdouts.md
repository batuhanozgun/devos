# Domain Reality Finding 06 — Cross-Domain Holdouts

**Status:** current active-node adversarial finding  
**Verification class:** same-model scenario challenge; not independent verification

## Candidate under attack

```text
Domain Reality
    ├─ Domain State / Configuration
    └─ Domain Dynamics / Processes
```

`Effect/Outcome` is treated as actual domain transition/result plus cross-ground causal/outcome relations, not a third child.

## Holdout 1 — SOUL / KEEL / Development OS product work

### State / Configuration
- actual deployed/product/system configuration;
- current service/system condition;
- current externally consequential behavior/state when material.

### Dynamics / Processes
- runtime interactions;
- failures/recovery;
- system evolution during operation;
- external/system processes that alter behavior.

### Boundary challenge
Source code/specification/Records remain Information in their meaning/provenance role. GitHub/CI/runtime can instead be Work Conditions when supporting development.

**Result:** two children sufficient; role separation required.

## Holdout 2 — clinical diagnosis without intervention

### State / Configuration
- actual current physiology, pathology and relevant condition.

### Dynamics / Processes
- disease progression;
- physiological processes;
- spontaneous/recovery trajectories.

No intended intervention/effect is required for a genuine Domain Reality.

**Result:** falsifies `effect` as mandatory co-equal branch; two children survive.

## Holdout 3 — clinical treatment

### State / Configuration
- patient state before/during/after treatment.

### Dynamics / Processes
- disease and physiological processes;
- treatment interaction with those processes;
- delayed adverse/recovery trajectories.

Whether improvement was **caused by** treatment is not identical to the observed post-state.

**Result:** effect is relation/attribution; no third child.

## Holdout 4 — physical repair / maintenance

### State / Configuration
- actual machine composition/configuration;
- current damage/wear/operating condition.

### Dynamics / Processes
- operation;
- degradation;
- heat/flow/vibration/failure propagation;
- repair-caused transitions and independent disturbances.

**Result:** current condition and change mechanisms expose distinct failure modes; two-child split productive.

## Holdout 5 — scientific observation / experiment

### State / Configuration
- specimen/system/phenomenon condition at relevant times.

### Dynamics / Processes
- natural/experimental process evolution;
- interactions and disturbances.

Observation-only inquiry needs both while causing no intended effect. Intervention adds an action-to-transition relation.

**Result:** two-child split survives both observational and interventionist science.

## Holdout 6 — market/business decision or intervention

### State / Configuration
- current prices/liquidity/inventory/customer/market conditions where material;
- actual institutional/venue status in its domain role.

### Dynamics / Processes
- transactions/flows;
- demand/supply changes;
- market/customer transitions;
- delayed feedback/network effects.

Actor identities, forecasts and price feeds remain separate Actor/Information semantics when relevant.

**Result:** no type-specific economic child required.

## Holdout 7 — robotics / autonomous operation

### State / Configuration
- objects/terrain/traffic/spatial configuration;
- robot/target relevant condition relative to selected boundary.

### Dynamics / Processes
- motion;
- interactions;
- changing traffic/weather/object trajectories;
- exogenous events.

Specified ODD/world model remains representation; actual conditions can diverge.

**Result:** state and dynamics both load-bearing; no extra spatial/temporal child required.

## Holdout 8 — legal / institutional work

### State / Configuration
- actual current jurisdiction/applicability/standing/status in its realized institutional role.

### Dynamics / Processes
- institutional/legal processes that alter standing/status;
- deadlines/transitions/enforcement events where they change domain reality.

Rule text/interpretation remains Information; issuer/enforcer authority remains Actors/control.

**Result:** socially constituted reality fits without a separate `institutional reality` child.

## Holdout 9 — delayed / indirect effects

### State / Configuration
- intermediate and later realized conditions.

### Dynamics / Processes
- propagation path;
- delays;
- feedback;
- intervening/exogenous processes.

Causal attribution requires evidence about relation among Work/action and trajectory, not a separate Effect Reality.

**Result:** dynamics branch becomes more important; effect-child still unnecessary.

## Holdout 10 — Work whose target is Information / Actor / Work

Examples:
- revise a specification;
- train/evaluate a person;
- redesign a workflow.

These Work episodes can be meaningful without a material Domain Reality target beyond possible consequences. Environment may contribute only Work Conditions.

**Result:** `Domain Reality = everything Work targets` is rejected; optional participation is coherent.

## Third-child probes

Candidates explicitly challenged:
- Structure / composition;
- entities / objects;
- constraints / laws / invariants;
- spatial reality;
- temporal reality;
- affordances / possibility space;
- effects / outcomes;
- physical / digital / social / institutional type branches.

### Result

No candidate currently forces a third immediate child.

Mapping:
- constituents/relations/topology → State / Configuration when realized and load-bearing;
- processes/events/transitions → Dynamics / Processes;
- constraints/laws/invariants → cross-cut state/dynamics or belong partly to Information when specified/represented;
- space/time → cross-cut scope/indexing dimensions;
- affordance/actionability → cross-ground relation;
- causal effect/outcome → actual transition/result + Work/causal/evidence relations;
- domain type taxonomies → specialization profiles, not universal immediate children.

## Holdout verdict

The two-child candidate survives the current diverse set without a recurrent forced-fit family.

Later child research may still expose a missing region. This finding establishes bounded support at the current immediate-child level only.
