## Reality / evidence distinction

A true standing can obtain even when access to it is uncertain, contested or indirect. Conversely, an assessment or report can be wrong. NIST conformity decision-rule work is a key anti-collapse case because actual conformance and acceptance/rejection decisions based on uncertain measurements can diverge.

Institutional/legal standing can be partly constituted by rules and authority without becoming identical to the document or database field that reports it.
