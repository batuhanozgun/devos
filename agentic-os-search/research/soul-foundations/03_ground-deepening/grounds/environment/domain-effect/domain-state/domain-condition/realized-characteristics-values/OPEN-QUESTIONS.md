## Q2 — True/current value semantics

BIPM distinguishes true, measured and conventional quantity-value concepts. Later Information research must decide how SOUL represents claims about an actual current magnitude without confusing:
- reality-side characteristic;
- estimate/measurement;
- uncertainty;
- conventional/reference value.

Open:

## Q6 — Current mode and state sufficiency

## Q7 — Stochastic domain properties vs epistemic uncertainty

Open:
