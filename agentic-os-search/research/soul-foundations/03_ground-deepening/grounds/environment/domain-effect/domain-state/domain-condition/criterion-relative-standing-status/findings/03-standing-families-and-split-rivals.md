# Finding 03 — Standing families and split rivals

**Status:** supported bounded finding

## Question

Do functional/operational, normative/regulatory, legal/institutional, quality/validity and other standing families require stable immediate children?

## Result

No tested standing-family split survives as a stable universal immediate-child decomposition.

## Functional / operational standing

Examples:
- `Ready / not-ready`;
- healthy / degraded / failed;
- operable / inoperable.

Kubernetes readiness is explicitly based on required conditions/checkpoints. Node pressure conditions map current signals to threshold-relative conditions. NASA current automation guidance distinguishes state/readiness, system health, mode and configuration as operationally important information.

These cases demonstrate criterion-relative functional standing, but not a universal functional-standing child.

## Normative / regulatory standing

ISO 19011:2026 provides particularly discriminating evidence:
- an audit evaluates evidence against audit criteria;
- findings indicate conformity or nonconformity;
- when the criteria are statutory/regulatory requirements, the finding is termed compliance or non-compliance.

This is strong evidence against treating `compliance` as a wholly separate universal first-order standing region merely because the criterion is regulatory. The criterion provenance changes, but the generic fulfilment/recovery question remains recognizable.

## Legal / institutional standing

Official business and professional licensing sources show genuine current statuses such as:
- active / suspended / revoked / inactive;
- good standing / not good standing;
- license current / delinquent / canceled.

These standings may depend on constitutive law, authority, filings, payment, disciplinary acts or other institutional facts. This creates stronger authority/binding requirements than many functional cases.

However, it does not force a separate universal child because:
- authority/binding is not itself the current standing;
- official records/certificates can report the standing without being identical to it;
- some functional or regulatory standings also depend on authorized rule-makers and assessment procedures;
- institutional cases can be recovered using the same protected question once the applicable regime is correctly bound.

## Quality / validity / acceptability

ISO quality vocabulary frames quality through the degree to which characteristics fulfil requirements. ISO validation/verification standards, however, often use `validation` and `verification` for processes that confirm claims/information.

Therefore `quality`, `valid`, `verified` and similar words are semantically overloaded:
- some uses name true criterion-relative standing;
- some name an assessment process;
- some name an information/claim result.

This overload argues against a universal `Validity / Quality` child.

## Criterion source is not a child basis

Tested criterion sources include:
- expected function;
- configured checkpoint/threshold;
- specification/standard;
- statutory/regulatory rule;
- contract/internal requirement;
- institutional/legal regime;
- scientific/assessment protocol.

These change criterion semantics and binding, but do not consistently create separate first-order standing recovery regions.

## Falsifier impact

- F4: **rejected** — functional versus normative/regulatory/legal is not a stable universal child split.
- F5: **rejected as child promotion** — legal/institutional authority matters, but remains a boundary/binding mechanism rather than a separate universal standing child.
- F6: **rejected** — validity/quality/acceptability is too overloaded and not a stable child.
- F20: **rejected** — institutional standing does not necessarily collapse into Actor authority semantics.

## Bounded conclusion

Standing-family labels are retained as domain/problem profiles inside one node, not promoted as immediate children.
