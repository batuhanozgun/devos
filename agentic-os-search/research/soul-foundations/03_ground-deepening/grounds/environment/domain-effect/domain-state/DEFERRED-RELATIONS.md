# Domain State — DEFERRED RELATIONS

**Status:** captured during Domain-State research; not systematic composition

These observations are preserved so later relation/control research can recover them. They do not authorize another node.

## R1 — State ↔ Dynamics

- Dynamics changes Structure and/or Condition over time.
- Current Structure/Condition can constrain or enable later Dynamics.
- Identity/continuity is required to compare State across trajectories.

Do not collapse current State into process/history.

## R2 — Structure ↔ Condition

- Structure can causally contribute to current/future Condition.
- Condition can motivate structural change.
- A fact can sometimes have overlapping structural and condition roles depending on the protected reasoning.

This pass does not define a final relation taxonomy between the two children.

## R3 — Domain State ↔ Information

- observation/measurement/model/specification/report/Record can represent Domain State;
- representation can be stale, wrong, partial or delayed;
- evidence/currentness/confidence/conflict belong to later Information/composition reasoning.

## R4 — Domain State ↔ Work

- Work may inspect, maintain or change Domain State;
- intended outcome does not establish actual State;
- Work closure/status does not establish resulting State;
- success/acceptance may compare intended/accepted outcome with actual Domain State.

## R5 — Domain State ↔ Actors

- Actor actions can change Structure/Condition;
- Actor identity/capability/authority remain Actors semantics;
- an institutional structure/standing may include Actor-related facts in Domain role without transferring semantic ownership.

## R6 — Domain State ↔ Work Conditions

The same realized fact can be:
- Domain State for Work that targets/studies that reality;
- Work Condition for Work whose execution depends on it;
- both roles when both questions matter.

Role switching does not imply duplicate intrinsic object types.

## R7 — State ↔ constraints / invariants

- constraints/invariants can restrict admissible structures/conditions and transitions;
- current satisfaction/violation/binding can become a Condition fact;
- represented rule formulations may live in Information.

## R8 — State ↔ causality

Current State tells what obtains; it does not by itself establish why.

A degraded Condition may result from:
- structural arrangement;
- Dynamics;
- Work intervention;
- another Actor/system;
- Work Conditions;
- exogenous disturbance.

Later causal attribution requires additional relation/evidence semantics.

## Guardrail

Do not expand these notes into systematic composition, causal graph, relation ontology or architecture during Domain-State closure.
