# Domain Condition Finding 06 — Boundary and Anti-Collapse Result

**Status:** ACTIVE-PASS FINDING  
**Date:** 2026-09-03

## Purpose

Attempt to break the Condition result through parent/sibling leakage, representation collapse, causal collapse and missing-region search.

## Strongest current hierarchy

```text
Domain State
    ├─ Domain Structure
    │    ├─ Constituent Composition / Membership
    │    └─ Relational Organization / Topology
    └─ Domain Condition
         ├─ Realized Characteristics / Values
         └─ Criterion-Relative Standing / Status
```

This is a research hierarchy, not an ontology/schema/data model.

## Structure boundary

Keep:

```text
which constituents participate / how they are organized
≠
what current non-structural characteristics or standing they have
```

A structural relation can affect a condition and a relational condition can mention another entity. Arity does not decide the branch. The protected question does.

No holdout forced Condition back into Structure.

## Dynamics boundary

Keep:

```text
current value / mode / standing
≠
transition, trend, degradation trajectory, history or future projection
```

A mode currently obtaining is Condition. Mode change is Dynamics. Reliability over a time interval and prognosis of future health are not pure current Condition facts by identity.

## Information boundary

Keep at least:

```text
actual realized characteristic
≠ measurement / observation / estimate / model value

actual criterion-relative standing
≠ health score / status field / certificate / dashboard / assertion by identity

criterion / threshold / rule representation
≠ current fact of satisfying or violating it
```

Kubernetes gives a digital case where status/condition fields are timestamped reported markers. NIST/ISO condition-monitoring work explicitly separates sensing/measurement/analysis from assessment. Institutional certificates likewise represent a standing rather than becoming the standing by identity.

## Actors boundary

An institutional standing may be Domain Condition while:
- who has authority;
- which actor grants/revokes it;
- who may act;
- role identity and responsibility
remain Actors semantics.

No institutional holdout forced authority into Condition.

## Work Conditions boundary

A fact does not have one permanent project role by object identity.

Example:
- a machine's current temperature can be Domain Condition for diagnostic Work targeting the machine;
- the same temperature can be a Work Condition for a separate Work item whose execution depends on safe machine operation.

Role switching is handled later by relations/context, not by duplicating Condition children.

## Constraint / specification boundary

The rule or desired limit is not the current condition by identity. But whether the realized condition meets that criterion can be a current criterion-relative standing.

This preserves the earlier `Constraints / Invariants` cross-cut result while giving current satisfaction/violation a clear Condition route.

## Causal boundary

Keep:

```text
current degraded / non-compliant / abnormal condition
≠ root cause
```

The same standing can result from different structures, dynamics, Work interventions, actors, environmental circumstances or exogenous events.

Condition therefore remains descriptive of what obtains, not explanatory of why.

## Parent-reopen test

No evidence from deeper Condition research currently forces:
- a third co-equal Domain State child;
- merger of Structure and Condition;
- removal of Condition from Domain State.

The deeper Condition split refines rather than overturns the parent result.

## Missing-region search

Tested but not promoted as universal Condition children:
- Health / Quality;
- Mode / Lifecycle Status;
- Capability / Capacity / Availability / Reliability;
- Whole / Aggregate Condition;
- Constituent Condition;
- Intrinsic versus Relational Condition;
- Quantitative versus Qualitative versus Categorical condition;
- Constraints / Compliance;
- Observed / Inferred / Reported Condition;
- Physical / Digital / Biological / Market / Institutional type branches.

Each is either contained by the two surviving children, cross-cutting, role-relative, time-dependent, representation-side or domain-specific.

## Bounded judgment

The strongest current immediate Condition result is the two-child split above. Broad late probes are now refining terminology/boundaries rather than producing a recurrent third first-order region.

This supports bounded closure at the current immediate-child depth, subject to the formal same-model completion/omission audit.
