# Finding 06 — Cross-domain holdouts, omission and leaf judgment

**Status:** bounded closure finding

## Cross-domain holdout result

The refined `Criterion-Relative Standing` node survived materially different holdouts without forcing a stable immediate-child split.

### Deployed software / services

Kubernetes:
- Pod `Ready` depends on readiness conditions/gates;
- Node pressure conditions arise when current resource signals satisfy configured thresholds;
- `Running` can coexist with not-ready.

Recovered as criterion-relative operational standing while preserving API representation and lifecycle/Dynamics boundaries.

### Physical machine / process asset

NIST asset condition management distinguishes real-time condition awareness, diagnostics and current/future health assessment. Functional health standing can depend on current condition plus expected function/health model without becoming identical to raw condition signals or the diagnostic artifact.

### Manufacturing / conformity

ISO conformity assessment explicitly tests whether specified requirements are fulfilled. NIST decision-rule work demonstrates that actual conformance and acceptance decisions based on uncertain measurement can diverge.

Recovered as criterion-relative standing; assessment/evidence remains separate.

### Regulatory / audit compliance

ISO 19011:2026 states that audit findings indicate conformity/nonconformity; when audit criteria are statutory/regulatory, findings are termed compliance/non-compliance.

Regulatory provenance changes criterion semantics, not the universal recovery region.

### Financial / banking

FDIC capital categories define `well`, `adequately`, `under`, `significantly under` and `critically under-capitalized` relative to regulatory capital levels.

Graded criterion-relative standing fits without a separate financial child.

### Legal / institutional

California/Delaware entity and professional-license sources expose current active/good-standing/suspended/revoked/etc. statuses and separate those from certificates or verification outputs.

Authority/constitutive-rule dependence is preserved without forcing a separate standing child.

### Ecology / environmental assessment

EPA assessment uses good/fair/poor condition categories relative to indicator/assessment criteria and aggregates component indicators at larger scales.

This fits as graded/aggregate criterion-relative standing; aggregation is a scope/rule issue rather than a separate universal child.

### Scientific / claim validity counterframe

ISO/IEC 17029 treats validation and verification as conformity-assessment processes over declared claims/information. This is a deliberate counterexample to blindly placing every `valid/verified` label in Domain Condition.

When `validity` names a claim-assessment or information result, route to Information/assessment semantics. When a real-world object occupies a criterion-relative accepted/valid standing, the protected question can remain here.

### Hybrid cyber-physical / safety-readiness

NASA current human-system guidance separately exposes state/readiness, projected state/mode, health and configuration to human operators. Safety thresholds and failure/inability-to-function cases reinforce that operational standing is criterion-sensitive while current state/mode and history remain distinguishable.

## Parent-reopen test

The strongest reopen rivals were:
1. merge standing into Realized Characteristics;
2. move all standing to Information/assessment;
3. split institutional/legal standing into a separate child;
4. treat standing only as a later relation/composition layer.

None survived:
- criteria can be wrong/inapplicable while characteristics are right, so sibling separation matters;
- true standing can differ from an assessment/report decision;
- institutional authority changes truth/binding mechanisms but not the generic standing recovery question;
- criterion relativity is relational but still a materially distinct recovery region from Structure or bare characteristics.

**F21: rejected.**
