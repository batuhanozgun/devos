## Boundary tests

### Structure

Keep separate where the protected question differs:

```text
which constituents exist/participate        → Constituent Composition
how constituents are structurally related   → Relational Organization
current value borne by a constituent/relation/whole → candidate here
```

Examples to test:
- link exists vs link latency;
- component participates vs component temperature;
- count of constituent instances vs concentration/fraction/abundance;
- spatial relation exists vs current numeric distance/separation value.

### Criterion-Relative Standing

Preserve the parent split unless falsified:

```text
actual current characteristic/value
+ materially applicable criterion
→ possible criterion-relative standing
```

The current pass researches the first term, not the full standing relation.

### Dynamics

Test current mode, rate, derivative, dwell time, path-dependent variable and accumulated quantities without equating snapshot values with their histories/processes.

### Information / representation

Strictly separate:
- actual characteristic;
- measurand / observable property;
- observation event;
- measured/estimated/modelled value;
- uncertainty/confidence/provenance;
- report/status field.

Representation can be evidence about reality without being reality by identity.

### Work Conditions / Actors

The same realized characteristic can carry a Work-Condition role for one focal Work. Role switching does not change the underlying fact's identity. Actor capability/authority semantics remain outside this child.
