# 1. Why the historical Environment closure is no longer enough

The original Environment parent pass reached a bounded result and its same-model audit found:

```text
Environment / Operating Reality
    ├─ Domain / Effect Reality
    └─ Work Conditions / Enabling–Constraining Environment
```

That judgment remains useful historical evidence about the parent level.

However, later dedicated research materially refined the tree:
- `Domain / Effect Reality` → `Domain Reality`;
- Domain Reality → `Domain State` + `Domain Dynamics`;
- Domain State → `Domain Structure` + `Domain Condition`;
- Domain Structure → two promoted children;
- Domain Condition → two promoted children.

The historical audit could not evaluate research debt created by children that did not yet exist in the canonical tree.

Therefore:

> historical parent closure ≠ current ground completion after deeper child discovery.

# 2. Parent coherence survives

The deeper tree does not currently force a third Environment first-order branch.

Retain:

```text
Environment / Operating Reality
    ├─ Domain Reality
    └─ Work Conditions
```

Reasons:
- deeper State/Structure/Condition results refine Domain Reality rather than producing another Environment role;
- Work Conditions remains the execution-condition role;

These sources are counterframes, not validation of the exact hierarchy.

# 3. Why four descendants remain material debt

The Ground Deepening plan's `G3 — Selective deepening` says a branch deserves a new pass when, among other triggers, it exposes a distinct failure mode.

The project's one-level method also states that probing a child enough to justify promotion does not silently count as researching that child.

All four current descendants meet this threshold.

## A. Constituent Composition / Membership

Distinct failure:
- known relations can be coherent while the actual constituent/member set is wrong.

Dedicated-pass questions remain around:
- parthood versus participation;
- nested membership/aggregation;
- substitution/absence;
- identity and selected scope;
- whether the node splits further or closes as a leaf.

## B. Relational Organization / Topology

Distinct failure:
- correct constituents can exist while structural organization/connections/arrangement are wrong.

Dedicated-pass questions remain around:
- network/dependency versus spatial/containment forms;
- interfaces/couplings;
- structural relation versus realized interaction/Dynamics;
- institutional relations versus Actor semantics;
- internal split versus leaf.

## C. Realized Characteristics / Values

Distinct failure:
- current non-structural characteristics can be wrong independently of criterion-relative standing.

Dedicated-pass questions remain around:
- intrinsic versus relational values;
- quantitative/qualitative/categorical forms;
- modes versus Dynamics;
- whole/constituent aggregation;
- structural boundary;
- split versus leaf.

## D. Criterion-Relative Standing / Status

Distinct failure:
- current characteristics can be correct while the wrong/inapplicable criterion yields the wrong standing.

Dedicated-pass questions remain around:
- reality-side standing versus assessment/report;
- criterion applicability;
- functional versus normative/regulatory standing;
- rule/threshold representation versus realized satisfaction/violation;
- authority/issuer semantics;
- split versus leaf.

This last branch is especially transition-critical because the next planned top-level ground is Information.

# 4. Why this does not force infinite descent

The project does not require researching every possible taxonomy forever.

For each promoted child:
1. run its dedicated coherence/split/boundary/holdout pass;
2. if no stable immediate child survives, close it as a bounded leaf;
3. if another material child survives, evaluate that child later under the same selective rule.

Environment is blocked now because four already-promoted nodes have never received step 1.
