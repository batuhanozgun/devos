# Environment Completion Review Finding 02 — Four Descendant Passes Remain Material

**Status:** bounded review finding  
**Date:** 2026-09-04

## Question

Do the four discovered Structure/Condition children need their own substantive passes before Environment can close for the current Ground Deepening purpose?

Children under review:

1. `Constituent Composition / Membership`
2. `Relational Organization / Topology`
3. `Realized Characteristics / Values`
4. `Criterion-Relative Standing / Status`

## Governing method

`03_ground-deepening/PLAN.md` defines `G3 — Selective deepening` and says a branch deserves a new pass when at least one of several conditions holds, including:
- it exposes a distinct failure mode;
- current evidence only names it but does not explain it;
- competing frames produce materially different implications;
- it is needed to distinguish the ground from another ground.

`HIERARCHICAL-DEEPENING-METHOD.md` separately protects one-level research: a child may be probed enough to validate that the split is real, but that does not count as silently researching the child itself.

## Result

**All four descendants remain material research debts. Environment is therefore NOT COMPLETE for the current Ground Deepening purpose.**

This is not a symmetry rule. Each child independently satisfies the selective-deepening threshold.

## 1. Constituent Composition / Membership

### Why it passes G3

The Structure pass explicitly promoted it because wrong constituent membership can occur while known relations remain coherent.

Protected recovery question:

> What actually belongs/participates in the selected realized whole/network?

Distinct unresolved child-local issues remain material:
- classical parthood versus network/group participation;
- nesting/aggregation versus selected-scope membership;
- absence/substitution;
- identity criteria at the snapshot;
- boundary/reference changes;
- whether a deeper stable split survives or this node closes as a leaf.

The parent pass established the child and its boundary; it did not run a dedicated coherence/split/holdout/closure pass on this child.

**Judgment:** dedicated pass warranted.

## 4. Criterion-Relative Standing / Status

### Why it passes G3

The Condition pass promoted it because current standing requires both realized condition evidence and criterion applicability/semantics, producing independent failure/recovery from bare characteristics.

Protected question:

> Relative to the materially relevant criterion, what standing actually obtains?

Distinct unresolved child-local issues are especially boundary-critical before Information research:
- what makes a standing reality-side rather than merely an assessment/report;
- functional versus normative/regulatory/institutional criteria;
- criterion applicability and scope;
- compliance/validity/readiness/health semantics;
- rule/threshold representation versus realized satisfaction/violation;
- Actor authority/issuer/enforcement versus Domain standing;
- whether a stable internal split survives or this node is a leaf.

Because the next top-level ground is Information, leaving this boundary only at parent-probe depth risks carrying an unresolved reality-versus-representation distinction into the transition.

**Judgment:** dedicated pass warranted.

## Why parent-pass detail is not enough

The current child findings are not empty labels. They contain definitions, examples, boundary probes and cross-lineage discrimination.

However, that detail was produced under the parent node's one-level objective. The project method explicitly distinguishes:

```text
probe child enough to validate promotion
≠
substantive child pass
```

Retroactively declaring the children researched because their parent finding is detailed would defeat the reason the one-level rule exists.

## Symmetry check

The conclusion does not follow from wanting four aesthetically balanced branches.

Each child independently has:
- a distinct first-order question;
- a demonstrated independent failure/recovery surface;
- material boundary questions;
- unresolved leaf/split rivals;
- explicit canonical status `discovered; inactive; not researched`.

If one child lacked these properties, the review would permit a subset outcome. Current evidence does not support that exception.
