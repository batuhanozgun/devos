## Frozen falsifier disposition

### F1 — Work Conditions reduces to Domain Reality facts + Work relation
**Disposition: PARTLY TRUE, DOES NOT ELIMINATE NODE.**

A later representation may be relational: actual facts need not be duplicated into a second reality class.

But research reduction fails because the Work-relative question protects distinct feasibility/support/hazard/access/capacity failure surfaces that generic Domain Reality research does not force.

### F2 — stronger node label required
**Disposition: PARTLY WON AS LABEL SIMPLIFICATION.**

Drop the paired canonical phrase `Enabling–Constraining Environment` from the preferred node label.

Retain:
- **Work Conditions**.

The long phrase can remain explanatory language.

### F3 — Enablers versus Constraints are stable children
**Disposition: REJECT.**

Same variable can enable or constrain as state/reference changes. JD-R is a strong outcome-specific rival but does not establish exclusive universal project children.

### F4 — Resources/Capacity is a stable child
**Disposition: REJECT AS CHILD; RETAIN DIMENSION.**

Resources/capacity recur strongly, but resourcehood is role-relative and resource condition interacts with access, sufficiency, hazards and dependencies.

### F5 — Access/Interfaces is a stable child
**Disposition: REJECT AS CHILD; RETAIN DIMENSION/RELATION.**

Access and interface cut across technical, physical, logistical and institutional support. Actor authority and Information representations must remain separate.

### F6 — Hazards/Interference/Degradation is a stable child
**Disposition: REJECT AS CHILD; RETAIN CONDITION ROLE/PROPERTY.**

Hazards originate in multiple condition families and can be created by tools, physical setting, organization, materials or resource interactions.

### F7 — physical/technical/social/institutional/logistical type taxonomy is strongest
**Disposition: REJECT AS UNIVERSAL HIERARCHY.**

External frameworks disagree materially on category sets. Hybrid holdouts cross the types. Treat as specialization profiles/tags/lenses when useful.

### F8 — Technical Work Environment is a necessary immediate child
**Disposition: REJECT AS UNIVERSAL CHILD; RETAIN SPECIALIZATION.**

TWE is deeply researched and valuable, but Work Conditions also exists in cases with no meaningful technical environment. No symmetry-based set of type children is justified.

### F9 — availability/readiness/sufficiency/capacity require own child
**Disposition: REJECT AS CHILD; RETAIN ANTI-COLLAPSE CONDITION DIMENSIONS.**

TWE strongly supports their distinctness, but they describe current support condition relative to protected use rather than independent first-order domains.

### F10 — timing/windows/schedules form Work-Conditions-local child
**Disposition: REJECT AS CHILD; BOUNDARY SPLIT RETAINED.**

Work plan/deadline/schedule semantics remain Work-local. Realized external availability/access windows can be Work Conditions. Relation deferred to composition.

### F11 — Actor-provided support causes Actor leakage
**Disposition: BOUNDARY SURVIVES.**

Actual support availability/coverage can be Work Condition. Bearer identity, competence, authority, obligation and accountability remain Actor semantics.

### F12 — institutional/regulatory conditions cause Information/Actor leakage
**Disposition: BOUNDARY SURVIVES WITH QUALIFICATION.**

Rule/policy text and claims are Information; issuer/enforcer/authority semantics are Actors/control; realized applicability/access/prohibition that materially constrains execution can participate as Work Condition.

### F13 — Domain Reality ↔ Work Conditions role switching breaks node
**Disposition: REJECT.**

Roles are reference-relative and non-exclusive. Same concrete identity can participate under either/both roles for different focal Work without duplication.

### F14 — materially different domain exposes missing child
**Disposition: NOT OBSERVED IN TESTED HOLDOUTS.**

Software, maintenance, clinical, science, logistics, institutional/legal, emergency, automated/nonhuman and nontechnical work mapped without a new recurrent first-order branch.

This is bounded evidence, not proof of universal absence.

### F15 — no stable child survives; node is bounded leaf
**Disposition: SUPPORTED BOUNDEDLY.**

Late probes mainly refined boundaries and dimensions rather than creating a stable recursive split.
