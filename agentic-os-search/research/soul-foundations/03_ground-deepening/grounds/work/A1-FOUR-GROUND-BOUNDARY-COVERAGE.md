# Work Ground Audit — A1 Four-Ground Boundary / Coverage

**Status:** COMPLETE  
**Date:** 2026-09-05  
**Dependency:** `A0-EVIDENCE-RECOVERY.md`

## 1. Question

Does the prior Work corpus still describe a coherent Work-local problem region after the Environment, Information and Actors boundaries are made explicit, or does it survive only by stealing state/semantics from neighboring grounds?

## 2. Protected Work-local question recovered

The strongest non-ontological Work-local formulation remains:

> How do possible pursuits toward purposes/outcomes become selected or rejected, structured, admitted/committed, enacted, coordinated, monitored/evaluated, adapted, concluded or recovered over time under dependencies and constraints?

This protected question concerns **the pursuit / undertaking / activity organization and evolution**, not the actual world state, its representation or the bearer/authority relation.

The audit therefore tests whether the prior Work distinctions can be interpreted under this protected question without taking ownership of neighboring-ground facts.

---

# 3. Work ↔ Environment

## 3.1 Actual conditions vs Work condition/readiness

Accepted Environment already states:

- Work Conditions are realized circumstances relative to Work;
- Work Conditions are not Work internal lifecycle/state;
- resource exists ≠ accessible ≠ available ≠ sufficient;
- Work closure ≠ actual resulting condition.

The prior Work corpus states that readiness/blockage can be relational properties of dependencies rather than simple item-local status.

### Boundary result

No contradiction is required if the two questions remain distinct:

- **Environment:** what actual condition/capability/resource state obtains?
- **Work:** given relevant conditions/dependencies/policies, what Work is admissible/ready/blocked/active or what coordination is required?

`Ready` therefore should not be treated as one intrinsic Work boolean. It can be a **derived Work-relative standing** over Work structure plus Environment conditions and other relations.

This is a boundary clarification, not a missing Work family.

## 3.2 Resource and capacity

The prior Work corpus uses `capacity` in flow/admission reasoning. Environment owns actual realized resources/capabilities/availability/sufficiency.

Two meanings must be separated:

1. **actual resource/capability capacity** — Environment-side condition;
2. **Work-system load/admission/flow relation** — how candidate/committed Work competes for or is limited by available capacity.

The second is a Work-relevant relation; the first is not Work-owned.

### H8 result

**H8 weakened / resolved by boundary split.** No new Work-local first-order family is needed, but later composition must not encode physical/technical resource state as an intrinsic Work property.

## 3.3 Work effects vs actual Domain Dynamics

The prior Work corpus correctly notes that Work may create partial externally visible effects and that cancellation does not erase them.

Accepted Environment clarifies that actual domain change/dynamics remain Environment-side.

### Boundary result

Keep separate:

```text
Work execution / causal attempt
!= actual environment/domain transition
!= representation/evidence of that transition
!= attribution that Work caused it
```

Work must preserve that effects can matter for recovery; it does not own the resulting world state.

### H1 result

**H1 does not break Work.** The risk is real but handled by explicit cross-ground boundary discipline.

# 4. Work ↔ Information

## 4.1 Plan vs actual Work

The prior Work corpus already makes `planned/prescribed Work != actual situated Work` a central distinction.

The accepted Information ground makes the separation sharper:

- plan/specification is an informational state;
- retrieving/exposing a plan is Information Dynamics;
- following, revising, rejecting or deviating from a plan is Work activity/state relative to that representation.

### Boundary result

A plan can be correct/current as information while actual Work differs; actual Work can also be appropriate while a stale status representation says otherwise.

No new Work family is required.

## 4.2 Work status vs representation of Work status

The prior corpus legitimately preserves Work-state questions such as candidate, admitted, active, suspended, failed or completed.

But the audit adds a mandatory anti-collapse:

> **Actual Work standing/state != informational representation claiming that Work has that state.**

A ticket marked `done` is Information. Whether execution actually closed, outcome criteria were satisfied, verification passed or acceptance occurred depends on the corresponding Work/Environment/Actors relations and evidence.

This distinction was implicit in the prior Work/Records deferral; the accepted Information ground now makes it explicit.

## 4.3 Verification / validation / acceptance evidence

The prior Work corpus separates execution completion, verification, validation and acceptance.

Under the current grounds:

- performing a verification/validation activity can be Work;
- test result/report/evidence is Information;
- the actual target condition may be Environment;
- authority to accept/waive belongs to Actors/relations;
- the Work can have a derived standing such as `verification passed` only relative to those relations and exact evidence/target binding.

### H2 result

**H2 weakened / resolved with explicit state-vs-representation rule.** The prior Work corpus need not be reopened, but later synthesis must avoid implementing Work status by simply trusting informational labels.

# 5. Work ↔ Actors

## 5.1 Participation / performance

Work can have participants, performers, coordinators, reviewers and decision points, but the identity/role/capability/authority of those bearers belongs to Actors/relations.

The prior Work corpus already defers who may perform, commit, waive, accept, terminate or reprioritise.

No boundary theft found.

## 5.2 `Commitment` ambiguity

The strongest lexical risk is the word `commitment`.

In Work research it was used for the transition from candidate/option into deliberately admitted Work.

In Actors/governance it can also mean an Actor obligation/promise/authorization relation.

These are not identical.

### Boundary correction

Prefer the following distinction when load-bearing:

- **Work selection/admission/activation standing** — Work-side;
- **Actor commitment/obligation/authorization** — Actors/relation-side.

An Actor commitment may cause or support Work admission, but one does not logically imply the other.

## 5.3 Requiredness / acceptance ambiguity

Similarly:

- Work can be `required` relative to a rule, objective or condition;
- an Actor can be obligated to perform/ensure it;
- a result can be accepted relative to a gate;
- an Actor can hold authority to issue that acceptance.

The Work-side standing does not own the Actor relation.

### H3 result

**H3 does not break Work.** It exposes lexical/compositional boundaries that must remain explicit.

# 6. Purpose / outcome boundary

A0 H4 asks whether purpose/outcome forces a fifth top-level ground.

The prior Work research does not require Work to own the ontology of the sought outcome. It requires preserving a distinction between:

- what is sought;
- actions undertaken;
- methods/refinements used.

Under the current grounds, a sought outcome may be expressed through several anchors:

- a desired criterion relative to Environment/domain state;
- an informational specification/representation of desired state;
- an Actor preference/obligation/authority relation;
- a Work-level purpose relation explaining why the pursuit exists.

The fact that a Work unit is **directed toward** an outcome is Work-relevant even if the outcome's actual state and representation live elsewhere.

### H4 result

**H4 currently rejected as a Work-boundary falsifier.** No fifth `Goal/Outcome` ground is forced by the current evidence. Purpose/outcome behaves more like a load-bearing cross-ground anchor/relation than an owned Work object family.

Reopen if later composition cannot preserve outcome direction without systematically mislocating the target state or authority.

# 7. Externally visible effects / acceptance / continuing responsibility

These prior deferred questions remain composites rather than local defects:

### Externally visible effects

- action/pursuit: Work;
- actual changed state/dynamics: Environment;
- observation/evidence: Information;
- causal/responsibility attribution: Actors/relations.

### Acceptance

- verification/validation work: Work;
- evidence/result representation: Information;
- authority/judgment: Actors;
- target/result actual condition: Environment where applicable;
- accepted Work standing: relation across these facts.

### Continuing responsibility

- recurring/standing activity: Work;
- obligation bearer/authority: Actors;
- trigger/current condition: Environment/Information depending what is observed;
- policy/record of obligation: Information/Records.

None forces a missing Work-local family.

---

# 8. Boundary anti-collapse set after A1

```text
Work pursuit/state
!= representation of Work pursuit/state
!= actual target/environment condition
!= Actor capability/authority/obligation

Work completion
!= resulting world state achieved
!= evidence says achieved
!= verifier judgment is valid
!= authorized acceptance occurred

Work admission
!= Actor obligation
!= resource availability
!= execution started
```

## 9. A1 verdict

The prior Work corpus survives the four-ground boundary test.

A1 found **important boundary clarifications**, especially around:

- actual Work state vs informational Work representation;
- Work readiness vs realized Work Conditions;
- Work-system capacity/load vs actual Environment resource capacity;
- Work admission vs Actor commitment/authority;
- Work-directed outcome vs ownership of the target outcome state.

But no tested boundary forces a new Work-local first-order family or makes `Work` residual/incoherent.

### Hypothesis status after A1

- H1 Environment theft → **weakened; boundary preserved**;
- H2 Information theft → **weakened; explicit anti-collapse required**;
- H3 Actors theft → **weakened; lexical/composite boundary required**;
- H4 separate Goal/Outcome ground → **not forced**;
- H8 resource/capacity mislocation → **resolved by two-level distinction**;
- H5/H6/H7/H9 remain live for A2/A3.
