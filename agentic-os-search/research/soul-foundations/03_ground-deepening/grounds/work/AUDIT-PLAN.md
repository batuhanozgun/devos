# Work Ground Coverage / Gap Audit — Plan

**Status:** active audit plan  
**Date:** 2026-09-05

## Objective

Test whether the already-completed Work vertical is sufficient as the current Foundation `Work` ground after Environment and Information have been deepened, without reopening broad Work research unless a material first-order gap survives.

## Decision rule

The audit is not successful merely because the old Work corpus is extensive. It must survive the new ground boundaries and newer holdouts.

A gap warrants targeted substantive Work deepening only if it is:

- genuinely Work-local rather than Environment / Information / Actors / later-composition;
- first-order or decision-critical at current Foundation depth;
- not already recoverable through the current Work distinctions;
- not merely a domain-specific workflow/mechanism taxonomy;
- stable under materially different examples or frames.

## A0 — Canonical / current evidence recovery

Recover:

- current Work vertical STATE, KEY, FINDINGS-MAP, synthesis, completeness audit, OPEN-QUESTIONS, DEFERRED-RELATIONS and exact revision binding;
- accepted Environment and Information boundaries;
- Actors vertical only where boundary discrimination requires it;
- new candidate studies selected through the catalog.

Output: evidence inventory and explicit audit hypotheses.

## A1 — Four-ground boundary and coverage audit

Test Work against:

### Environment

Can Work target, depend on or modify operating reality without absorbing the actual realized domain/runtime state into Work?

### Information

Can Work consume/produce plans, status, evidence, context and records without treating those representations as actual Work state/execution/outcome?

### Actors

Can Work preserve participation/assignment/decision points without treating role, capability, authority, obligation or accountability as Work-local intrinsic fields?

### Cross-ground deferrals

Revisit purpose/outcome, commitment/obligation, resources/capacity, externally visible effects, acceptance and continuing responsibility. Determine whether they expose Work-boundary defects or merely deferred relations/composites.

## A2 — First-order omission / gap test

Re-attack the current first-order Work distinctions:

1. purpose/outcome vs action/task vs method;
2. plural units/levels;
3. candidate/eligible/committed/executing distinctions;
4. plan/prescription vs situated execution/adaptation;
5. control regime plurality;
6. dependencies/coordination/concurrency;
7. item-local state vs system flow/capacity;
8. multidimensional Work state;
9. effort/duration/waiting/elapsed/recurrence;
10. completion vs verification/validation/acceptance;
11. termination/failure/recovery/compensation/retry;
12. bounded vs continuing/supporting Work.

Target omission hypotheses:

- decision/sensemaking/investigation as a potentially distinct Work family;
- learning/discovery-driven Work where the work definition itself changes;
- obligation/commitment as more than admission state;
- resource/capacity semantics beyond relational constraint;
- outcome/effect realization in the world;
- multi-agent coordination/integration work;
- policy/gate/verification-generated Work;
- interrupted/resumed/migrated Work across sessions/actors/systems;
- work about changing the working system itself (meta-work/evolution).

## A3 — New candidate-study holdouts

Use later studies to challenge—not define—the Work frame.

### Anthropic AI-Native SDLC

Probe:

- artifact-chain versus actual Work;
- plan-before-mutation;
- stage labels versus dependency graph;
- parallel sessions/subagents;
- producer feedback versus verification;
- production gates and recurring maintenance/incident-generated work;
- configuration evolution as Work.

### Multi-agent patterns

Probe:

- decomposition, routing and coordination work;
- merge/integration work;
- generator/reviewer/verifier separation;
- hierarchy and delegation as Work vs Actors relations;
- human orchestration as hidden Work.

### Context / Memory / Harness

Use only where it tests:

- continuity/handoff work;
- context assembly as Information versus Work action;
- orchestration/retry/verification loops;
- runtime/harness state versus Work.

## A4 — Selective external / cross-domain holdouts

Only if A1–A3 leave a live gap hypothesis, use primary/authoritative or strong academic sources from materially different traditions. Candidate families:

- project/portfolio/operations management;
- process/case/workflow;
- coordination/CSCW;
- queueing/flow;
- systems engineering verification/validation;
- incident/maintenance/recovery;
- learning/discovery/adaptive work;
- organizational decision/sensemaking where needed.

Do not perform literature expansion merely to accumulate examples.

## A5 — Adversarial rival / reduction audit

Attempt to show that:

- `Work` is still too residual or broad;
- purpose/outcome requires a separate ground;
- decision/sensemaking is not adequately represented as Work;
- resource/capacity belongs inside Environment strongly enough to break current Work claims;
- acceptance/commitment are primarily Actors relations rather than Work distinctions;
- the twelve preserved families are an accidental grab-bag rather than a coherent ground;
- one simpler framing preserves all decision-critical distinctions;
- a new first-order family survives across materially different domains.

This is same-model review unless an independent path is separately available.

## A6 — Closure

Possible outcomes:

### Outcome 1 — Existing Work corpus sufficient

Accept the prior Work vertical into ground-deepening with explicit boundary corrections/bridges and no new child hierarchy forced.

### Outcome 2 — Targeted gap

Open only the minimum new Work-local deepening needed for the surviving gap, then re-audit.

### Outcome 3 — Boundary falsifier

If Work itself or the four-ground decomposition is materially broken, return to the relevant parent/adequacy gate rather than patching locally.

## Stop condition

Return for user evaluation once the audit can state with bounded confidence whether Work is sufficient at current Foundation depth and whether any targeted deepening is required.

Do not proceed automatically to Actors.
