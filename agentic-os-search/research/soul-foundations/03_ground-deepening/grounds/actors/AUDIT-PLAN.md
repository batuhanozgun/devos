# Actors Ground Coverage / Gap Audit — Plan

**Status:** active audit plan  
**Date:** 2026-09-05

## Objective

Test whether the already-completed Actors vertical is sufficient as the current Foundation `Actors / Agency–Participation–Authority` ground after Environment, Information and Work have been deepened, without reopening broad Actors research unless a material first-order gap survives.

## Decision rule

A gap warrants targeted substantive Actors deepening only if it is:

- genuinely Actors-local rather than Environment / Information / Work / later-composition;
- first-order or decision-critical at current Foundation depth;
- not already recoverable through the current multi-anchor Actors distinctions;
- not merely a domain-specific legal/security/organizational taxonomy;
- stable under materially different human, organizational and non-human cases.

## A0 — Canonical / current evidence recovery

Recover:

- current Actors vertical STATE, KEY, FINDINGS-MAP, synthesis, completeness audit, OPEN-QUESTIONS, DEFERRED-RELATIONS and exact current-surface binding;
- accepted Environment, Information and Work boundaries;
- selected candidate studies through the catalog.

Output: evidence inventory and explicit audit hypotheses.

## A1 — Four-ground boundary and coverage audit

### Actors ↔ Information

Test:
- bearer/role/authority/obligation standing vs representations asserting them;
- identity/role records vs actual current standing;
- delegated authority documents/tokens vs actual scope/currentness;
- evidence of action/decision vs actual participation/attribution.

### Actors ↔ Environment

Test:
- intrinsic/standing capability vs realized actionability;
- permission/authority vs actual tool/resource/interface availability;
- role/authority vs runtime enforcement and technical constraints;
- non-human participant vs the technical substrate enabling action.

### Actors ↔ Work

Test:
- performer/participant vs Work assignment/admission;
- Work requiredness vs Actor obligation;
- Work acceptance standing vs authority to accept;
- reassignment/delegation vs Work identity;
- continuing Work vs continuing responsibility/accountability.

## A2 — First-order omission / gap test

Re-attack current Actors distinctions:

1. bearer identity / continuity;
2. role / office / position / membership;
3. situation / episode / context / time;
4. participation and decision roles;
5. capability / competence;
6. permission / authority / power / obligation;
7. representation / delegation / impersonation / on-behalf-of;
8. action / decision / omission / refraining;
9. causal / provenance / institutional attribution;
10. responsibility / accountability;
11. shared / joint / collective / corporate agency;
12. operational non-human participation vs legal/moral/personhood attribution.

Target omission hypotheses:

- transitive/effective authority across agent-to-agent paths;
- policy-enforced technical agency versus institutionally authorized agency;
- affected/beneficiary/rights-holder positions as potentially first-order;
- epistemic authority/trust/expertise as more than competence or authorization;
- continuing/stewardship responsibility independent of episodes;
- collective identity/agency under dynamically changing membership;
- multi-agent delegation chains where capability and authority diverge at each hop;
- human-in-the-loop gates where operational performer and accountable authority separate;
- autonomous/non-human systems whose operational discretion is materially greater than simple tool participation.

## A3 — New candidate-study holdouts

### Anthropic AI-Native SDLC

Probe:
- scoped identities;
- producer/reviewer/owner/release-manager distinctions;
- subagents and agent-to-agent authority paths;
- transitive authority failure;
- human review gate;
- environment-tiered autonomy;
- advisory instruction vs hard permission boundary.

### Multi-Agent Patterns

Probe:
- hierarchy/delegation;
- generator/reviewer/verifier/integrator role separation;
- hidden human orchestration;
- collective/team labels vs actual authority/responsibility topology;
- parallel/hierarchical systems where actor identity does not imply institutional authority.

### Context / Memory / Harness

Use only where it tests:
- context-bound role/authority information;
- runtime permissions and tool availability;
- orchestration identity;
- persistence of authority/identity state across sessions.

## A4 — Selective external / cross-domain holdouts

Only if A1–A3 leave a live Actors-local first-order gap, use primary/authoritative or strong academic sources from materially different traditions, e.g.:

- access control / authorization / delegated authorization;
- agency law / institutional authority;
- organizational roles/accountability;
- shared/collective agency;
- safety/human-machine responsibility;
- autonomous-agent governance;
- fiduciary/stewardship/beneficiary structures.

Do not expand literature merely to accumulate terms.

## A5 — Adversarial rival / reduction audit

Attempt to show that:

- `Actors` is still too residual or broad;
- bearer/role/authority/participation can be reduced to Work relations;
- capability belongs entirely to Environment;
- authority/obligation belong entirely to later control/composition rather than Actors;
- attribution/accountability are only Information/records problems;
- affected/beneficiary/rights-holder positions force a broader `Stakeholders/Parties` ground;
- non-human agency requires a separate first-order region;
- one simpler frame (e.g. bearer + typed relations, episode + participants, principal-agent network) preserves all decision-critical distinctions;
- a stable immediate-child hierarchy can be promoted without false disjointness.

## A6 — Closure

Possible outcomes:

### Outcome 1 — Existing Actors corpus sufficient

Accept the prior Actors vertical into ground-deepening with explicit boundary corrections/bridges and no forced child hierarchy.

### Outcome 2 — Targeted gap

Open only the minimum Actors-local deepening needed for the surviving gap, then re-audit.

### Outcome 3 — Boundary falsifier

If Actors itself or the four-ground frame is materially broken, return to top-level adequacy rather than patching locally.

## Stop condition

Return for user evaluation once the audit can state with bounded confidence whether Actors is sufficient at current Foundation depth and whether targeted deepening is required.

Do not automatically run top-level adequacy or begin composition afterward.
