# Actors Ground — Coverage / Gap Audit Synthesis

**Status:** bounded audit synthesis / awaiting user evaluation  
**Date:** 2026-09-05  
**Scope:** Actors as one of the accepted four Foundation grounds after Environment, Information and Work deepening

## 1. Executive conclusion

The independent Actors vertical remains sufficient for the current Foundation purpose after being re-tested against:

- the accepted Environment / Operating Reality boundary;
- the accepted Information / Representation boundary;
- the accepted Work boundary;
- newer agentic-system candidate studies;
- new omission/reduction/rival tests.

The audit did **not** find a material Actors-local first-order gap requiring new substantive Actors research.

The strongest current Foundation-level formulation is:

> **Actors / Agency–Participation–Authority concerns which persistent bearers/positions/parties are implicated in a situation, in what capacity and standing, through which agency/participation/representation relations, and how authority/obligation, action/non-action, attribution/responsibility and collective/non-human agency are distributed across them over context and time.**

This is a research-ground formulation, not an ontology primitive or architecture module.

## 2. What the audit changed

The main effect is not a new Actors taxonomy. It is a sharper boundary and a few important orientation corrections.

### 2.1 Actor standing vs informational representation

A role record, token, directory entry, delegation claim, log or accountability statement is Information.

Therefore:

```text
representation says Actor standing is X
!= actual Actor standing is X
```

### 2.2 Actor capability vs Environment actionability

The same competence/capability can exist while tool/network/resource access changes.

Therefore:

```text
Actor capability/competence
!= Environment affordance/access
!= situated actionability
```

### 2.3 Authority vs effective technical reach

A system may mechanically allow an effect path that the bearer is not institutionally authorized to use.

Therefore:

```text
Actor authority
!= technical effect power
!= runtime enforcement outcome
```

### 2.4 Actors vs Work

Participation, assignment, obligation and acceptance authority must not be inferred from Work standing.

```text
Actor participation/assignment != Work identity/admission/execution
Work requiredness != Actor obligation
Work acceptance state != authority to accept
```

### 2.5 `Actors` does not mean only active doers

Beneficiaries, affected parties, rights holders, principals, recipients and accountability forums can be relevant positions even when they perform no positive action.

This is an orientation correction, not a new ground.

## 3. Why Actors remains a distinct ground

A serious reduction was tested: perhaps Actors is only a combination of Environment + Information + Work.

That fails because Actor-side relations can vary while neighboring facts remain fixed.

With the same Work, same Environment and same informational artifact:

- authority can be revoked;
- obligation can change;
- a different bearer can occupy a role;
- delegation/principal relations can change;
- accountability can attach to a different forum/office;
- the same action can have different institutional attribution.

The irreducible protected question concerns **who/what bears identity/standing and how agency, participation, authority, representation and attribution are distributed**, not the world state, representation or Work pursuit alone.

## 4. Existing Actors distinctions remain sufficient

The prior multi-anchor map continues to cover the tested cases:

1. persistent bearer / identity continuity;
2. role / office / position / membership;
3. situation / episode / context / time;
4. participation and decision positions;
5. capability / competence;
6. permission / authority / power / obligation;
7. representation / delegation / impersonation / on-behalf-of;
8. action / decision / refraining / omission;
9. causal / provenance / legal / institutional attribution;
10. responsibility / accountability;
11. shared / joint / collective / corporate agency;
12. operational non-human participation vs legal/moral/personhood attribution.

No audit case required a thirteenth first-order family.

## 5. Effective / transitive authority

The most important new agentic pressure is the difference between **direct authority** and **reachable effect power**.

Example:

```text
Agent A
→ invokes Agent B
→ B has privileged capability
→ effect occurs
```

This does not establish that A had legitimate authority.

The case composes:

- Actor authority/delegation relations;
- Environment capability/access graph;
- Work/orchestration path;
- policy/enforcement;
- Information evidence/telemetry;
- attribution/accountability.

Therefore effective power is a later relation/control problem, not a new Actors child.

## 6. Epistemic authority / trust / expertise

`Who should we believe?` decomposes into different concerns:

- expertise/competence and mandate/certification role — Actors;
- source/provenance/reliability/evidence standing — Information;
- review/certification Work — Work;
- access to the relevant actual target — Environment where applicable.

No separate epistemic-Actor family is forced.

## 7. Standing / stewardship responsibility

Standing responsibility can persist without current Work.

It is expressible through:

- persistent bearer;
- role/office;
- obligation/duty;
- scope/context/time;
- accountability/forum;
- triggered Work when action becomes due.

Important anti-collapse:

```text
standing Actor responsibility
!= current Work episode
```

## 8. Non-human and multi-agent systems

Modern AI agents can exhibit substantial operational discretion: tool choice, planning, subagent delegation, recovery and routing.

This strengthens—not invalidates—the existing separation:

```text
operational agency/discretion
!= authority/obligation
!= legal/institutional attribution
!= accountability
!= moral/personhood status
```

Multi-agent hierarchy likewise does not imply:

```text
hierarchy position = authority = competence = responsibility = accountability
```

Nor does a coordinated runtime team automatically become a persistent corporate/group agent.

## 9. Immediate-child judgment

Several candidate decompositions were tested:

- Standing / Participation;
- Bearer & Identity / Authority & Representation / Participation & Agency / Attribution & Responsibility;
- Individual / Collective / Non-human;
- Operational Agency / Normative Standing;
- Identity/Standing State / Agency/Participation Dynamics.

All are useful projections but fail as stable sibling hierarchies because role, delegation, omission, responsibility, collective agency, context/time and non-human participation cut across them.

Current structural judgment:

```text
Actors / Agency–Participation–Authority
    ← coherent Foundation ground
    ← boundedly sufficient at current depth
    ← deep relational / multi-anchor internal problem map
    ← NO stable universal immediate-child split promoted
```

This is a bounded-leaf judgment at the current Foundation depth, not a claim that Actors lacks deeper concepts.

## 10. Naming judgment

The current label remains usable:

> **Actors / Agency–Participation–Authority**

But `Actors` must not be interpreted literally as a universal class of active doers.

The region also includes semantically relevant non-performing parties/positions and typed standing/attribution relations.

Potential alternative labels such as `Agency / Participation / Standing` can be reconsidered during top-level adequacy, but no current falsifier requires renaming.

## 11. Why broad new external search was not opened

The audit plan made new external research conditional on a live first-order gap hypothesis.

A1–A3 eliminated those gaps; A5 did not revive one. The prior Actors corpus already spans materially different source traditions, and the newer candidate studies provide contemporary agentic stress cases.

Additional broad search at this point would have low expected structural information gain and high risk of accumulating legal/security/organizational vocabularies without changing the Foundation result.

A4 remains reopenable if a future falsifier creates a decision-critical question.

## 12. Current anti-collapse rules

```text
Actor identity != role != current participation
Actor capability/competence != authority/permission != obligation
Actor capability != Environment actionability
Actor standing != representation/evidence of standing
Actor authority != technical effect power
performer != decider != authorizer != principal != accountable party
own-behalf action != delegation != impersonation
positive action != full agency surface
causal/provenance attribution != responsibility != accountability
aggregation != shared action != corporate/group agency
operational non-human action != legal/moral/personhood attribution
Actor participation/assignment != Work state
Work requiredness != Actor obligation
```
