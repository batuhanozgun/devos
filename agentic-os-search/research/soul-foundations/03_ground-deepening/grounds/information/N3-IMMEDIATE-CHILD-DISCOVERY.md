## 1. Question

N3 asks whether the twelve N2 problem families compress into a small set of stable first-order research branches without:

- turning processes, states, roles and lifecycle conditions into fake peers;
- importing a disciplinary taxonomy;
- promoting recurrent cross-cutting dimensions merely because they have names;
- forcing `Records / Persistent Information` into a sibling position that overlaps all other representation semantics.

This pass compares rival decompositions. It does not yet close the node.

# 3. Rival decomposition A — familiar nouns

Candidate:

```text
Observation / Data
Belief / Model
Evidence
Context
Records
```

## Result: REJECT

This was already weakened by N1/N2 and fails N3 decisively.

It mixes unlike analytical kinds:

- observation may be an act/procedure;
- a measurement/observation result is an informational state;
- belief is a holder↔content relation or epistemic state;
- evidence is relative to a target claim/question;
- context is use-relative selection/exposure;
- Records is a persistence/lifecycle specialization.

It therefore creates category errors before any child research begins.

# 4. Rival decomposition B — five problem-region buckets

Candidate:

```text
1. Constitution / identity
2. Formation / transformation
3. Standing / plurality
4. Selection / exposure
5. Persistence / continuity
```

Approximate N2 coverage:

- constitution / identity → P1, P3, P4;
- formation / transformation → P2, P6;
- standing / plurality → P5, P7, P8, P10;
- selection / exposure → P9, P11;
- persistence / continuity → P12.

## Strengths

- preserves several obvious failure families;
- prevents observation process from being confused with result/content;
- gives persistence visible space;
- is operationally readable.

## Failure

The last three buckets are not stable peer branches.

### Standing / plurality is mostly relational/cross-cutting

Source, perspective, confidence, evidential role, temporal applicability and conflict can all vary for the **same informational state** and can also change through informational dynamics.

Treating them as a sibling branch forces the branch to own properties/relations that recur everywhere else.

### Selection / exposure is use-relative

Context, visibility, retrieval/exposure and accessibility are strongly relative to Work, Actor, query, purpose or system boundary. They describe **how informational states are selected/available/used**, not a clean independent population of informational phenomena.

### Persistence overlaps every other branch

Persistence can apply to:

- observations/results;
- assertions/models;
- provenance/lineage;
- contexts/views;
- conflicts/standing histories;
- source designations.

The existing Records corpus confirms that persistence activates additional obligations, but that does not make persistent information disjoint from constitution or dynamics.

**Verdict:** useful internal problem map, poor universal immediate-child hierarchy.

# 5. Rival decomposition C — state / constitution vs dynamics / formation–transformation

Candidate:

```text
Information / Representation
    ├─ Informational State / Representational Constitution
    └─ Informational Dynamics / Formation–Transformation
```

The labels are provisional. The structural distinction is the result under test.

## Child candidate C1 — Informational State / Representational Constitution

Protected first-order question:

> **What informational state/result/representation exists, what is it about, what content/form/identity does it carry, and what relations/standing make its interpretation materially different from another informational state?**

Primary N2 load:

- P1 referent / scope;
- P3 content / form / assertion semantics;
- P4 informational identity / equivalence.

State-side dimensions/relations include, when material:

- source/holder/perspective;
- epistemic/reliability standing;
- temporal applicability/freshness;
- conflict with other states;
- accessibility/visibility;
- uncertainty/confidence;
- persistence status.

These are not automatically children of C1; they are recurrent dimensions/relations over informational states.

### Distinct failure family

Examples:

- wrong referent while process was correctly executed;
- same bytes but different represented scope;
- correct provenance but ambiguous content;
- two equivalent encodings mistaken for two independent facts;
- assertion existence mistaken for truth;
- stale result still correctly preserved and retrievable.

These failures concern **what informational state there is and what it means/stands for**, not primarily how it was generated.

## Child candidate C2 — Informational Dynamics / Formation–Transformation

Protected first-order question:

> **How do informational states become available, get generated, selected, transformed, revised, communicated, invalidated or otherwise change?**

Primary N2 load:

- P2 acquisition / observation formation;
- P6 derivation / transformation / lineage;
- P9 selection / view / context formation.

Dynamic aspects of other N2 families include:

- source attribution changes;
- belief/standing revision;
- correction/retraction/supersession;
- conflict detection/merge;
- exposure/communication/retrieval;
- persistence write/update/forget/disposition transitions.

### Distinct failure family

Examples:

- correct target but biased/noisy acquisition;
- correct source states but invalid derivation;
- summary changes claim strength;
- context assembly omits decisive evidence;
- correction exists but is not propagated;
- retrieval exposes the wrong version despite correct stored states.

These failures concern **how informational state is produced or changed**, not merely its current content.

# 6. Is state/dynamics merely a generic cross-cutting dimension?

This is the strongest objection to Rival C.

`state` and `dynamics` recur in many domains, so visual symmetry with Environment is not evidence.

Rival C is retained only because the split passes the child-promotion test independently of symmetry:

1. **Distinct first-order questions** survive: constitution/meaning/identity vs formation/change/derivation.
2. **Distinct failure families** survive: a state can be semantically wrong despite a valid generation process, and a process can be faulty despite well-defined inputs/outputs.
3. **Independent traditions repeatedly make an analogous distinction**:
   - measurement process vs measurement result;
   - observation procedure/act vs result;
   - provenance entity vs activity/generation/derivation;
   - belief state vs belief-change operations.
4. **Collapsing the split repeatedly creates category errors** such as treating observation as an object subtype or derivation as merely an attribute of output.
5. **Later reasoning changes materially** because provenance, uncertainty, context and persistence must often bind to both a state and the process that produced/changed it.

Thus the split is not retained because `state/dynamics` is a universal vocabulary. It is retained because two recurrent **problem regions** survive independent attack.

# 7. Rival decomposition D — no immediate children; retain one rich leaf

Candidate:

> Treat the whole Information / Representation parent as a bounded leaf with the N2 problem map only.

## Strength

This avoids over-taxonomizing a highly relational problem space.

## Failure

It discards a repeatedly load-bearing distinction:

- informational result/state vs the process that generated/changed it.

Across measurement, provenance, observation and belief-change cases, collapsing these causes different semantics and failure modes to be represented as one thing.

A single leaf would therefore lose structural information that later Work/Actor/Environment composition is likely to need.

**Verdict:** too coarse at the current foundation purpose.

# 8. Persistence / Records structural judgment

## Question

Should `Records / Persistent Information` be an immediate third child beside State and Dynamics?

## Current judgment: NO — retain as a deep persistence specialization/profile, not a universal peer child

Reasons:

1. Persistence is triggered by a **horizon/lifecycle requirement**, not by a disjoint informational kind.
2. The same informational state can move from transient to persistent use without changing its referent/content class.
3. Persistent information still has both:
   - state/constitution problems;
   - formation/change/derivation/retrieval/disposition dynamics.
4. Making Records a peer would create overlap with both promoted candidates.
5. Existing Records research remains highly valuable because persistence introduces distinctive obligations:
   - identity/version binding;
   - preservation closure;
   - history/standing reconstruction;
   - retrieval contracts;
   - retention/disposition.

Therefore the stronger hierarchy-neutral interpretation is:

> **Records is a deeply researched persistence specialization activated across the broader Information / Representation problem space, not currently a clean immediate child partition.**

This is analogous to retaining a deep specialization/profile without pretending its specialization axis is the universal parent decomposition.

This judgment remains challengeable in N4–N6.
