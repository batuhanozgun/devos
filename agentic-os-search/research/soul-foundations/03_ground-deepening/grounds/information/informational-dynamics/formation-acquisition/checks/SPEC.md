# Constructive Check Specification

**Date:** 2026-09-12  
**Nature:** constructed finite examples, not an experiment on SOUL or a provider  
**Timing:** written before the script's first execution, after source reconnaissance

## Claim and oracle

Test whether explicit toy records and finite source worlds exhibit the distinctions asserted in the Formation argument. The oracle is supplied fixture truth or exact finite enumeration, not an LLM's self-report. Fixtures, implementation and interpretation share one author; this is not independent verification.

Twelve cases are specified:

1. Exact capture of a false assertion can be source-faithful while the asserted world claim is false.
2. Complete processing of emitted records can coexist with incomplete target coverage.
3. Record-only identification is possible exactly when the target is constant on each observation fibre in the finite fixture.
4. `missing`, `null`, `unknown` and numeric zero remain distinct acquisition outcomes.
5. Two deliveries from one origin differ from two origin episodes with identical payloads; neither origin count proves independence.
6. Result/receipt time can disagree with source-reference order in the stipulated common-clock fixture.
7. Syntactically valid capture can lose a source qualifier.
8. A probe can change the quantity it records relative to the pre-probe target.
9. Acquisition fidelity and later selection correctness realize all four combinations.
10. A generated forecast record can be acquired faithfully without observing its future referent.
11. Correctness under a stipulated calibration interpretation differs from correctness under an incorrect unit/model, despite the same raw indication.
12. A negative detection supports absence over the fully covered, perfect-detector finite fixture; the same record does not support absence when coverage or detector function is unknown.

Five named mutations must be detected by the same assertions: replace missing/null/unknown with zero; drop a negating qualifier; count deliveries as distinct origins; treat processing coverage as target coverage; use receipt order as source-reference order. Expected outcome is a rejected mutation, not a production defect count.

No real network, sensor, survey participant, signature verifier, log collector, LLM, database, process restart or deployment is exercised. All fixture boundaries are stipulated. Statistical representativeness, real detector sensitivity, empirical prevalence, semantic taxonomy uniqueness and live-system efficacy are outside the oracle.
