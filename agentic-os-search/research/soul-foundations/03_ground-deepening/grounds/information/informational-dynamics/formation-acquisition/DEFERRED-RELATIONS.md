# Formation / Acquisition — Cross-Node Relations and Deferred Work

**Date:** 2026-09-12  
**Role:** interfaces and unresolved conditions, not an ontology or execution queue

| Protected relation / question | Relevant existing region | Boundary or deferred work |
|---|---|---|
| Representation refers to a target under a time/scope | State + Binding + Environment where actual condition is focal | Captured source does not establish target truth. |
| Source act is attributed to a producer/role | Actors + Binding | Authentic source, legitimate authority and reliable content are different. |
| An acquisition pursuit chooses a target/procedure | Work + Control + Environment conditions | Completed collection Work does not prove the intended result. |
| Signals and model calculations jointly form a result | Formation + Derivation | Separate source contact from computational validity without imposing raw-first order; dedicated Derivation remains unresearched. |
| Already-existing material is selected or exposed | Selection/Exposure + Binding | Correct selection need not mean correct acquisition; dedicated Selection remains unresearched. |
| An attempt produces an error or absence record | Formation + State + causal/Standing inquiry | Meaning depends on detector/coverage/source contract; no universal remote-failure inference. |
| A received record is copied or materialized elsewhere | Propagation + State identity + Formation at receiver locus | Local novelty is not a new origin or independent corroboration. |
| Acquisition itself affects the source condition | Actual/Contrastive Causation + Environment + Work | Exact pre-probe/under-probe target and effect need evidence. |
| Acquisition evidence supports a qualification | Standing + causal inquiry where material | Fidelity, truth, sufficiency and acceptance remain distinct. |
| Source information reaches a response process | Returned Influence | Acquisition/delivery does not establish operative use or effect. |
| A record persists and changes future responses | Records specialization + Persistent Adaptation | Storage is not adaptation, and this pass does not test live learning. |

These routes retain semantic interfaces, not new typed-relation commitments. Case-specific coverage, fidelity, clock comparability, intervention effects and source independence require concrete evidence. No adjacent child, runtime design or implementation is activated by this ledger.
