# Exposure — KEY

**Updated:** 2026-09-16. **Status:** contextually accepted bounded leaf/E5.1–E5.5; original publication complete.

What specified information is available to which consumer, in which required mode, at which locus/time, under what actionable conditions, and with what evidence?

```text
resource description != requested content
known locator != executable access != content in a particular invocation
actual possession != legitimate authority
static union of contacts != time-respecting path
path in each possible world != one feasible observation-based policy
accepted request != established endpoint availability
one observed recipient/time != all applicable recipients/future times
updated source != updated retained view
denied future read != erased received copy
equal bytes != supported decoded representation
presentation != understanding != shared assurance != authorized action
```

These are claim distinctions, not compulsory pipeline stages. A locator or on-demand route can be exactly sufficient for its intended endpoint. A historical view can be correct; increased disclosure is not universally desirable.
