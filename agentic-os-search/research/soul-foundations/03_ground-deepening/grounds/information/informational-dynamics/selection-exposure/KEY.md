# Selection / Exposure — KEY

**Updated:** 2026-09-16. Parent/S5, U5 and E5 accepted at recorded scopes; new integration result separately proposed.

```text
Selection / Exposure [accepted parent]
├─ Use-Conditioned Selection / Set Adequacy [accepted leaf; U5.1–U5.6]
```

Selection asks which existing resources, parts or permitted contingent views serve the inquiry. Exposure asks which specified information is available for a consumer under the required endpoint/mode. These are not two services or a universal choose-then-send sequence.

```text
information need != query proxy
source universe != index != eligible candidates != exposed view
relevant items != sufficient set
best feasible score != feasibility of a sufficient permitted strategy
address / offsets != exact representation / fragment identity
individually newest != jointly coherent or appropriate as-of
chosen IDs != content in the required invocation
planned bundle != supplied bundle
availability != demonstrated interpretation, acceptance or action
```

U5 retains criterion fidelity, action/rationale/audit differences, quantifier-sensitive evidence, joint/contextual value, contingent reading versus changed need, and present selection versus future reuse. E5 retains exact target/consumer/mode, actionable temporal conditions, scoped observation, retained views and representation support distinct from actual use.

The new [integration SYNTHESIS](../../../../../07_selection-dynamics-integration-review/SYNTHESIS.md) proposes I1–I5: compatible common witness, actual consumer/history, qualified substitutes and established side information, temporal/authority scope and exact completion status. Those refinements await their own evaluation; this derived key does not accept them.

The parent rich-leaf, U specification/construction and E opportunity/presentation rivals remain reopenable. Source depth, same-author tests and repetitions do not establish unique taxonomy or live actor efficacy. Original suites retain separate evidence scope. STATE → INDEX gives current authority and exact evidence. The original publications are complete; no automatic later node, architecture or agent-control work follows.
