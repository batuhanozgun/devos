# Informational State / Representational Constitution — Deferred Relations

**Status:** bounded deferral surface  
**Date:** 2026-09-05

This file records cross-node/cross-ground relations encountered during Informational State research that are important but intentionally not solved by this node.

## 1. State ↔ Dynamics

Deferred relation questions:

- which formation/derivation/revision events should be explicit lineage of a State;
- which transformation changes State identity versus only its realization;
- how correction/retraction/supersession changes standing while preserving history;
- how context/view formation creates new selected/projected States.

Owner for deeper research: later `Informational Dynamics / Formation–Transformation` pass plus later composition where needed.

## 2. State ↔ Environment

Deferred:

- typed binding between represented state and actual realised condition;
- truth/error relation;
- forecast/model vs realised-state reconciliation;
- uncertainty about Environment state;
- stale representation detection relative to current Environment.

Informational State preserves reference/applicability semantics but does not own actual reality.

## 3. State ↔ Work

Deferred:

- how goals, plans, commitments, statuses, evidence and acceptance assertions bind to actual Work transitions;
- what representation changes are merely descriptive versus legally/operationally constitutive under a control regime;
- when verification evidence is sufficient for Work acceptance.

State research does not grant representational updates causal force over Work by default.

## 4. State ↔ Actors

Deferred:

- source/holder/asserter/observer/authorizer role relations;
- Actor-local vs shared/system-level informational state;
- delegation/quotation/representation of another Actor;
- authority-for-role versus source provenance;
- accountability for incorrect/misleading States.

Actor identity/capability/authority remain Actors territory.

## 5. State ↔ Records / persistence

Deferred:

- which States must persist and why;
- persistence horizon and protected future use;
- exact State identity/version/representation binding across time;
- historical standing reconstruction;
- retention/disposition of superseded or false States;
- when context/views/derived States acquire their own recordhood obligations.

The completed Records vertical remains the deep persistence evidence package.

## 6. State ↔ evidence / truth / authority / decision

Later relation/control research may need explicit typed distinctions among:

```text
state represents claim
state is true/false/unknown relative to referent
state supports/challenges target claim
source is authoritative for a role
state is sufficient evidence under a criterion
Actor is authorised to decide
Work decision/commitment occurs
```

These relations intentionally remain separated rather than collapsed into one `standing` field.

## 7. State ↔ context / visibility

Deferred:

- eligible source universe;
- selection/ranking/compression/context-formation policy;
- model/Actor-visible State set;
- context coverage/fidelity/currentness;
- access/permission dependencies.

Current bounded result: context is a selected/projected informational State produced by Dynamics relative to use; source existence, persistence and model visibility remain distinct.

## 8. Authorization

Recording these relations does not authorize systematic composition or another node pass.
