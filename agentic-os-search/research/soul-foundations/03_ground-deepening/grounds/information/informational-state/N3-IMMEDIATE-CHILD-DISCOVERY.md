## 1. Question

Do the N2 State problem families form stable first-order child branches, or are they mutually dependent constitution dimensions/relations over the same informational state?

N3 compares rival decompositions under the project child-promotion test.

---

# 2. Rival A — inherited three-part split

```text
Informational State
    ├─ Referent / Scope
    ├─ Content / Interpretation
    └─ Identity / Equivalence
```

## Strengths

- each names a real failure family;
- wrong referent can occur with otherwise correct content;
- same content can have multiple representations;
- identity/copy/version errors are highly consequential.

## Failure under hierarchy test

### Referent/scope and content are constitutionally entangled

For many representation systems, the subject/property/scope is part of the expressed content rather than a separable population of state phenomena.

Examples:

- `20°C` changes meaning when the subject/property/time binding changes;
- a graph statement's subject/relation/object together constitute its semantic claim;
- an annotation's target/selector determines what its body/comment is about.

### Identity/equivalence is comparison over the whole state

Whether two states count as the same can depend on:

- content;
- referent/scope;
- representation form;
- source/provenance;
- time;
- protected use.

It therefore behaves more like an individuation/equivalence relation over constituted states than a clean sibling region.

### Qualification is left structurally homeless

Source, perspective, mode, uncertainty, freshness and standing can materially change interpretation while fitting no clean child.

**Verdict:** useful orientation map; reject as immediate-child hierarchy.

# 3. Rival B — four-part split with qualification

```text
Informational State
    ├─ Reference / Applicability Binding
    ├─ Content / Interpretation
    ├─ Identity / Equivalence
    └─ Qualification / Standing
```

## Strengths

- makes state standing explicit;
- preserves decision-critical differences among fact/estimate/forecast/hypothesis, confidence and attribution;
- gives identity/version errors visible ownership.

## Failure

The branches repeatedly determine one another:

- applicability can be part of content semantics;
- mode/standing can affect identity (`same sentence quoted vs asserted`);
- source can matter for evidential identity but not semantic equivalence;
- temporal qualification can be scope, standing, or version identity depending on protected use;
- uncertainty may be encoded as content (distribution) or carried as qualification;
- evidence/authority standing is target-/Actor-/Work-relative and not wholly State-local.

This frame gives every important noun a home but does so by creating overlapping buckets rather than independent first-order regions.

**Verdict:** reject as universal child hierarchy.

# 4. Rival C — core constitution vs qualification/standing

```text
Informational State
    ├─ Semantic / Representational Constitution
    └─ State Qualification / Standing
```

Approximate mapping:

- core constitution → P1–P6;
- qualification/standing → P5, P7–P9;
- P10/P11 cross both.

## Strengths

This has a meaningful operational intuition:

> what the state says/is versus how it is qualified/positioned for reliance.

It also separates two common failure examples:

- wrong semantic content;
- right content but wrong currentness/confidence/source/stance.

## Attack

The boundary is not stable enough for child promotion:

1. `forecast`, `hypothesis`, `normative statement` can be interpreted as content mode or standing.
2. temporal scope can be semantic content, applicability qualification or identity/version boundary.
3. source/perspective can change interpretation itself rather than merely qualify a fixed content.
4. uncertainty can be the represented content (probability distribution) or metadata/standing around content.
5. identity/equivalence requires both sides and remains outside a clean two-child split.
6. evidence/authority standing partly belongs to relations with other states, Actors and Work/decisions.

The two regions are useful analytic lenses, but collapsing one into the other does not consistently create the kind of category error that justified the parent State/Dynamics split.

**Verdict:** retain as internal diagnostic distinction, not child hierarchy.

# 5. Rival D — representation-object vs claim/proposition vs model/state types

Candidate familiar type taxonomy:

```text
Data / Observation Result
Claim / Assertion
Belief / Estimate / Model
Record / Document
```

## Failure

The same concrete state can play several roles:

- a measurement result is data and may support a claim;
- a model output can be a prediction, evidence and later a record;
- a record persists a claim/model/result rather than forming a disjoint semantic kind;
- belief depends on holder relation;
- `data` is often representation form rather than one content class.

**Verdict:** reject category/type taxonomy as Foundation child split.

# 6. Rival E — bounded leaf with explicit constitution dimensions

Candidate:

> Treat `Informational State / Representational Constitution` as a bounded leaf for the current Foundation depth, while preserving a structured internal map of mutually dependent dimensions and relations.

Proposed internal map:

```text
Informational State / Representational Constitution   ← bounded leaf candidate

Core constitution dimensions
    • referent / subject binding
    • applicability / scope / reference frame
    • representational content / interpretation
    • representation form / encoding / schema binding
    • mode / stance / representational commitment

Individuation/comparison dimensions
    • identity / granularity / equivalence
    • version / copy / projection / fragment / aggregate distinctions when material

Qualification / relational dimensions
    • source / holder / perspective / attribution
    • uncertainty / confidence / reliability / epistemic standing
    • temporal standing / freshness
    • plurality / compatibility / conflict
    • availability / visibility / persistence status where State-side
```

## Why this is not merely refusing to decompose

The node remains useful because it protects one first-order outcome:

> **a representation must remain sufficiently constituted and qualified that a later consumer can tell what state it is, what it means/applies to, and when it is materially the same as or different from another state.**

Within that outcome, the dimensions are heavily co-dependent rather than independent child regions.

## Child-promotion test

### Distinct questions?

Yes, many dimensions ask different questions.

### Distinct failure modes?

Yes, wrong target, wrong meaning, wrong identity and wrong standing can fail separately.

### Does that force child promotion?

No. The project method requires more than separable questions: the candidate should form a stable first-order region rather than a recurring dimension/relationship.

### Cross-domain independence?

Current internal evidence repeatedly shows the opposite: different domains package the dimensions differently.

### Does collapsing dimensions lose necessary information?

Only if the dimensions themselves are erased. They can remain explicit in a leaf map without claiming hierarchical siblinghood.

**Verdict:** leading decomposition.

# 7. Why State differs from the parent State/Dynamics split

Potential objection:

> If State contains different failure families, why not promote them just as State/Dynamics were promoted?

Answer:

The parent split had a stronger categorical separation:

```text
informational product/result/state
!=
process/operation that produces or changes it
```

Those branches have different transition semantics and external traditions repeatedly distinguish the analytical kinds.

Inside State, by contrast:

- referent changes content interpretation;
- scope changes identity/currentness;
- form changes interpretability/equivalence;
- mode/standing changes what the same words mean for use;
- identity is a relation over all of the above.

The candidate State subregions therefore behave more like **facets of one constituted representation** than different first-order problem territories.

# 8. Cross-cutting dimensions retained

Even under the leaf candidate, not every concern becomes State-local.

Explicit boundary-sensitive relations remain:

- provenance/derivation history → State relations + Informational Dynamics;
- evidence → relation to target claim/question/body of information;
- authority → Actor/policy/control relation;
- truth → relation to represented reality/model semantics;
- current visibility/context → State + context-formation Dynamics + use relation;
- persistence lifecycle → Records specialization + Dynamics;
- conflict resolution/revision → Informational Dynamics / Work / authority depending focal question.

The leaf map records only the **State-side interpretation** of these concerns.
