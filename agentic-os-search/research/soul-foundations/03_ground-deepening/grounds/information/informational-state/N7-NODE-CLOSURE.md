# 4. Why no child was promoted

The pass found distinct failure families but not stable first-order partitions.

### Reference / scope

Load-bearing, but often part of content semantics itself.

### Content / interpretation

Central, but so broad that promoting it would reproduce the parent with leftover qualifiers.

### Identity / equivalence

Load-bearing, but depends on the whole constituted State and protected-use criteria; it behaves as individuation/comparison relation.

### Qualification / standing

The strongest rival child, but it mixes heterogeneous relations:

- uncertainty may be content or qualification;
- time may be applicability, standing or identity;
- source/perspective may affect interpretation;
- evidence is target-relative;
- authority partly belongs to Actors/control;
- truth relates State to actual reality;
- visibility depends on context-formation Dynamics and use.

### Conflict / plurality

Requires relations among multiple already constituted States and comparison criteria.

### Form / representation resource

Important but not a disjoint State population; one State can have many realizations and one resource can carry many States.

Thus promotion would create more overlap/residual ambiguity than structural gain.

# 7. External holdout value

The external corpus is diverse enough for bounded falsification but not universal proof.

Strong structural examples include:

- metrology: result = values attributed to measurand plus relevant information/uncertainty;
- RDF: reference/relation/object jointly constitute statements; referenced proposition need not be asserted;
- RDF canonicalization: informational equivalence is not byte/identifier identity;
- Web Annotation: source/selector/state/scope/purpose jointly specify a SpecificResource;
- PROV: specialization/alternate relations capture aspect/time/perspective-sensitive identity;
- Verifiable Credentials: verification/authenticity/currentness does not establish truth of claims;
- DCAT: version/status/coverage/attribution remain facets/relations around datasets and series.

No external taxonomy is adopted as SOUL Foundation structure.
