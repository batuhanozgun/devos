# Informational State / Representational Constitution — N1 Node Coherence Attack

**Status:** COMPLETE; node survives, internal decomposition remains open  
**Date:** 2026-09-05  
**Dependency:** `N0-CANONICAL-RECOVERY.md`

## 1. Question

Does `Informational State / Representational Constitution` remain a coherent research node when its label, scope and reduction rivals are attacked, or is it merely a residual bucket for anything that is not informational process/dynamics?

## 2. Reduction rival A — State is only a snapshot of Dynamics

Claim:

> An informational state is just a temporary output of acquisition/transformation, so a separate State node is unnecessary.

Counterexamples:

- the same acquisition procedure can yield states with different referents/content;
- a state can persist after the generating process is unavailable or forgotten;
- two semantically different states can have identical generation mechanisms;
- a state may be wrong/ambiguous/mis-scoped even when the process that created it was correctly executed;
- downstream consumers must interpret the state even when they know nothing about its generation dynamics.

**Verdict:** reduction fails. Current-state constitution owns decision-critical semantics not recoverable from process history alone.

## 3. Reduction rival B — State is only underlying reality

Claim:

> The represented condition is simply a view of Environment and should be stored as Environment state.

Counterexamples:

- actual condition can change while a representation remains stale;
- representation can change while actual condition remains fixed;
- model/forecast/estimate/hypothesis may represent non-realised or uncertain conditions;
- two Actors/systems may hold incompatible states about the same unchanged reality;
- a correctly preserved record can faithfully retain a false representation.

**Verdict:** reduction fails. Mediated state can vary independently of the referent.

## 4. Reduction rival C — State is only Actor belief/knowledge

Claim:

> Informational state is reducible to what an Actor knows/believes.

Counterexamples:

- a shared database/model can contain information no current Actor has in working awareness;
- source, holder, transmitter and authority can be different Actors;
- a representation can exist externally without being believed by anyone in the system;
- Actor identity/capability/authority does not change merely because a representation about it changes.

**Verdict:** reduction fails. Holder/perspective is an important relation, not the whole State node.

## 5. Vocabulary rival — Data / Claim / Belief / Model / Evidence / Record

This looks intuitive but mixes:

- representation forms (`data`);
- content/mode (`claim`, `model`);
- holder↔content relations (`belief`);
- target-relative roles (`evidence`);
- persistence specialisation (`record`).

The same informational state can simultaneously be represented as data, carry a claim/model, be believed by one Actor, serve as evidence for a question and later become a record.

**Verdict:** not a stable universal decomposition.

## 6. Label attack — does `State` imply only static facts?

Potential problem:

`State` might be read as:

- only factual propositions;
- only current truth;
- only immutable snapshots;
- only structured database rows.

Required bounded meaning:

> an identifiable informational result/representation available for interpretation at a relevant analytical moment, including descriptive, predictive, hypothetical, normative, probabilistic, model-like, symbolic or other representational content when the focal question concerns what the representation is and means rather than how it was formed/changed.

The node therefore may include uncertain, future-oriented, disputed or non-propositional structured representations. `State` is an analytical role, not a truth claim.

**Verdict:** label is usable only with `Representational Constitution` as scope protection.

## 7. Pre-semantic signal attack

Question:

> Does raw signal/channel information with no stable semantic referent invalidate the node?

Cases:

- a byte sequence has stable syntax but interpretation depends on a schema not currently available;
- a sensor waveform exists before a higher-level measurement value is derived;
- compressed/encrypted data is identifiable as an informational object while its semantic content is unavailable to the current consumer.

Result:

The node need not require rich human-semantic proposition content. It requires enough **representational individuation/interpretation convention** for there to be a state/result whose form/content/binding can be distinguished from its production process.

Pure channel capacity/noise without a concrete represented/result state is better treated under mediation Dynamics and/or Environment channel conditions.

**Verdict:** no forced sibling split between `Data` and `Semantic Representation` at this level.

## 8. Node residual-bucket test

Potential residual definition:

> “Anything informational that exists now.”

Rejected.

The node is bounded by a protected question:

> **What represented/informational result exists, what is it about, what content/form/identity/qualifications constitute it, and what makes it materially the same as or different from another state?**

Problems whose primary question is acquisition, derivation, revision, selection, communication or invalidation route to Informational Dynamics even if they create/change State.

Problems whose primary question is actual condition, Work execution/commitment or Actor authority route to neighboring grounds.

## 9. Internal-framing attack

N0 inherited three candidate regions:

1. referent/scope;
2. content/form/interpretation;
3. identity/granularity/equivalence.

N1 finds a strong warning against prematurely treating them as children:

- referent/scope often participates directly in content semantics;
- identity/equivalence is usually a comparison over already constituted states and may be purpose-sensitive;
- form/interpretation can change identity criteria;
- temporal/perspective/modal qualifiers can alter what counts as the same content/state;
- source/standing may be external relations yet materially affect interpretation/use.

Therefore the inherited three-part frame is a **problem map**, not yet a hierarchy.

## 11. N1 verdict

`Informational State / Representational Constitution` survives coherence, reduction, label and residual-bucket attack.

The node is **not** reducible to:

- Informational Dynamics;
- Environment state;
- Actor belief;
- persistent Records;
- familiar representation nouns.

However N1 weakens confidence in any immediate child split inherited from the parent. The strongest open question is now:

> **Does State contain stable first-order children, or are referent, content, identity and qualification inseparable constitution dimensions of one bounded leaf?**

N2 must inventory failure/problem families afresh before N3 compares those rivals.
