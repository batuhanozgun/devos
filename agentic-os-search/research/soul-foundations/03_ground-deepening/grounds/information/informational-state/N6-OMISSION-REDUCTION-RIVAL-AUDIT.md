# Informational State / Representational Constitution — N6 Omission, Reduction and Rival-Decomposition Audit

**Status:** COMPLETE; no missing stable immediate child found; same-model adversarial self-review  
**Date:** 2026-09-05  
**Dependency:** `N5-EXTERNAL-CROSS-DOMAIN-FALSIFIERS.md`

## 1. Verification warning

This is a **same-model adversarial review**. It is not independent verification.

The purpose is to defeat, if possible, the leading N3–N5 result:

> `Informational State / Representational Constitution` is a bounded leaf at the current Foundation depth; its internal structure is better represented by explicit, mutually dependent constitution/qualification relations than by immediate child branches.

The audit therefore searches for:

- a missing first-order child;
- a forced-fit case;
- a stable rival decomposition with cleaner boundaries;
- evidence that one supposedly dimensional concern actually owns an independent protected outcome;
- a reason to merge State back into the parent or split it from the parent differently.

---

# 2. Missing-child probe — Reference / Scope

## Promotion argument

Reference errors are independently catastrophic:

- right value, wrong entity;
- right claim, wrong period;
- right statement, wrong sample/population;
- same resource, wrong version/segment.

This looks like a distinct protected outcome:

> bind information to the correct subject and applicability boundary.

## Anti-promotion attack

Across RDF, measurement, annotation and credential cases, reference/applicability is often part of what the state **means**, not a separable population of State phenomena.

Examples:

- changing RDF subject changes the proposition;
- changing measurand changes what a value represents;
- changing annotation target/selector changes the annotated state;
- changing credential subject changes the claim.

A `Reference` child would therefore have to own a semantic component that is simultaneously constitutive of the `Content` child.

## Verdict

Distinct diagnostic dimension, but no stable child boundary.

**Not promoted.**

---

# 3. Missing-child probe — Content / Interpretation

## Promotion argument

Semantic interpretation appears central enough to own a branch:

- encoding can be valid while meaning is wrong;
- schema/vocabulary can be absent;
- same syntax can support different interpretations;
- a representation can be ambiguous or under-specified.

## Anti-promotion attack

A universal `Content` child immediately depends on:

- referent/scope;
- representation form/schema;
- mode/stance;
- units/reference frame;
- sometimes source/perspective.

It would become almost coextensive with the whole State node. The remaining siblings would mainly be qualifiers or relations around it.

That is not a useful first-order decomposition; it is a relabeling of the parent plus leftovers.

## Verdict

Central constitution region, not a stable child under the current depth.

**Not promoted.**

---

# 4. Missing-child probe — Representation Resource / Form

## Rival

Split the node into:

```text
Semantic State / Content
Representation Resource / Encoding
```

## Why plausible

The same semantic content can be represented in many forms; the same bytes can be interpreted differently. Systems also need artifact/resource identity independent of semantic equivalence.

## Attack

This split fails as a universal first-order structure because:

- some states are naturally abstract values/relations rather than document-like resources;
- one concrete artifact can encode many informational states;
- one state can be distributed across several resources;
- form matters only relative to an interpretation/equivalence requirement;
- RDF canonicalization demonstrates that concrete realization and abstract informational equivalence are related but not peer populations;
- Records already deepens persistent resource/version/representation obligations when horizon matters.

The distinction remains critical, but as a form/realization dimension plus identity relation.

## Verdict

**Not promoted.**

---

# 5. Missing-child probe — Identity / Equivalence

## Promotion argument

Identity errors are independent and highly consequential:

- copy vs independent source;
- version vs same resource;
- projection vs complete source;
- aggregate vs constituent;
- equivalent encoding vs distinct fact.

The completed Records corpus gives this region substantial depth.

## Anti-promotion attack

Identity/equivalence cannot be evaluated without criteria drawn from the entire constituted state:

- referent;
- scope/time;
- content;
- form;
- source/provenance;
- protected use.

RDF Dataset Canonicalization, PROV specialization/alternate relations, Web Annotation SpecificResource and Records version/representation distinctions all show that identity is **relation/individuation over states/resources**, not a self-contained informational state kind.

Promoting it as a child would duplicate the semantics it needs from every other branch.

## Verdict

Very high-value cross-state relation family; not a child.

**Not promoted.**

---

# 6. Missing-child probe — Mode / Assertion / Proposition Status

## Candidate

```text
Asserted / Observed / Estimated / Hypothetical / Forecast / Normative / Quoted ...
```

## Why plausible

Misreading representational commitment changes downstream reasoning even when words/values are identical.

## Attack

RDF 1.2 provides a strong counterexample to a type hierarchy: a proposition can be referenced without being asserted. The same represented proposition can participate under different assertion relations.

Likewise:

- a quoted statement and an endorsed statement may have identical text;
- a model output can be treated as forecast, candidate, or accepted estimate depending on surrounding standing;
- a normative text can represent an obligation without itself creating binding authority.

This is best preserved as **mode/stance/commitment qualification of the state**, with some force delegated to Work/Actors/control.

## Verdict

Load-bearing qualification, not stable child.

**Not promoted.**

---

# 7. Missing-child probe — Qualification / Standing

This is the strongest remaining rival to the leaf result.

## Candidate split

```text
Informational State
    ├─ Core Representational Constitution
    └─ Qualification / Standing
```

Qualification would own:

- source/attribution;
- uncertainty/confidence;
- reliability;
- currentness/freshness;
- epistemic status;
- evidential status;
- possibly visibility/persistence status.

## Promotion argument

A state can have correct content but wrong standing:

- accurate quote treated as endorsed fact;
- correct historical value treated as current;
- point estimate used without uncertainty;
- authentic credential treated as proof that its claims are true.

These are distinct failure modes.

## Strong attack

The boundary is unstable across domains and across the same state:

1. **Uncertainty** may itself be represented content (distribution/interval) or an external qualification.
2. **Temporal applicability** may be part of proposition content, validity standing, or version identity.
3. **Source/perspective** can alter interpretation, not merely qualify fixed content.
4. **Mode** may be semantic content (`forecast for 2030`) or assertion relation (`quoted but not endorsed`).
5. **Evidence** is target-relative, not intrinsic State standing.
6. **Authority** belongs partly to Actors/policy/control.
7. **Truth** relates state to actual reality/model semantics, not to an intrinsic metadata field.
8. **Current visibility** depends on context-selection Dynamics and use.
9. VC 2.0 explicitly separates cryptographic verifiability/currentness from truth and use-specific validation, demonstrating that one generic `Standing` branch would itself contain heterogeneous relations.

The proposed child would therefore become a residual bucket of cross-cutting relations crossing State, other Information, Actors, Work and Environment.

## Verdict

Useful diagnostic grouping; fails clean first-order child boundary.

**Not promoted.**

---

# 8. Missing-child probe — Perspective / Holder / Sharedness

## Promotion argument

SOUL systems must distinguish:

- Actor-local belief;
- shared model;
- external-source claim;
- system-generated estimate;
- quoted/delegated information.

## Attack

These distinctions depend on relations between State and Actors/systems:

- source != current holder;
- holder != endorser;
- shared storage != shared belief;
- system-level representation != every Actor's knowledge;
- Actor authority remains Actors territory.

Creating a `Perspective` child would partially duplicate Actor relations and still leave content/identity/applicability inside each perspective.

## Verdict

Cross-ground attribution/perspective relation family.

**Not promoted.**

---

# 9. Missing-child probe — Temporal State / Currentness

## Promotion argument

Time creates independent semantics:

- observed time;
- effective/applicable time;
- known/recorded time;
- validity interval;
- current/historical/superseded standing.

Records has already shown that one timestamp is insufficient.

## Attack

Time plays several roles rather than one child role:

- applicability/scope of content;
- state standing/freshness;
- version/identity boundary;
- derivation/generation time in Dynamics;
- persistent historical reconstruction in Records.

A `Temporal State` child would therefore split one dimension by medium rather than own a coherent population or protected outcome.

## Verdict

Critical multi-role dimension; not child.

**Not promoted.**

---

# 10. Missing-child probe — Conflict / Plurality

## Promotion argument

Systems need to preserve contradictory, competing or partially compatible informational states without silently overwriting them.

## Attack

Conflict requires at least two already constituted states and comparison conditions:

- same referent?
- same time/scope?
- same mode?
- compatible uncertainty?
- independent provenance?

It is therefore a relation/condition over states. Conflict resolution/revision additionally belongs to Dynamics/Work/authority depending on focal question.

## Verdict

No isolated `Conflict State` branch required.

**Not promoted.**

---

# 11. Missing-child probe — Schema / Ontology / Representation System

## Promotion argument

Interpretation depends on vocabularies, schemas, units, languages and ontologies. Without them, bytes can survive while meaning is lost.

## Attack

A schema/ontology can itself be represented as Informational State, but its role relative to another state is interpretive/reference metadata. Construction/revision/governance of such systems can be Dynamics/Work.

Promoting `Schema` would mix:

- representation resource;
- interpretive relation;
- modeling Work;
- implementation mechanism.

## Verdict

Important interpretation dependency, not immediate child.

**Not promoted.**

---

# 12. Missing-child probe — Non-propositional / multimodal representation

## Challenge

Does the leaf map secretly assume all State is proposition-like text/data?

Holdouts:

- image;
- embedding/vector representation;
- map;
- probabilistic distribution;
- simulation/model state;
- waveform;
- graph;
- executable/model artifact used representationally.

## Result

The leaf map remains applicable without forcing proposition semantics:

- referent/applicability can be partial/implicit;
- content/interpretation can be structural/statistical/model-based;
- form/encoding remains explicit;
- identity/equivalence criteria can differ by use;
- mode/standing may be weaker or domain-specific.

The node does not require that every State instantiate every dimension, only that material distinctions not be silently collapsed.

## Verdict

No multimodal child forced; the bounded scope survives.

# 13. Rival decomposition — Intrinsic vs Extrinsic State

Candidate:

```text
Intrinsic Constitution
Extrinsic Relations / Standing
```

## Attraction

This appears cleaner than content-vs-standing.

## Failure

The intrinsic/extrinsic boundary is unstable:

- subject/referent may be external relation yet semantically constitutive;
- units/schema may be external conventions yet necessary for content;
- temporal scope can be encoded or relational;
- identity depends on use/provenance criteria;
- uncertainty can be encoded content or external assessment.

The distinction can still be useful in specific models, but it is not a stable Foundation child split across holdouts.

**Verdict:** rejected as universal immediate-child structure.

---

# 14. Rival reduction — merge Informational State back into Information parent

Claim:

> If State is a leaf with many dimensions, perhaps it need not be a child at all.

Attack result:

The parent State/Dynamics separation remains load-bearing:

- a well-constituted state can be produced by faulty Dynamics;
- faulty state meaning/scope can exist despite valid process execution;
- an output can be interpreted independently of reconstructing its full generation process;
- external measurement, provenance, observation and belief-change traditions preserve product/result vs process/change distinctions.

The fact that State has no deeper children does not invalidate its first-order boundary from Dynamics.

**Verdict:** do not merge.

---

# 15. Rival split — promote State into multiple top-level grounds

Candidate:

- Meaning / Semantics;
- Identity;
- Epistemic Standing;
- Representation Resource.

## Attack

This would fragment one protected outcome — correct representational constitution — into cross-dependent grounds whose boundaries repeatedly require one another and cross Environment/Actors/Work relations.

It would also overfit implementation/disciplinary vocabularies without evidence of independent top-level failure territories comparable to Environment, Work, Actors or parent Information.

**Verdict:** reject.

# 16. Reduction of internal map

N6 tests whether the internal leaf map itself is over-elaborate.

A useful compact grouping survives:

```text
A. Reference & applicability
   what is represented, under what scope/frame/time

B. Content & realization
   what is expressed and how form/schema/mode carry it

C. Individuation
   when this state is same/different/version/copy/projection/aggregate

D. Qualification & relations
   source/perspective, uncertainty/standing/freshness, conflict, visibility/persistence status where material
```

But these four groups are **orientation clusters only**, not children. The same decision-critical field may participate in more than one group depending on the domain.

This compact grouping can improve retrieval without pretending the dimensions form a taxonomy.

# 17. Omission verdict

No adversarial probe exposes a stable immediate first-order child that improves the Foundation hierarchy without creating greater overlap or boundary leakage.

The strongest candidates reduce as follows:

```text
reference / scope                → constitution dimension
content / interpretation         → central constitution dimension
representation form              → constitution/realization dimension
mode / assertion                 → state mode/qualification
identity / equivalence           → individuation relation over constituted states
source / perspective             → attribution relation, partly Actors-bound
uncertainty / standing           → qualification / target-relative relation
freshness / currentness          → temporal applicability/standing + Dynamics/Records links
conflict / plurality             → relation over multiple states
schema / ontology                → interpretation dependency / represented resource / Work boundary
visibility / persistence status  → State condition + Dynamics/Records/Actors/Environment dependencies
```

Additional probes now mostly change vocabulary, grouping or domain mechanism rather than exposing a new first-order region.

# 18. N6 verdict

The N3–N5 leading result survives the same-model adversarial audit:

```text
Informational State / Representational Constitution   ← BOUNDED LEAF CANDIDATE

No immediate child promoted.
```

The leaf is not semantically empty. It retains a required constitution map so later SOUL / Development OS reasoning can distinguish:

- wrong referent from wrong content;
- wrong scope/currentness from wrong value;
- semantic equivalence from byte/resource identity;
- assertion/forecast/hypothesis modes;
- source/holder/authority/truth differences;
- uncertainty/standing loss;
- genuine contradiction from scope/time/perspective differences;
- source existence/persistence from current visibility.

## Verification status

- canonical parent/internal evidence: recovered;
- completed Records specialization: reused;
- relevant candidate studies: selectively reused;
- materially different primary/authoritative external traditions: used as falsifiers;
- N6: same-model adversarial review;

Therefore N6 supports bounded closure, not universal or independently proven completeness.
