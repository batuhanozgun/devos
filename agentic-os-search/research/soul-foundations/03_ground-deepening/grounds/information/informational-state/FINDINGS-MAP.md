# Informational State / Representational Constitution — Findings Map

**Status:** bounded leaf / user-evaluated / accepted for Foundation sequencing  
**Research date:** 2026-09-05; **maintenance update:** 2026-09-14  
**Warning:** this is a Foundation research map, not architecture/ontology/schema.

## A. Node result

Current bounded judgment:

> **Informational State / Representational Constitution is a bounded leaf for the current Foundation research depth. No stable immediate child split survived N1–N6.**

This does not mean the node has no internal structure. It means its load-bearing concerns behave more like mutually dependent constitution dimensions/relations than clean first-order child regions.

## B. Protected outcome

A usable informational state must preserve enough constitution that a later consumer can determine, when material:

- what the representation is about;
- under what applicability/scope/reference frame;
- what it expresses and how it is interpreted;
- which form/schema/encoding carries it;
- in what representational mode/stance it appears;
- when it is the same as or different from another state;
- which source/perspective/uncertainty/currentness/standing relations materially affect interpretation or reliance.

## C. Internal constitution map — not child hierarchy

```text
Informational State / Representational Constitution

A. Reference & applicability
   ├─ referent / subject binding
   └─ scope / time / population / reference frame

B. Content & realization
   ├─ content / semantic interpretation
   ├─ representation form / encoding / schema binding
   └─ mode / stance / representational commitment

C. Individuation
   ├─ identity / granularity / equivalence
   └─ version / copy / projection / fragment / aggregate distinctions when material

D. Qualification & relations
   ├─ source / holder / perspective / attribution
   ├─ uncertainty / confidence / reliability / epistemic standing
   ├─ temporal standing / freshness
   ├─ plurality / compatibility / conflict
   └─ availability / visibility / persistence status where State-side
```

The A–D groups are compact orientation clusters. They are not accepted children and may overlap in domain-specific cases.

## D. Why inherited three-part hierarchy was rejected

The parent exposed:

```text
referent / scope
content / interpretation
identity / equivalence
```

as load-bearing State problem regions.

The child pass found that these do not form a clean hierarchy:

- referent/scope often constitutes content meaning;
- identity/equivalence is evaluated over the whole State under criteria;
- form/interpretation affects equivalence;
- temporal/perspective/modal qualifiers can change identity or content;
- source/standing would otherwise be structurally homeless.

The three-part frame remains useful as a diagnostic prompt but not as immediate children.

## E. Why `Core Constitution + Qualification/Standing` was not promoted

This was the strongest rival split.

It failed because the boundary changes by domain:

- uncertainty can be represented content or qualification;
- time can be content scope, currentness standing or identity/version boundary;
- source/perspective can alter interpretation itself;
- mode can be content or assertion relation;
- evidence is target-relative;
- authority partly belongs to Actors/policy/control;
- truth relates representation to reality, not simply to an intrinsic standing field.

The distinction remains useful diagnostically but not as a universal child partition.

## F. Identity / equivalence result

Identity is load-bearing but not reducible to one identifier or one object property.

Potential distinctions include:

```text
same bytes
!= same representation identity
!= same semantic content
!= same version
!= same source assertion
!= same derivation
!= same projection/aggregate
!= same state for every protected use
```

RDF canonicalization, PROV specialization/alternate relations, Web Annotation SpecificResource and Records evidence all support treating identity/equivalence as relation/individuation over constituted states/resources.

## G. Mode / stance result

The same represented content can carry materially different commitment:

- observed result;
- assertion/report;
- quotation;
- assumption;
- hypothesis;
- estimate;
- forecast;
- simulation output;
- normative/policy representation;
- candidate alternative.

Mode is essential to interpretation but does not form a disjoint State type hierarchy. Representing a norm/decision/status also does not create the corresponding Work/Actor force.

## H. Standing / truth / evidence / authority result

Preserve:

```text
state exists
!= state is interpreted correctly
!= represented claim is true
!= state is evidence for target claim
!= source is authoritative for role
!= evidence is sufficient for decision
!= decision is authorised/committed
```

W3C Verifiable Credentials supplies a strong holdout: a credential may be cryptographically verifiable/current while truth of its claims still requires separate validation for the use case.

## I. Conflict / plurality result

Before treating two States as contradictory, align at least when material:

- referent/property;
- applicability time/scope;
- unit/reference frame;
- mode/stance;
- granularity;
- uncertainty;
- source/lineage independence.

Conflict is therefore a relation over constituted states plus comparison conditions. Conflict resolution/revision is later Dynamics/Work/authority territory depending on focal question.

## J. Boundary with Informational Dynamics

```text
State      → what represented result exists and how it is constituted/qualified
Dynamics   → how states are acquired, derived, selected, revised, communicated, invalidated or otherwise changed
```

A faulty transformation can produce a well-defined wrong output State; a State can be mis-scoped/ambiguous despite a correctly executed process.

The State leaf result does not weaken the accepted parent State/Dynamics split.

## K. Boundary with Environment

Environment owns realised conditions. Informational State owns representations of them when mediation is focal.

```text
actual condition
!= measurement/model/forecast/claim about condition
```

Truth/currentness is not established merely by good State constitution.

## L. Boundary with Work

Represented plans, statuses, decisions, evidence and acceptance assertions are informational States. Actual selection, commitment, execution, verification and acceptance remain Work.

Changing `status = done` does not itself complete Work.

## M. Boundary with Actors

Source/holder/perspective/attribution can qualify State interpretation. Actor identity, role, capability, authority, obligation and accountability remain Actors.

Source authority does not imply universal truth.

## N. Boundary with Records / persistence

State constitution exists before persistence. When future-use/horizon obligations activate, Records deepens:

- exact identity/version/representation binding;
- preservation closure;
- history/standing survivability;
- retrieval guarantees;
- retention/disposition.

Correct persistence can preserve a false or stale State perfectly.

## O. External falsifier convergence

Materially different external traditions did not force a State child hierarchy:

- metrology bundles measurand + result values + uncertainty/relevant info;
- RDF statements couple reference/relation/object and separate assertion participation;
- RDF canonicalization makes equivalence whole-dataset/criterion dependent;
- Web Annotation composes source/selector/state/scope/purpose around a SpecificResource;
- PROV represents aspect/time/perspective-sensitive specialization/alternates;
- Verifiable Credentials combine subject/claims/issuer/validity/status while separating verification from truth;
- DCAT uses version/status/coverage/attribution as facets/relations around datasets/series.

The convergence is on **coupled constitution facets**, not one shared taxonomy.
