# Informational State / Representational Constitution — Research Plan

**Status:** active node plan  
**Date:** 2026-09-05

## Objective

Research Informational State as a first-principles foundation node without importing a ready-made knowledge, database, epistemology or ontology taxonomy as the answer.

The pass must determine whether the node has stable immediate first-order children and preserve distinctions that later SOUL / Development OS reasoning may need for failure analysis and composition.

## Starting hypotheses to attack

The parent pass exposed three provisional state-side regions:

1. referent / subject / scope binding;
2. representational content / form / interpretation / assertion semantics;
3. informational identity / granularity / equivalence.

These are **not pre-accepted children**. The pass must test merge, split, dimension and relation alternatives.

## Decision-critical questions

### Constitution / aboutness

- What makes an informational state about one referent/scope rather than another?
- Can scope, time, perspective or qualification change without changing informational identity?
- How should partial, ambiguous, indirect or composite aboutness be treated?

### Content / interpretation

- What is the distinction among raw representation form, interpreted content and assertion/claim mode?
- When do two different encodings constitute the same informational state for the research purpose?
- When can the same form support materially different interpretations?

### Identity / granularity / equivalence

- What makes two informational states the same, versions, specializations, projections, fragments, aggregates or materially different states?
- Which identity criteria are context-relative versus intrinsic enough to belong locally?

### Standing / plurality

- Which distinctions among assertion, assumption, hypothesis, estimate, accepted fact, confidence, reliability and evidential standing are state-local?
- How should genuine contradiction be separated from differing time, scope, perspective, granularity or uncertainty?

### Holder / source / sharing

- What distinguishes source, holder, perspective and audience/visibility?
- What makes information Actor-local, shared, system-level or externally sourced without collapsing Information into Actors or access control?

## N0 — Canonical / internal evidence recovery

Recover:

- parent Information N2/N3/N4/N5/N6/N7 evidence relevant to State;
- completed Records evidence where persistence reveals state identity/standing requirements;
- relevant candidate-study packages through `research/studies/CATALOG.md` and selected `META.md`/findings;
- historical evidence only when current canonical surfaces point to it or it materially tests a boundary.

## N1 — Node coherence attack

Test whether:

- Informational State is genuinely distinct from Informational Dynamics;
- it is too broad and residual;
- `Representational Constitution` is an appropriate protected description;
- signal/data before semantic interpretation forces a split;
- belief/knowledge/claim/data/record categories create a stronger rival parent framing.

## N2 — First-principles problem inventory

Derive problem families from failure cases and independent questions, not familiar nouns.

Expected probes include:

- wrong referent or scope;
- right referent, wrong content;
- right content, ambiguous interpretation;
- stale temporal applicability;
- identity/version confusion;
- projection/summary losing load-bearing qualification;
- contradictory states that are actually scope/time/perspective variants;
- source/holder/authority confusion;
- uncertainty/standing loss;
- persistent copy preserving the wrong state perfectly.

## N3 — Immediate-child discovery

Compare at least these rival frames:

- referent / content / identity;
- semantic anchoring / representational constitution / state standing;
- denotation-aboutness / content-interpretation / identity-equivalence / qualification-standing;
- no stable split: one state node with cross-cutting dimensions.

Promote only distinctions that survive the project child-promotion test.

## N4 — Boundary / anti-collapse

Stress against:

- Informational Dynamics: state/result vs acquisition/derivation/revision/selection;
- Environment: represented condition vs actual realised condition;
- Work: represented plan/status/decision vs actual commitment/execution/acceptance;
- Actors: representation about/source/holder vs Actor identity/authority;
- Records: persistent informational state vs persistence lifecycle obligations.

## N5 — External / cross-domain falsifiers

Use materially different traditions rather than many examples from one vocabulary. Candidate domains:

- measurement/observation results;
- knowledge representation / RDF-style statements and graph semantics;
- provenance/entity identity and specialization;
- annotation/targeting and selectors;
- database/query/data-model identity and views;
- scientific claims/data with uncertainty and versioning;
- legal/recordkeeping statements where source, standing and persistence diverge;
- distributed/versioned representations where equal bytes do not imply equal meaning or applicability.

Primary/authoritative sources are preferred where available. External taxonomies are falsifiers and mechanism evidence, not imported ontology.

## N6 — Omission / reduction / rival audit

Attempt to find:

- a stable missing first-order child;
- a case forced unnaturally into the proposed split;
- a supposedly local dimension that actually belongs to Dynamics or a neighboring ground;
- a simpler decomposition preserving all decision-critical distinctions;
- a third-party framing that exposes a hidden assumption.

Same-model audit must remain labeled non-independent.

## N7 — Closure

Close for user evaluation only if:

- the node boundary remains coherent and non-residual;
- immediate-child structure or justified no-split result is boundedly supported;
- broad external probes have declining structural information gain;
- cross-cutting dimensions are explicit;
- Records and neighboring-ground boundaries remain recoverable;
- residual/reopen questions are explicit;
- verification strength is accurately labeled.

Finding an immediate child does not authorize researching it in this pass.
