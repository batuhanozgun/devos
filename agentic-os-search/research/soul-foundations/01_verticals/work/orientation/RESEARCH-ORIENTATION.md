# Work — Initial Research Orientation

**Status:** historical starting orientation, retained for research-path recovery  
**Current conclusion:** see `../synthesis/WORK-VERTICAL-SYNTHESIS.md` when available

## 1. Established context

The authorised task is independent Layer-1 foundations research into the provisional problem label `Work`.

Established before substantive Work research:

- Records is sufficiently complete for the current foundation purpose and has been evaluated.
- Work is explicitly authorised as the active independent vertical.
- Actors, cross-vertical synthesis, SOUL architecture and implementation design are not authorised.
- Records substantive conclusions are not Work axioms.
- `Work` is a research label, not a primitive or accepted ontology category.

## 2. Weak starting hypothesis

A deliberately weak prompt was retained from the parent framing: the area may involve things that must be done, changed, investigated, decided, verified, recovered, coordinated or completed, together with conditions under which such activity is represented and controlled.

This was not accepted as a definition because it already risks privileging:

- a bounded `thing to do` as the unit of analysis;
- explicit work items over ongoing activity;
- lifecycle/state-transition models over situated or flow models;
- planned work over emergent work;
- completion as the dominant terminal semantics.

## 3. Decision-critical assumptions challenged first

The initial inquiry treated the following as falsifiable framing assumptions:

1. **Task atomism:** a task/work item is the natural base unit.
2. **Lifecycle primacy:** Work is mainly a state-machine/lifecycle problem.
3. **Plan fidelity:** planned sequence is a sufficiently faithful account of actual work.
4. **Single-case identity:** each action/event belongs to one obvious work instance.
5. **Closure universality:** meaningful work is normally bounded by completion.
6. **Item locality:** progress and control can be understood from item-local properties without system-level flow or dependency state.
7. **Simple termination:** cancellation or failure can be modeled as stopping/deleting rather than as recovery, compensation or reconciliation.

## 4. Competing starting frames

Rather than choose a taxonomy in advance, the first evidence sweep compared materially different units and explanatory lenses:

### A. Task / work-item lifecycle frame

Work is represented as bounded items with states, transitions, dependencies and completion criteria.

This remains useful, but its universality was the main hypothesis under test.

### B. Process / task-network frame

Work is a structured network of activities, potentially hierarchical, partially ordered, concurrent and decomposable through alternative methods.

HTN planning provided an explicit counterexample to flat task lists: a task network can be partially ordered, and a method maps an abstract task to a possible network for achieving it.

### C. Constraint / event / case frame

Work is not necessarily driven by a fixed activity sequence. Some domains are better characterised by constraints, events, evolving situations and discretionary actions.

Declarative process research and OMG CMMN directly challenge over-specified imperative flows.

### D. Situated activity frame

The plan or procedure is not identical to the work as actually performed. Work unfolds in local circumstances and can adapt while retaining its purpose.

Work-as-Imagined / Work-as-Done research and activity-theoretic work analysis challenge models that reduce actual practice to execution of a prescribed script.

### E. Coordination / dependency frame

A material part of Work is the management of dependencies among activities: shared resources, producer/consumer relations, prerequisites, simultaneity and task/subtask relations.

This lens makes coordination and articulation work visible rather than treating them as administrative noise around the `real` task.

### F. Flow / queue frame

Work may need system-level analysis: number of items in process, rate, waiting/time-in-system and capacity interact even when each individual item has a valid lifecycle.

This challenges item-local optimisation as a complete Work model.

### G. Durable activity / operations frame

Not all Work is a temporary project or finite item. Activity theory distinguishes short-lived goal-directed actions from durable collective activity systems; project-management literature separately distinguishes temporary projects from ongoing repetitive operations.

This challenges universal closure as a foundation assumption.

## 5. Strongest alternative to the starting frame

The strongest early alternative was:

> **Work is better treated provisionally as situated, interdependent activity and flow oriented toward objects/goals/outcomes under constraints, evolving information, temporal/dependency structure and recovery conditions; bounded tasks or work items are useful projections in some regimes, not yet justified as the universal primitive.**

This is a research orientation, not a final ontology.

## 6. Initial directional result

The first evidence sweep falsified the narrow form of `Work = task item + scalar lifecycle` as a sufficient foundation frame.

It did **not** falsify tasks or lifecycles as useful concepts. Instead, it required subsequent research to examine at least:

- units and levels of analysis;
- goal/object/action/decomposition relations;
- plan versus actual execution;
- imperative versus declarative/adaptive control;
- dependencies, concurrency, interruption and coordination;
- system-level flow/capacity;
- state, completion, validation and acceptance semantics;
- failure, termination, recovery and compensation;
- temporary versus ongoing work.

The subsequent findings notes follow these evidence-emergent questions rather than a precommitted pass sequence.
