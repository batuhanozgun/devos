# Work Environment — Counterframe / Terminology Source Ledger

**Role:** evidence trace for `findings/06-counterframes-and-terminology.md`  
**Date:** 2026-09-02

## S1 — ISO 6385 work-system/work-environment terminology

ISO 6385:2016, *Ergonomics principles in the design of work systems*.  
https://www.iso.org/standard/63785.html

Relevant evidence:
- ergonomics uses `work environment` as part of a broader work-system frame including workers, equipment, workspace and surrounding factors.

Use role: establishes terminology collision; not evidence for the intended technical-domain definition.

## S2 — Digital workplace review

Marsh et al., *The digital workplace and its dark side: An integrative review*, Computers in Human Behavior 128 (2022), 107118.  
https://doi.org/10.1016/j.chb.2021.107118

Relevant evidence:
- digital workplace spans connected technologies used for work;
- stronger formulations go beyond technology into physical/cultural/digital elements, practices, leadership and human-technology relationships.

Use role: demonstrates that `digital workplace` is broader/socio-technical rather than a clean technical-only term.

## S3 — Digital Work Environment / CSCW

Nauwerck & Cowen Forssell, *The Digital Work Environment—a Challenge and an Opportunity for CSCW*, ECSCW 2018.  
Repository: https://mau.diva-portal.org/smash/record.jsf?pid=diva2%3A1821670

Relevant evidence:
- emerging/boundary-object concept;
- no consensus on definition;
- continuum from narrow cognitive/interface definition to broad physical/organizational/social/cognitive effects of digitalisation.

## S4 — NIST/CNSSI `computing environment`

NIST CSRC Glossary, `computing environment`.  
https://csrc.nist.gov/glossary/term/computing_environment

Definition source CNSSI 4009-2015: workstation/server host plus OS, peripherals and applications.

Use role: shows established computing term is host-centric/narrower than the richer distributed work-support phenomenon.

## S5 — National Academies computational reproducibility

National Academies, *Reproducibility and Replicability in Science*, 2019.  
Summary: https://www.ncbi.nlm.nih.gov/books/NBK547531/  
Reproducibility chapter: https://www.ncbi.nlm.nih.gov/books/NBK547532/

Relevant evidence:
- computational environment includes OS, hardware architecture and library dependencies necessary to reproduce computational results.

Use role: supports execution/analysis-context meaning of `computational environment`.

## S6 — The Turing Way reproducible environments

*The Turing Way*, `Reproducible Environments`.  
https://book.the-turing-way.org/reproducible-research/renv/

Relevant evidence:
- computational environment broadly = system where a program runs, including hardware and software versions/configuration.

Use role: corroborates narrow execution/computation focus.

## S7 — Tools and techniques for computational reproducibility

Piccolo & Frampton, *Tools and techniques for computational reproducibility*, GigaScience, 2016.  
https://pmc.ncbi.nlm.nih.gov/articles/PMC4940747/

Relevant evidence:
- software runs within OS/hardware/dependency context;
- environment differences change execution/output;
- multiple capture techniques have different fidelity.

## S8 — NIST/ECMA Software Engineering Environment reference model

NIST SP 500-211 / ECMA TR/55.  
https://www.nist.gov/publications/reference-model-frameworks-software-engineering-environments-technical-report-ecma-tr55

Relevant evidence:
- richer environment as system/framework of tools plus common services/integration on underlying platform;
- environments can be adapted/instantiated/subdivided.

Use role: closest established rich technical analogue, but software-engineering-specific.

## S9 — SEI Software Development Environment integration

Brown, Feiler & Wallnau, *Understanding Integration in a Software Development Environment*, CMU/SEI-91-TR-031.  
https://www.sei.cmu.edu/library/understanding-integration-in-a-software-development-environment/

Relevant evidence:
- SDE as unifying framework of services supporting software development/maintenance.

## S10 — Current CASRAI computational-environment term

CASRAI Dictionary, `Computational Environment` (2026).  
https://casrai.org/dictionary/term/computational-environment

Relevant evidence:
- full software/hardware context for analysis execution, including OS/runtime/libraries/config/env vars/hardware-specific dependencies.

Strength caveat:
- useful current terminology source, but dictionary editorial content is not treated as primary research authority; corroborated by National Academies/Turing Way.

## S11 — Work-support environment phrase in digital-library systems

Nikolaou & Marazakis, *System infrastructure for digital libraries: A survey and outlook*, LNCS 1521 (1998).  
Search/summary route: https://eurekamag.com/research/109/615/109615809.php

Relevant evidence:
- historical use of `work support environment` for an integrated setting combining information management, coordination and collaboration.

Use role:
- shows `work-support environment` is linguistically plausible but not established as a general standardized domain term.
