# Environment — KEY

**Document role:** CURRENT_L0  
**Vertical revision:** `environment-foundation-2026-09-01-r1`  
**Status:** intentionally lossy orientation surface; bounded result awaiting user evaluation; not evidence or architecture.

## What this vertical studied

Whether a distinct first-order problem remains around the world/operating conditions outside a selected controlled-system boundary after Records, Work and Actors are already preserved.

`Environment` is a research label, not an accepted SOUL primitive or module.

## Main result

A distinct foundation **problem region** survives reduction, but not as a clean fourth object class.

The strongest current account is a **boundary-relative operating world**:

- current external/world states and conditions;
- processes/dynamics that can change independently;
- interfaces/resources through which sensing/action/dependence occurs;
- partial/noisy/delayed observation of that world;
- external conditions that affect feasible actions and outcomes.

The same concrete entity can be internal system element, Actor, tool, resource, infrastructure or external system depending on boundary and relation.

## Non-collapse rules

- Environment/world state ≠ context.
- World state ≠ observation ≠ belief ≠ Record.
- Actor capability ≠ situated actionability.
- Work status/effects ≠ underlying external condition.
- Tool/resource/infrastructure ≠ intrinsic Environment object type.
- Other Actor ≠ only Environment.
- Boundary ≠ fixed natural fact.
- Environment ≠ static metadata.

## Fourth-leg result

- **Independent foundation problem region:** supported at bounded research level.
- **Mutually exclusive fourth ontology leg:** not supported.
- **Required fourth architecture module:** not established.
- **Relation-only representation:** remains viable if it can represent boundary-relative external states/conditions/resources/interfaces as relata; that represents the problem region rather than eliminating it.

## Strongest working principle

> Before judging whether an Actor/Work system can act or has achieved an outcome, distinguish the selected system boundary, the relevant current operating-world state/dynamics, what was actually observed/known/recorded, and the relations that make those conditions relevant to the Work.
