# Environment — Open Questions

**Status:** residual questions after bounded independent research  
**Vertical revision:** `environment-foundation-2026-09-01-r1`

These questions do not currently reopen a missing first-order Environment family. They remain refinement, threshold, domain-specific or later cross-vertical questions unless new evidence shows otherwise.

## Environment-local residuals

### OQ1 — Minimum sufficient world model

For a given protected use, which external/current states, processes and dynamics must remain observable/modelled, and which can safely remain outside representation?

The research establishes that live world state can matter; it does not imply modeling the whole world.

### OQ2 — Boundary lifecycle

How should a system-of-interest boundary be selected, revised and versioned when tools, agents, services or infrastructure become more tightly/loosely coupled over time?

Boundary relativity is established; exact governance is not.

### OQ3 — Controllability / observability thresholds

When should an external condition be tracked because it can be sensed, influenced, disturbed or only statistically inferred? The foundation pass preserves state/observation separation but does not choose a control-theoretic model.

### OQ4 — Environmental dynamics granularity

When is a condition best treated as a state, process, event, stochastic dynamic, constraint or background assumption? Domain semantics differ materially.

### OQ5 — Resource semantics

Resources/capacity can be internal, Actor-bound, shared or external. The independent pass does not decide one universal resource ontology or scarcity model.

### OQ6 — Social/institutional environment

Regulations, markets, norms, counterparties and public infrastructure can affect Work and Actor possibilities. The exact line between external condition, Actor authority/obligation and relation/control semantics remains domain- and boundary-dependent.

### OQ7 — Model mismatch and environment knowledge

How should a system represent confidence, uncertainty, freshness and model mismatch between believed environment dynamics and actual dynamics? This touches Records/evidence/verification and later design.

### OQ8 — Cross-level recurrence

The same boundary-relative operating-world problem appears structurally plausible for Development OS, SOUL and task-specific working systems, but recurrence across these levels has not been independently validated as a universal grammar.

## Reopen condition

Reopen Environment substantive research if:
- user explicitly directs it;
- a later synthesis exposes a decision-critical external/world distinction not supported here;
- or a material counterexample shows that the current boundary/state-dynamics/actionability account omits a new first-order family.
