# Environment — Deferred Relations

**Status:** current cross-vertical deferral surface  
**Vertical revision:** `environment-foundation-2026-09-01-r1`  
**Rule:** these relations were exposed by Environment research but are not solved inside this independent vertical.

## DR1 — Environment ↔ Records: observation, evidence and freshness

Questions:
- What persistent information establishes an observation of world state, with what time/provenance/uncertainty?
- How should stale beliefs or records be distinguished from changed world state?
- Which environmental model/dynamics assumptions deserve persistence and versioning?

Environment contribution only:
- world state, observation/belief and Record cannot safely collapse.

Deferred because:
- persistence, provenance, retrieval and standing are Records concerns; evidence strength is later synthesis/verification.

## DR2 — Environment ↔ Work: feasibility, readiness and effects

Questions:
- Which world/resource/interface conditions make Work executable, blocked, risky or inapplicable?
- How do Work actions change external state and how are partial effects/compensation related to world recovery?
- When is a condition a Work dependency versus a broader operating-world state shared across Work?

Environment contribution only:
- actionability can change with external condition while Work description remains fixed.

Deferred because:
- Work-local lifecycle/dependency semantics and composition belong outside this vertical.

## DR3 — Environment ↔ Actors: capability, access and situated possibility

Questions:
- How should stable competence/capability combine with current affordances/resources/interfaces?
- Which environment conditions affect authorization without becoming authority themselves?
- How do affected parties, counterparties and other Actors contribute to one Actor/system's environment while retaining Actor semantics?

Environment contribution only:
- situated possibility is relational and cannot be assigned wholly to the Actor or Environment object.

Deferred because:
- authority, obligation, delegation and attribution remain Actors/relation questions.

## DR4 — Boundary / system-of-interest relation

Questions:
- Who/what selects the system-of-interest and boundary for a given analysis/Work system?
- How are boundary changes justified, time-scoped and kept consistent with Actors/Work/Records?
- When does an external tool/service become an internal/constitutive system element?

Environment contribution only:
- boundary choice materially determines Environment membership.

Deferred because:
- boundary governance is a later system-composition/control question.

## DR5 — External systems and interfaces

Questions:
- How are external systems represented while preserving their own Actor/Work/Records semantics if relevant?
- Is an interface a property of one endpoint, a bilateral relation, a contract, a Work dependency or composite?

Environment contribution only:
- external interfaces are load-bearing to actionability and effects.

Deferred because:
- final relation ownership requires cross-vertical synthesis.

## DR6 — Resources / capacity / availability

Questions:
- When is capacity an Actor capability, Work allocation/flow constraint, external resource state or relation among them?
- How should shared/scarce/depletable resources affect multiple Work units?

Environment contribution only:
- current resource availability may vary independently of Actor/Work facts.

Deferred because:
- allocation authority and flow semantics cross Work/Actors/environment.

## DR7 — Validation / acceptance in operating environment

Questions:
- Which environment state/conditions are necessary to establish intended-use validation or readiness?
- How are representative test/simulation environments related to actual operational environment?

Environment contribution only:
- success/fitness can depend on operating conditions not captured by execution closure.

Deferred because:
- verification/validation/acceptance and evidence are cross-vertical/control concerns.

## DR8 — Exogenous dynamics and responsibility

Questions:
- When an external disturbance/change causes failure, how should causal contribution, prevention/detection duty and accountability be attributed?

Environment contribution only:
- external dynamics may change independently and causally affect outcomes.

Deferred because:
- causal attribution, responsibility, Work recovery and evidence require later combined analysis.
