# SOUL Context — exploratory work

## Status

**LOCAL / PROVISIONAL / NOT PROMOTED**

Bu klasör, repo-context çalışması sırasında kullanıcının proje-geneli araştırma metodolojisine geçmesinden **önce** üretilmiş ek düşünce ve challenge artefaktlarını taşır.

Bunlar kötü/atıl içerik değildir; fakat epistemik rolleri `evidence/` ile farklıdır.

## Kullanım sınırı

Bu dosyalar:

- eski repoların bize doğrudan söylediği bilgi değildir,
- `AGENT.md` veya `agent/**` davranışı değildir,
- project-wide SOUL Research methodology değildir,
- canonical taxonomy/stopping/package schema değildir,
- SOUL architecture/requirements/backlog değildir.

Kullanıcı yalnız "eski repo araştırmalarına bak" dediğinde bu klasör **default olarak okunmaz**.

Bu klasör ancak:

- kullanıcı erken/provisional fikirleri özellikle istediğinde,
- yeni bir yöntem tasarımında geçmiş exploratory work'ü karşılaştırma/karşı-kanıt olarak görmek gerektiğinde,
- belirli bir eski hipotezin nasıl oluştuğu sorulduğunda

açılır.
