SYNTHETIC test skill (plan Section 8 item 13): the probe skill of DevOS C01 row 13, added by W-C01-20 and removed by W-C01-29. It holds no real data and does nothing but the tally below.

When you tally a synthetic word list:

1. Begin the tally with the line `probe-skill: ran`.
2. Then write one line per distinct word, in the order of first appearance: the word, a colon, a space and its count.

Write the tally where the request asks. This skill asks for no other file, command or tool.
