3. **BLOCKING: the push check can silently skip file contents and commit messages.** Location: `tool_allowlist.py:1769-1775`.
   - **Cause.** `pushed_blocks` reads one `git log -p --text --format=%x1e%H%x1f%B%x1f` stream. It splits commits on byte 0x1e and fields on byte 0x1f. Message and patch bytes are not escaped, so either byte inside a message or an added file moves the record boundaries. Text after it is dropped (it lands in the "sha" field) or read as the wrong field.
   - **Evidence 1: control character in a message.** A commit whose message is `W` + 0x1f + the planted secret: `git -C <fixture> push origin claude/t-us` → "allowed by rule L1: the push's 1 commit(s) … carry no library match". On the same message text, `tools/leak_fingerprints.py scan` reports "1 line(s) matched". The 0x1e variant is also allowed and reports "2 commit(s)" for one commit.
   - **Evidence 2: an ordinary commit.** One commit adds `a.png`, whose bytes include 0x1e and no later 0x1f, together with `b.md` holding the planted secret and `c.md` holding the fake service name. Result: "allowed by rule L1: the push's 21 commit(s) …". Neither check ran on the later files, and the commit count shows the parse broke.
   - **Why it matters.** `--text` emits binary files as raw bytes, and binary data usually contains 0x1e. Any commit that adds a figure or PDF sorted before text files can hide those files' added lines. That breaks "the file contents, paths and commit messages of every commit in the pushed range", and the gap can be hit by accident, not only on purpose.
   - **Fix to re-check.**
     - List the range with `git rev-list`, and use that list for the commit count.
     - Read each commit's message and its first-parent patch separately, or use a NUL-delimited format that no content byte can break.
     - Either leave binary files out of the patch or parse them safely. The working order already lists encoded and compressed files as not covered.
     - Add negative tests: a message with 0x1e and one with 0x1f before the secret; a commit adding a binary with 0x1e before a secret file and a service-name file. Assert an L1 deny and the correct commit count.
