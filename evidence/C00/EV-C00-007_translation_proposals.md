# EV-C00-007 · Proposals noticed during the translation of the plan package (W-C00-06)

They are proposals, not decisions. The English text was translated as the Turkish stood, so none of these changes is in it. W-C00-10 (plan C00 step 7) gives each row a disposition, and a row that changes the plan goes through plan section 14. Line numbers are those of the Turkish source at commit 3de3a17; the English text keeps them.
