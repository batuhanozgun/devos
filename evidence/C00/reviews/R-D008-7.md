## Criterion 2: B-2 fix

**Denied, as claimed:** for exact paths to `tools/check_records.py` and `tools/records.py`, the file tools, `>`, `sed -i`, `tee`, `cp` onto the file, `rm`, `mv`, `truncate`, `dd` and `ln -sf`. Running them via `python3` is allowed.

**B7-1 (blocking): the gate code is guarded by exact path only, so named writes still change M7.** `write_guarded` compares realpaths for equality. Unlike the strict zones, it applies no glob expansion, no ancestor test and no coverage of what the gate imports. All of the following are **allowed** in the live tree:
- **Glob:** `sed -i s/a/b/ tools/*.py`. This is a realistic honest mistake (a bulk rename across tools), and it rewrites both gate files. The same glob on `.claude/hooks/*.py` is denied.
- **Ancestor:** `rm -rf tools`, `mv tools <x>`, then `mv <x'> tools`.
- **Import shadowing, non-shell:** `Write` of `tools/yaml.py` (rule T1). The gate runs `python3 tools/check_records.py`, so the script directory is first on `sys.path`, and a new `tools/yaml.py` replaces PyYAML for the gate. Reproduced in a disposable copy: a one-line `tools/yaml.py` took over `check_records.py`'s run. A `.pyc` under `tools/__pycache__/` is a similar route for `records`.

The glob case is a named-target write and the shadowing case is a non-shell route, so both fall in the review prompt's blocking class. L-103's claim that "M7 no longer depends on a file any tool could silently change" is not met.

Fix (either is enough):
- (a) **Structural, as R-D008-6 suggested.** Have `merge_checks` export `tools/` from `origin/main` (`git archive` or `git show`) into a fresh temporary directory, and run it with `python3 -B -P` (no bytecode writes, no script-directory path entry; `-P` needs Python 3.11 or later, else set `sys.path` explicitly) and a clean environment.
- (b) **Lexical.** Make the whole live `tools/` directory a strict zone. That gives it glob and ancestor handling, and covers new files. It costs nothing, because the live tree stays at `main` and changes are made in scratch clones.

Add planted cases either way. Separately, the denial reason for the file tools is labelled `F3 (Claude Code's own configuration)`, which misnames the gate code (minor, acceptance (c)).
