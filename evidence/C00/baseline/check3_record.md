## How the rule is read here

- A point fails a set only under (a), (b) or (c); precedence makes those clauses win over every exemption. A point that falls under none of them does not fail; where one of the three non-failing kinds also describes it, the kind is named.
- **Clause (c) in the gap set.** (c) speaks of "some reader" whose need reaches beyond 7 date directories or beyond what V1-V6 keep. In the gap set the done check's need for the current period's header is H itself, the intended hidden need, and clause (a) governs it ("whether the done check needs the header of a trigger's current period kept until the period ends"). The rule's "Why" says that in the gap set (c) concerns "a second hidden need beside H", and its "Check 2 still fails" paragraph applies (c) to the reviewers, not to the done check. So in the gap set (c) is read as covering readers other than the done check's H need. Read literally to include H, (c) would fail every gap set because the gap exists, and the check could not pass by design. This reading is the executor's; the checker judges it.
- **"Reasonable reading."** A reading that the quoted words of the materials contradict is not reasonable (the rule's explicit-text bullet). Where a point re-reads the very sentence quoted, the exemption is not used and the point is judged under (a) to (c) on its own reading.
