**F-1 (blocking). migration-checks.yml is not a valid workflow on GitHub, at this head and since fix 2.**

- **Where.** In migration-checks.yml, inside the `workflow_check` run body (YAML line 31), six `${{ … }}` sequences sit in Python string literals:
  - :74 `c.startswith("${{") and c.endswith("}}")`
  - :263, :265, :267 and :269, the `if:` values of the self-check copies
  - :303 `"${{ secrets.SUPABASE_DB_PASSWORD }}"`
- **What GitHub's parser says.** I ran `@actions/workflow-parser` 0.3.61 (npm, installed to scratch/w03verdict/wp, run offline) on both files. On migration-checks.yml it reports:

  - `(Line: 31, Col: 14): Unrecognized function: 'cancelled'`
  - migrate.yml: 0 errors.
- **Control.** A copy with only those literals rewritten gives 0 errors.
- **When it entered.** The same parser on the file at each commit:
  - eddab74: 0 errors
  - 762640d: 0 errors
  - d4eb7c6 (fix 2): the 2 errors
  - ccd92f2: the 2 errors
  - 5cad061: the 2 errors
- **Effect.** On GitHub, M22, `pr_inputs` (M15), `pr_decide` (M16) and `w03_tests` never run on any pull request. That means:
  - Point 6's "the checks of the next pull request name the difference" cannot be met.
