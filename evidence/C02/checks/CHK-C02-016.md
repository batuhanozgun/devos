EV:364 uses it the same way twice ("kaydetmeden kapatın"). So the reader is primed for "restart that project without resetting the password". That contradicts the step it then names, because step 18/42 is the reset button.

- **Effect.** There is no leak. The worst outcomes are:
  - confusion;
  - skipping the reset, which leaves a wrong secret that "connection: failed" catches;
