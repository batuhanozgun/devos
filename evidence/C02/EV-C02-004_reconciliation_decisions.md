# EV-C02-004 · Reconciliation decisions

**Why this record exists.** The executor allocated the points where W-C02-03, W-C02-04 and W-C02-05 meet (L-285: A1 the token's path is W-C02-05's; A2 the migration path is W-C02-03's) and had each producer write the interfaces it assumed of the others. A reader compared W-C02-04's and W-C02-05's records (R-45). This record gives the executor's decision on each point it raised, so that the revising producers write one design, and each decision says which record changes. Each is a technical decision (working order section 8); none is Batu's, unless marked. The points that depend on W-C02-03 are decided in part 2, after its record.
