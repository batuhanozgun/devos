# DevOS

DevOS, SOUL'u geliştirecek yapay zekâ çalışma sistemidir. SOUL, kullanıcının bir işi yapabilmesi için eksik kalan uzmanlığı kapatan bir ajan sistemi olarak tasarlanmaktadır; ürün deposu [`soul-system`](https://github.com/batuhanozgun/soul-system).

## Durum

Kurulum henüz başlamadı. Bu depoda şu an yalnız kurulum planı ve ekleri var. Kurulumu bir Claude Code oturumu (kurucu) bu plana göre yapacak.
